# Оригинал

### Татар халык / Зиннур Сафиуллин - Соңгы кыңгырау (өченче вариант)

```
Көмеш чыңлы җиз кыңгырау безне
Олы юлга калды озатып.
Ул әле дә чыңлый колакларда
Күңелләрне безнең кузгатып.

Җиз кыңгырау чыңнарына күмелеп,
Артта калды мәктәп еллары.
Гомер буе озата барыр инде
Кыңгырауның көмеш чыңнары.

Урамнарда мәктәп юлы белән
Укучылар үтсә тезелеп,
Сабакташлар шунда искә төшә,
Күңелкәйләр кала өзелеп.

Җиз кыңгырау чыңнарына күмелеп,
Артта калды мәктәп еллары.
Гомер буе озата барыр инде
Кыңгырауның көмеш чыңнары.

Еллар урап, бер кайтырбыз әле,
Тынып калгач язгы ташулар.
Укытучының якын тавышыдай
Җиз кыңгырау моңы каршылар.

Җиз кыңгырау чыңнарына күмелеп,
Артта калды мәктәп еллары.
Гомер буе озата барыр инде
Кыңгырауның көмеш чыңнары.
```

# Перевод

### Татар халык / Зиннур Сафиуллин - Последний звонок (третий вариант)

```
Медный колокол с серебряным звоном
Проводил нас в большую дорогу.
Он и ныне в ушах отзывается,
Тревожа наши сердца.

Погрузившись в перезвоны медного колокола,
Позади остались школьные годы.
Всю жизнь теперь будет провожать
Серебряный звон колокола.

По дороге к школе, вдоль улиц
Шли колонной ученики,
И тогда вспоминаются одноклассники -
Сердце сжимается от тоски.

Погрузившись в перезвоны медного колокола,
Позади остались школьные годы.
Всю жизнь теперь будет провожать
Серебряный звон колокола.

Годы кругом - мы вернемся однажды,
Схлынут тихо весенние воды.
Как родной голос учителя, встретит
Нас мелодия медного звона.

Погрузившись в перезвоны медного колокола,
Позади остались школьные годы.
Всю жизнь теперь будет провожать
Серебряный звон колокола.
```
