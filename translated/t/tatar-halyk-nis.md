# Оригинал

### Татар халык / - ӘНИСӘ

```
Тыпыр-тыпыр биергә

Тимер идәннәр кирәк,

Тимер идәннәр өстенә

Хәтфә паласлар кирәк.
Хәтфә паласлар өстенә

Имән өстәлләр кирәк,

Имән өстәлләр өстенә

Көмеш табаклар кирәк.
Көмеш табаклар эченә

Хөрмә җимешләр кирәк,

Хөрмә җимешләр ашарга

Алтын кашыклар кирәк.
Алтын кашыкны тотарга

Кара кашлы кыз кирәк,

Кара кашлы кыз каршына

Батыр егет тә кирәк.
```

# Перевод

### Татар халык / - Аниса

```
Чтобы плясать притопывая,

Нужен железный пол,

А поверх железного пола

Нужны бархатные ковры.
Поверх бархатных ковров

Нужны дубовые столы,

А поверх дубовых столов

Нужны серебряные подносы.
В серебряные подносы

Нужны финиковые плоды,

А чтобы есть финиковые плоды,

Нужны золотые ложки.
Чтобы держать золотую ложку,

Нужна черноброва девица,

А навстречу черноброй девице

Нужен ещё и батыр-джигит.
```
