# Оригинал

### Татар халык / - КАРУРМАН

```
Кара урманнарның уртасында

Төлке уйный торган урлар бар.
Кичтем карурман,

Кистем пар каен,

Сагынам көн саен.
Көйсен дә генә йөрәк, сүнмәсен дәрт,

Дәртлеләргә якты юллар бар.
Кичтем карурман,

Кистем пар каен,

Сагынам көн саен.
```

# Перевод

### Татар халык / - Чёрный лес

```
Посреди чёрных лесов
Есть поляны, где играют лисы.
Прошёл я чёрный лес,
Срезал пару берёз,
Тоскую каждый день.

Пусть утешится сердце, не угаснет пыл,
Для полных пыла есть светлые пути.
Прошёл я чёрный лес,
Срезал пару берёз,
Тоскую каждый день.
```
