# Оригинал

### Татар халык / - ҖАНЫЕМ-БӘГЪРЕМ

```
Иртә буран, кич тә буран,

Мамык шәлеңне уран, шул,

Мамык шәлеңне уран.

Кигән киемеңне күрсәм дә,

Җаныем-бәгърем,

Үзең күргәндәй булам.
Ишек алдында йөримен,

Яуган карны көримен, шул,

Яуган карны көримен.

Синнән башка ямь табалмыйм,

Җаныем-бәгърем,

Ямансулап йөримен.
Тимер чана карлар яра,

Бу йөрәгем ник яна, шул,

Бу йөрәгем ник яна?

Бу йөрәгем, белеп яна,

Җаныем-бәгърем,

Сөйгәнем ятка кала.
```

# Перевод

### Татар халык / - Душа моя, родная моя

```
Утром метель, и вечером метель,

Закутайся в свой пуховый платок, шул,

Закутайся в свой пуховый платок.

Даже если вижу твою одежду,

Душа моя, родная моя,

Мне кажется, будто вижу тебя саму.
Хожу у порога,

Разгребаю выпавший снег, шул,

Разгребаю выпавший снег.

Без тебя не нахожу отрады,

Душа моя, родная моя,

Хожу тоскуя.
Железные сани режут снег,

Отчего же горит это моё сердце, шул,

Отчего же горит это моё сердце?

Это моё сердце горит, зная,

Душа моя, родная моя,

Что мой милый остаётся у чужой.
```
