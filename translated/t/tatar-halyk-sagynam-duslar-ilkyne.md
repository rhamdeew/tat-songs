# Оригинал

### Татар халык / - САГЫНАМ, ДУСЛАР, ИЛКӘЙНЕ

```
Сагынам, дуслар,
сагынам, дуслар,

Сагынам туган илкәйне, шул,

Сагынам туган илкәйне.

Илкәй белән бергә сагынам

Яшьли сөйгән яркәйне.
Баш куям тезләреңә лә,

Яшь коям эзләреңә, шул,

Яшь коям эзләреңә.

Әллә ниләр бирер идем

”Аһ” дигән сүзләреңә.
Агасың Иделкәем лә,

Биек ярларың белән, шул,

Биек ярларың белән.

Каласың, туган илкәем

Сөйгән ярларым белән.
```

# Перевод

### Татар халык / - Скучаю, друзья, по родному краю

```
Тоскую, друзья,
тоскую, друзья,
Тоскую по родному краю, вот,
Тоскую по родному краю.
Вместе с родным краем тоскую
По любимой, что полюбил смолоду.

Кладу голову на твои колени,
Слёзы лью на твои следы, вот,
Слёзы лью на твои следы.
Чего бы я только не отдал
За слово твоё «ах».

Течёшь ты, Волга моя,
Своими высокими берегами, вот,
Своими высокими берегами.
Остаёшься ты, родной мой край,
С моими любимыми людьми.
```
