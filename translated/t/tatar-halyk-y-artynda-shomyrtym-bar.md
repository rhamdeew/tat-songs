# Оригинал

### Татар халык / - ӨЙ АРТЫНДА ШОМЫРТЫМ БАР

```
Өй артында шомыртым бар,

Яннарында бөрлегән, шул,

Яннарында бөрлегән.

Бөрлегәндәй матур булып

Чәчәк ата илгенәм.
Өй артында шомыртым бар,

Чәчәкләр яннарында, шул,

Чәчәкләр яннарында.

Без туганбыз илебезнең

Иң матур таңнарында.
Өй артында шомыртым бар,

Яннарында чияләр, шул,

Яннарында чияләр.

Чияләр дә безгә карап

Сез бәхетле, дияләр.
```

# Перевод

### Татар халык / - За домом у меня есть черёмуха

```
За домом у меня черёмуха,
Рядом с ней земляника, вот,
Рядом с ней земляника.
Прекрасная, словно земляника,
Цветёт моя родная сторона.

За домом у меня черёмуха,
Рядом с ней цветы, вот,
Рядом с ней цветы.
Мы родились в нашей стране
В самые прекрасные зори.

За домом у меня черёмуха,
Рядом с ней вишни, вот,
Рядом с ней вишни.
И вишни, глядя на нас,
Говорят: вы счастливы.
```
