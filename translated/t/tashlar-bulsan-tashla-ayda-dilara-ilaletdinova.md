# Оригинал

### Диләрә Илалетдинова - Ташлар булсаң ташла әйдә

```
Ташлар булсаң ташла әйдә, син мине

Җиргә салып тапта, әйдә, хисемне.

Җилгә очсын, эйдә, чәчәк бәйләмнәре

Онытыйк без биргән вәгъдәләрне.

Сагышларда, газапларда

Калдыр мине, алга кара.

Әйтә алмаган сүзләремнән

Әрнүләрем артта бара.

Син минем көннәремнең яктысы

Төннәремдә балкып торган йолдызым.

Сүндер әйдә китеп янар утларымны,

Төн капласын минем хыялымны.

Сагышларда, газапларда

Калдыр мине, алга кара.

Әйтә алмаган сүзләремнән

Әрнүләрем артта бара.

Ташлар булсаң ташла әйдә, син мине

Ятлар килеп урлады шул сөюне.

Телим сиңа бары, бары бәхетле бул

Тоя күрмә миндәге көюне.

Сагышларда, газапларда

Калдыр мине, алга кара.

Әйтә алмаган сүзләремнән

Әрнүләрем артта бара.
```
