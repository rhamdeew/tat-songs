# Оригинал

### Татар халык җыры - Җаныем, бәгырем (беренче вариант)

```
Иртә буран, кич тә буран,
Мамык шәлеңне уран шул,
Мамык шәлеңне уран.
Кигән киемең күрсәм дә,
Җаныем, бәгырем,
Үзең күргәндәй булам.

Ишек алдында йөримен,
Карлар яуса көримен шул,
Карлар яуса көримен.
Синнән башка ямь табалмый,
Җаныем, бәгырем,
Ямансулап йөримен.

Тимер чана карлар яра,
Бу йөрәгем ник яна шул,
Бу йөрәгем ник яна?
Бу йөрәгем белеп яна,
Җаныем, бәгырем,
Сөйгәнем ятка кала.
```

# Перевод

### Татарская народная песня - Душа моя, родная (первый вариант)

```
Утром вьюга, вечером метель,
В пуховую шаль свою закутайся, о,
В пуховую шаль свою закутайся.
Видеть твою одежду -
Душа моя, родная,
Будто самой тебя вижу.

У двери хожу я,
Снег пусть валит - разгребаю, о,
Снег пусть валит - разгребаю.
Кроме тебя краски не найду,
Душа моя, родная,
Хожу, тоскуя.

Железные сани снег режут,
Это сердце зачем горит, о,
Это сердце зачем горит?
Это сердце знаючи горит,
Душа моя, родная,
Любимый мой достанется чужому.
```
