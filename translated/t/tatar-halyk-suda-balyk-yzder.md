# Оригинал

### Татар халык / - СУДА БАЛЫК ЙӨЗӘДЕР

```
Суда балык йөзәдер лә,

Балыкчыны сизәдер, ай, сизәдер.
Кушымта:
Әкрен кирәк,

Ипләп кирәк

Ишетергә, сандугач сайрауларын.
Авылыбызда бер матур бар,

Үзәгемне өзәдер, ай, өзәдер.
Кушымта.
Кара бөдрә чәчләре лә,

Шомарадыр тараса, ай, тараса.
Кушымта.
Ушларымны китәрәдер

Бер елмаеп караса, ай, караса.
Кушымта.
```

# Перевод

### Татар халык / - В воде, наверное, плавает рыба

```
В воде плавает рыба,
Чует она рыбака, ай, чует.

Припев:
Тихо нужно,
Осторожно нужно,
Чтобы услышать пение соловья.

В нашей деревне есть одна красавица,
Разрывает мне душу, ай, разрывает.

Припев.

Её чёрные кудрявые волосы
Разглаживаются, если расчесать, ай, расчесать.

Припев.

Ум мой уносит,
Стоит ей улыбнуться и взглянуть, ай, взглянуть.

Припев.
```
