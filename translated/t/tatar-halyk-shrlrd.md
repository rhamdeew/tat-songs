# Оригинал

### Татар халык / - СӘХРӘЛӘРДӘ

```
Сәхрәләрдә кошлар, әй, ник моңлана? –

Ашый торган җимеше юк... юк... юк...
Моңсыз да егет, әй, ник моңлана?

Сөйгән яры янында юк... юк... юк...
```

# Перевод

### Татар халык / - В степях

```
В степи птицы, ай, почему тоскуют? –

Нет плодов, чтобы поесть... нет... нет... нет...
А безрадостный джигит, ай, почему тоскует?

Нет рядом любимой... нет... нет... нет...
```
