# Оригинал

### Татар халык / - АЙ, ЙОЛДЫЗЫМ

```
Әй дускаем, буең зифа,

Тал кебек бөгеләсең,

Таллар кебек бөгеләсең,

Кем өчен өзеләсең?
Кушымта:
Ай, йолдызым, йолдызым,

Йолдызым, рушаным,

Син йөргән гөл бакчасына

Керергә тырышамын.

Үзләренең коесы бар, –

Безгә кереп су ала,

Чиләген тутырып ала да,

Көлә-көлә югала.
Су буенда кыяк үлән –

Кыеп аласы иде.

Мәңге сагынмаслык итеп

Карап каласы иде.
Кушымта.
Гөл чәчәкләре коела

Былбыл кагынган саен.

Гөлчәчәкләргә охшатам

Сине сагынган саен.
Кушымта.
```

# Перевод

### Татар халык / - Ай, звезда моя

```
Эй, дружок, стан твой строен,
Гнёшься ты, словно ива,
Гнётесь вы, словно ивы,
По кому ты так истаиваешь?

Припев:
Ах, звезда моя, звёздочка,
Звёздочка моя, светлая моя,
В тот цветочный сад, где ты гуляешь,
Стараюсь я пробраться.

У них свой есть колодец, —
Заходит к нам за водой,
Наполнит ведёрко до края
Да со смехом исчезает.

У воды осока растёт —
Скосить бы её.
Так наглядеться,
Чтоб уж вовек не тосковать.

Припев.

Лепестки цветов осыпаются,
Всякий раз, как соловей встрепенётся.
С цветком тебя сравниваю
Всякий раз, как скучаю по тебе.

Припев.
```
