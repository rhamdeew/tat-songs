# Оригинал

### Туфан Миңнуллин / Хисмәтулла Дәүләтов - Фәрештәм

```
Гәрәбәдән тезгән муенсаккаенның
Гәрәбәсе кайсы гына илләрдән?
Тапмас бу диеп уйлама, табырмын
Җилләр куып җитә алмас җирләрдән.

Беләзегең, алкаларың көмештән,
Күңелләрең ник суынды, фәрештәм?
Йөзегеңә акык кашлар такмадым,
Нахак сүзләр кем сөйләде, аппагым?

Энҗеләрән тезгән муенсаккаеңның
Энҗеләре кайсы гына яклардан?
Мин кагылган кайнар кулларыңа
Кагылдыра күрмә бер үк ятлардан.

Беләзегең, алкаларың көмештән,
Күңелләрең ник сыуынды, фәрештәм?
Йөзегеңә акык кашлар такмадым,
Нахак сүзләр кем сөйләде, аппагым?
```

# Перевод

### Туфан Миңнуллин / Хисматулла Даулетов - Мой ангел

```
Из янтаря нанизанное твоё ожерелье -
Янтарь его из каких же стран?
Не думай, что не найду - найду я,
Из земель, куда и ветры не долетают.

Браслет твой, серьги твои из серебра,
Почему сердце твоё остыло, ангел мой?
Агатовый камень в кольцо твоё я не вставлял,
Кто лживые слова сказал, светлая моя?

Из жемчуга нанизанное твоё ожерелье -
Жемчуг его из каких же краёв?
К твоим горячим рукам, которых касался я,
Не дай прикоснуться чужим.

Браслет твой, серьги твои из серебра,
Почему сердце твоё остыло, ангел мой?
Агатовый камень в кольцо твоё я не вставлял,
Кто лживые слова сказал, светлая моя?
```
