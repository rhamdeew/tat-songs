# Оригинал

### Татар халык җыры - Җаным жәл түгел сиңа

```
Алым жәл түгел сиңа,
Гөлем жәл түгел сиңа;
Алым түгел, гөлем түгел,
Җаным жәл түгел сиңа

Алларым диям сине,
Гөлләрем диям сине;
Алым түгел, гөлем түгел,
Җаннарым диям сине.

Әрәмәдә карама,
Карамада кондыз бар;
Караңгы дип килми калма,
Ай булмаса, йолдыз бар.

Түгәрәк күлдән салкын су
Эчтем җаным көйгәнгә;
Ерак җирне якын итеп
Килдем сине сөйгәнгә.
```

# Перевод

### Татар халык җыры - Тебя мне не жаль, душа

```
Алое мне не жаль тебе,
И цветок мне не жаль тебе;
Не только алое, не только цветок -
Даже душу мне не жаль тебе.

Алой моей зову тебя,
Цветком моим зову тебя;
Не только алая, не только цветок -
Душой моей зову тебя.

В роще - вяз,
У вяза бобёр живёт;
Не останься, молвя: темно, -
Нет луны - звезда взойдёт.

Из кругляшки-озера
Пил я холод, душу жгло;
Даль я сделал близкой мне,
К тебе с любовью я пришёл.
```
