# Оригинал

### Татар халык / - УФА ЮЛЛАРЫ ПЫЯЛА...

```
Уфа юллары пыяла,

Таш булса таймас иде, шул,

Минем йөрәккәем яна, –

Син булсаң янмас иде.
Кызыл-кызыл бөрлегән лә,

Күл буена тезелгән, шул,

Булмас инде минем кебек

Синең өчен өзелгән.
Әйдә, дустым, су буена,

Бөдрә чәчең юарсың, шул,

Син юарсың, мин җырлармын,

Күңелең тулса җыларсың.
```

# Перевод

### Татар халык / - Дороги Уфы — стекло...

```
Дороги Уфы — стекло,
Был бы камень — не скользил бы, вот,
Моё сердечко горит, —
Была бы ты рядом — не горело бы.

Красная-красная земляника,
Вдоль озера рассыпана, вот,
Не будет уже, наверное, как я,
Так истосковавшегося по тебе.

Пойдём, друг мой, к воде,
Вымоешь свои кудрявые волосы, вот,
Ты помоешь, я спою,
А если сердце переполнится — заплачешь.
```
