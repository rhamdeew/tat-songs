# Оригинал

### Татар халык / - КАР СУЫ

```
Агып ла китте, агып ла китте...
Яулыгым кар суына, шул,

Аһ, җанашым, чыдый алмыйм

Йөрәгем ярсуына, шул,

Йөрәгем ярсуына.
Сикереп-сикереп агадыр кар суы,

Ник басылмый йөрәгем ярсуы?
```

# Перевод

### Татар халык / - Снеговая вода

```
Уплыл, уплыл...
Мой платок в талую воду, вот,
Ах, любимая моя, не могу совладать
С бушующим моим сердцем, вот,
С бушующим моим сердцем.

Прыжками-скачками течёт талая вода,
Почему же не утихает буйство моего сердца?
```
