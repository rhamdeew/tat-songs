# Оригинал

### Татар халык җыры - Аллы-гөлле гөлчәчәк (беренче вариант)

```
Аллы-гөлле гөлчәчәкне
Иснә, бәгырем, исле ул;
Үзе алсу, үзе нәфис,
Бигрәк синең төсле ул.

Гөл чәчәгенә бәйләнеп,
Чия пешә бал кебек.
Буең зифа яшь тал кебек,
Йөзең тулган ай кебек.

Алларым, диям сине,
Гөлләрем, диям сине;
Аллы-гөлле чәчәгем,
Дип, өзелеп сөям сине.
```

# Перевод

### Татарская народная песня - Цветочек с лепестками (первый вариант)

```
Пёстрый цветочек,
Понюхай, сердце моё, он ароматный;
Сам он розовый, сам нежный,
Особенно на тебя похож.

Рядом с цветком
Вишня зреет, как мёд.
Твой стан строен, как молодая ива,
Твоё лицо - как полная луна.

Мои алые, говорю тебе,
Мои цветы, говорю тебе;
Пёстрый мой цветочек,
Так, до боли, люблю тебя.
```
