# Оригинал

### Татар халык / - УФ, ЙӨРӘГЕМ

```
Җиделе лампа, бишле куык,

Ватылды җиргә төште;

Уф, йөрәгем, су бирегез,

Иркәм исемә төште.
Ак өемнең түрләренә

Элеп куйдым тастымал;

Уф, йөрәгем, су бирегез,

Ут кабуы ихтимал.
Урман буйларында йөргән

Чакларны сагынырсың;

Уф, йөрәгем, килмә якын,

Утына кабынырсың.
```

# Перевод

### Татар халык / - Ух, сердце моё

```
Семилинейная лампа, пузырёк на пять,

Разбился, упав на пол;

Ах, моё сердце, дайте воды,

Вспомнилась мне любимая.
На видном месте моего белого дома

Повесил я полотенце;

Ах, моё сердце, дайте воды,

Может, вспыхнет огонь.
Будешь тосковать по временам,

Когда гулял вдоль леса;

Ах, моё сердце, не подходи близко,

Загоришься от его огня.
```
