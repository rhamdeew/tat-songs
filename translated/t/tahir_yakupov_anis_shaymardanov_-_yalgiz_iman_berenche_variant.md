# Оригинал

### Таһир Якупов / Әнис Шәймәрданов - Ялгыз имән (беренче вариант)

```
Ялгыз имән ярын эзли,
Иелә иңнәремә.
Керер идем кочагыңа -
Булмый, син йөрәгемдә!

Ялгыз имән ярын эзли,
Үрелә беләгемә.
Калма, ияр дияр идем -
Булмый, син йөрәгемдә!

Ялгыз имән яр таба алмый,
Яшь тула күзләренә.
Күз яшьләрен алыр идем -
Булмый, син йөрәгемдә!

Ялгыз имән яр табалмый,
Гел керә төшләремә.
Төшне өнгә кушар идем -
Булмый, син йөрәгемдә!
```

# Перевод

### Таһир Якупов / Аниш Шаймарданов - Одинокий ясен (первый вариант)

```
Одинокий дуб ищет свою любовь,
Клонится к моим плечам.
Войти бы в твои объятия -
Нет, ты в моем сердце!

Одинокий дуб ищет свою любовь,
Тянется к моей руке.
Останься, «пойдём со мной» скажу я -
Нет, ты в моем сердце!

Одинокий дуб не может найти любовь,
Слезы наполняют глаза.
Стереть бы эти слёзы -
Нет, ты в моем сердце!

Одинокий дуб не находит любовь,
Всё приходит в мои сны.
Сон я явью бы сделал -
Нет, ты в моем сердце!
```
