# Оригинал

### Татар халык / - ТУГАН ИЛЕМ

```
Саг(ы)намын туган-үскән илемне,

Әллә кай җирләре ямьле_иде...

Сөямен, /

Шул илемне уйлап көямен. / 2 кат
Яшел болыннардан шаулап аккан

Сулары татлы, тәмле иде.

Бигрәк тә

Шул су буе тора йөрәктә.
Кайтасым ла килә туган якка,

Йөрәккәем шунда ашкына

Өзлексез... /

Чит җирләрдә ялгыз күңелсез. / 2 кат
Яланына чыгып йөргән чакта,

Таныш иде аның бар ягы.

Түзалмыйм, /

Туган-үскән илдән бизалмыйм. / 2 кат
Атам белән анам, туганнарым,

Дус-ишләрем калды барсы да,

Барсы да... /

Сагынып елыйм, йөрәк ярсый да. / 2 кат
```

# Перевод

### Татар халык / - Родная страна моя

```
Тоскую по родному краю, где рос,

Как же были прекрасны те места...

Люблю его, /

Думая о нём, сгораю. / (2 раза)
Реки, что с шумом текли

Среди зелёных лугов, были сладкими, вкусными.

Особенно

Тот берег реки живёт в моём сердце.
Хочется вернуться в родные края,

Моё сердце туда рвётся

Непрестанно... /

На чужбине одиноко и тоскливо. / (2 раза)
Когда выходил гулять в поле,

Всё вокруг было знакомо.

Не могу вытерпеть, /

Не могу отвыкнуть от родного края. / (2 раза)
Отец и мать, все родные,

Все друзья остались там,

Все... /

Тоскуя, плачу, сердце рвётся. / (2 раза)
```
