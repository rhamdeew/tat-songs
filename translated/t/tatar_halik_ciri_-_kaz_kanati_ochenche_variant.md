# Оригинал

### Татар халык җыры - Каз канаты (өченче вариант)

```
Каз канаты кат-кат була,
Ир канаты ат була;
Чит җирләрдә бик күп йөрсәң,
Туган илең ят була.

Каз канатлары кавырсын
Иркәм авыр - сабырсың.
Бик авырсаң, бик сабырсың
Ахры ятка калырсың.

Каз канатларын санадым
Тезелеп кагынганда.
Инде кемнәргә карармын
Өзелеп сагынганда?
```

# Перевод

### Татарская народная песня - Крылья гуся (третий вариант)

```
Крылья гуся - слой на слое,
Крылья мужчины - конь его;
Если много ходил по чужим землям,
Родная земля твоя - как чужая.

Гусиные крылья - перья,
Милый мой, тяжко - но ты терпелив.
Если очень тяжко, очень терпелив,
В конце концов останешься чужим.

Считал я гусиные крылья,
Когда они, выстроившись, взмахивали.
На кого теперь мне смотреть,
Когда изнываю от тоски?
```
