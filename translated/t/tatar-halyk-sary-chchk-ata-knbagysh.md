# Оригинал

### Татар халык / - САРЫ ЧӘЧӘК АТА КӨНБАГЫШ

```
Агыйделкәйләргә без төшәрбез,

Колачларны салып йөзәрбез, шул.

Юл өсләре яшел багана,

Юл өсләре яшел багана, –

Матур килде безгә замана.
Кычкырыр ла кәккүк, сайрар былбыл,

Шул чагында ничек түзәрбез?

Сары чәчәк ата көнбагыш,

Сары чәчәк ата көнбагыш,

Дуслар белән яшәү куаныч.
```

# Перевод

### Татар халык / - Жёлтым цветком цветёт подсолнух

```
Спустимся мы к Агидели,
Поплывём, раскинув руки, вот.
Вдоль дороги — зелёные столбы,
Вдоль дороги — зелёные столбы, —
Хорошее пришло к нам время.

Закукует кукушка, запоёт соловей,
Как же мы тогда стерпим?
Жёлтым цветом цветёт подсолнух,
Жёлтым цветом цветёт подсолнух,
Жить с друзьями — это радость.
```
