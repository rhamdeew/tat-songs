# Оригинал

### Татар халык / - АГЫМСУ

```
Агымсуның буйларында

Матур кырлар, урманнар.

Шул кырларда тырышып эшли

Безнең дуслар, туганнар.
Акчарлаклар шаулап оча

Агымсу буйларыннан.

Иртән истә, төнлә төштә, –

Чыкмыйсыз уйларымнан.
Ага сулар, ага сулар,

Ага сулар гел шулай.

Аккан сулар кире кайтмый, –

Яшь гомерләр дә шулай.
```

# Перевод

### Татар халык / - Река

```
Вдоль берегов текущей реки —
Красивые поля, леса.
На этих полях усердно трудятся
Наши друзья, родные.

Чайки с шумом летают
Вдоль берегов реки.
Утром в памяти, ночью во сне —
Не выходите из моих дум.

Текут воды, текут воды,
Текут воды всё так же.
Утёкшая вода назад не возвращается, —
Так же и молодые годы.
```
