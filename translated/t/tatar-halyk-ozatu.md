# Оригинал

### Татар халык / - ОЗАТУ

```
Сикердем читәннәрен лә,

Йөгердем, җитәлмәдем, шул,

Ни булды икән телләремә, –

Сау бул, дип әйтәлмәдем.
Урманнарда йөргән чакта

Адаштым юлларымны, шул,

Күңелем йомшак, елармын дип,

Бирмәдем кулларымны.
Өй артындагы талларны

Яратмасаң кисәрсең, шул,

Мин сагынсам тәрәзә ачам, –

Син җил булып исәрсең.
```

# Перевод

### Татар халык / - Проводы

```
Перепрыгнул через изгороди,

Бежал, но не успел, шул,

Что случилось с моим языком, –

Не смог сказать «прощай».
Гуляя по лесам,

Заблудился в дорогах, шул,

Душа моя мягкая, боялась расплакаться,

Не подал я тебе рук.
Ивы за домом

Не любишь – срубишь их, шул,

А я, тоскуя, открою окно, –

Ты подуешь ко мне ветром.
```
