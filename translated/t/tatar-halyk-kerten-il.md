# Оригинал

### Татар халык / - ӘКЕРТЕН, ҖИЛ...

```
Әкертен җил, монда кабер,

Монда анам күмелгән;

Монда ятим, яшь сабыйның

Кайнар яше түгелгән.
Өрмә җил, сызгырма, тукта –

Куркыр әнкәем, җаным;

Бирмисең тын моңаерга

Әнкәм турында минем.
```

# Перевод

### Татар халык / - Тише, ветер...

```
Тише, ветер, здесь могила,

Здесь похоронена моя мать;

Здесь сиротские, детские слёзы

Горячие пролились.
Не дуй, ветер, не свисти, остановись –

Испугается моя матушка, душа моя;

Ты не даёшь мне тихо погоревать

О моей матери.
```
