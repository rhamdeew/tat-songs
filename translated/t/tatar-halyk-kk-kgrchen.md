# Оригинал

### Татар халык / - КҮК КҮГӘРЧЕН

```
Күк күгәрчен күктә уйный,

Күләгәсе җирдә уйный.

Минем күңелем сине уйлый,

Күк күгәрчен, сандугачым,

Синең күңелең кемне уйлый?
Күк күгәрчен, кил каршыма,

Хат языйм канатыңа;

Язган хатым, аманатым,

Күк күгәрчен, сандугачым,

Тапшырчы җанашыма.
Күк күгәрченнәр гөрлидер

Гөлләр чәчәк атканда;

Син җаныемнан хәбәр көтәм,

Күк күгәрчен, сандугачым,

Таң сызылып атканда.
```

# Перевод

### Татар халык / - Сизый голубь

```
Сизый голубь играет в небе,

Его тень играет на земле.

Моя душа думает о тебе,

Сизый голубь, мой соловей,

О ком думает твоя душа?
Сизый голубь, подойди ко мне,

Я напишу письмо на твоём крыле;

Моё письмо, мой завет,

Сизый голубь, мой соловей,

Передай его моей любимой.
Сизые голуби воркуют,

Когда цветы распускаются;

Я жду вестей от своей души,

Сизый голубь, мой соловей,

Когда занимается заря.
```
