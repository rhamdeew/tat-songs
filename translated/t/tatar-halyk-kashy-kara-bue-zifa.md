# Оригинал

### Татар халык / - КАШЫҢ КАРА, БУЕҢ ЗИФА

```
Карлыгандай кара, ай, күзләрең,

Бөрлегәндәй йөзләрең.

Шикәрләрдән тәмле, ай, балдан татлы

Сөям дигән сүзләрең.
Кушымта:

Алма бакчасының юлы

Тәрәзәләргә туры.

Әллә сиңа бирелгәнме

Бөтен донъяның нуры?!

Кашың кара, буең зифа,

Күзең дә кара синең.

Кара күзеңә карасам,

Йөрәгем яна минем.
Бишмәтеңдә синең, ай, биш төймә,

Нигә төймәләмисең?

Аралар да безнең, ай, ерак түгел,

Нигә килгәләмисең?
Кушымта.
```

# Перевод

### Татар халык / - Брови твои чёрные, стан твой стройный

```
Черны, как смородина, ай, твои глаза,

Лицо твоё, словно костяника.

Слаще сахара, ай, слаще мёда

Твои слова «люблю тебя».
Припев:

Дорога яблоневого сада

Ведёт прямо к окнам.

Неужели тебе одной досталась

Вся краса этого мира?!

Брови твои черны, стан твой строен,

И глаза твои черны.

Как погляжу в твои чёрные глаза,

Загорается моё сердце.
На твоём бешмете, ай, пять пуговиц,

Почему ты их не застёгиваешь?

Ведь расстояние между нами, ай, не так уж далеко,

Почему же ты не приходишь?
Припев.
```
