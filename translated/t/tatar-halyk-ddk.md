# Оригинал

### Татар халык / - ДҮДӘК

```
Йөгерә үрдәк, йөгерә каз

Боты озынга күрә.
Кушымта:

Ай, дүдәк, дүдәк, дүдәк,

Басма өстендә каз-үрдәк,

Кыйгак-кыйгак,

Бак-бак-бак-бак,

Басма өстендә каз-үрдәк.
Без кызларны яратабыз

Бите кызылга күрә.
Кушымта.
Йөгерә үрдәк, йөгерә каз,

Кала эзеннән тамга.
Кушымта.
Үтә матурларны сайлап

Урта матурдан калма.
Кушымта.
```

# Перевод

### Татар халык / - Дудэк

```
Бежит утка, бежит гусь,
Потому что ноги длинные.

Припев:
Ай, дудэк, дудэк, дудэк,
На мостках гусь да утка,
Кыйгак-кыйгак,
Бак-бак-бак-бак,
На мостках гусь да утка.

Мы любим девушек
За то, что щёки красные.

Припев.

Бежит утка, бежит гусь,
Остаётся след-отметина.

Припев.

Выбирая самых красивых,
Не останавливайся на средней красоте.

Припев.
```
