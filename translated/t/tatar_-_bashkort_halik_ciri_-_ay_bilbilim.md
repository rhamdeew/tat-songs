# Оригинал

### Татар - Башкорт халык җыры - Башкорт халык җыры - Башкорт халык җыры - Ай былбылым

```
Ай былбылым, вай былбылым,
Агыйделнең камышы;
Таң алдыннан чут-чут килә
Сандугачлар тавышы.

Ай былбылым, вай былбылым,
Агыйделдә таң ата;
Таңнар ата, өзелә үзәк,
Җырлата да елата.

Ай былбылым, вай былбылым,
Кунып сайрый талларга;
Синең хакта серләремне
Сөйлим (ачам) сандугачларга.
```

# Перевод

### Татар - Башкирская народная песня - Башкирская народная песня - Башкирская народная песня - Ай, соловей мой

```
Ай, соловей мой, ух, соловей мой,
Тростник Агыйделя;
Перед зарёю слышно «чут-чут» -
Голос соловьёв.

Ай, соловей мой, ух, соловей мой,
В Агыйделе заря занимается;
Зори занимаются, сердце разрывается,
Заставляет петь и плакать.

Ай, соловей мой, ух, соловей мой,
Сидя, поёт на ивах;
О тебе мои тайны
Рассказываю (открываю) соловьям.
```
