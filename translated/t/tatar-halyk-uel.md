# Оригинал

### Татар халык / - УЕЛ

```
Курайчылар курай, ай, уйнамас,

Башкорт курайлары булмаса;

Моңсыз да гына егет, һай, моңаймас,

Баш кынае хәсрәтле булмаса.
Арыслан да киек һич урамас,

Каршысында биек тау булса;

Егет тә генә кеше һич кайгырмас,

Баш кынае аның сау булса.
```

# Перевод

### Татар халык / - Уел

```
Курайщики не станут играть на курае,

Ай, если не будет башкирских кураев;

И безрадостный джигит, ай, не затоскует,

Если не будет горестной родовой печали.
И лев, дикий зверь, никогда не зарычит,

Если перед ним высокая гора;

И джигит, человек, никогда не станет горевать,

Если его родовая честь цела.
```
