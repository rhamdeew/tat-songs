# Оригинал

### Таһир Асылгәрәй - Язгы яңгыр

```
Үтәр әле кышлар да,
Килер сагынган язлар.
Кояш нурыннан алда,
Болыннарымны назлар.

Язгы яңгыр, ямь уятыр,
Кышның әзләрен юар.
Тәүге тапкыр, нур уйнатып,
Яшь үләннәре туар.

Көннәр чумар чәчкәгә,
Төсләрен яңгыр буяр.
Төннәр йолдыз чәчсә дә,
Уңыш яңгыры кояр.

Язгы яңгыр, ямь уятыр,
Кышның әзләрен юар.
Тәүге тапкыр, нур уйнатып,
Яшь үләннәре туар.
```

# Перевод

### Таһир Асылгәрәй - Летний дождь

```
Пройдут и эти зимы,
Придут желанные вёсны.
Перед лучами солнца
Мои луга разнежит.

Весенний дождь пробудит прелесть,
Смоет зимние следы.
Впервые, играя лучом,
Родится молодая трава.

Дни утонут в цветах,
Дождь окрасит их цвета.
Пусть ночи и рассыпают звёзды,
Прольётся дождь урожая.

Весенний дождь пробудит прелесть,
Смоет зимние следы.
Впервые, играя лучом,
Родится молодая трава.
```
