# Оригинал

### Пума - Сагынма, жимешем

```
Хыялым турендэ
Мин синен белэн.
Акылынны жинэм,
Янына килэм.

Мин очам хыялга,
Канатлар талса да,
Сагыну давылы
Йорэкне ярса да.
Кунелдэ сурэтенэ
Шаярып куз кысам,
Очрашу мизгелендэ
Мин сине кочам.

Сагынма, жимешем,
Сагынма, килэм мин,
Сагынма, яратканым син.
Син мине кот, син мине кот,
Сагынма, килэм мин.

Юлларын чигендэ
Карашын куренэ,
Менлэгэн нурларын
Балкышы син генэ.

Сагынма, жимешем,
Сагынма, килэм мин,
Сагынма, яратканым син.
Син мине кот, син мине кот,
Сагынма, килэм мин.
```

# Перевод

### Пума - Не скучай, моя милая

```
В глубине моей мечты
Я с тобой.
Я покоряю твой разум,
Прихожу к тебе.

Я лечу в мечту,
Пусть даже устанут крылья,
Пусть буря тоски
Разрывает сердце.
В душе твоему образу
Я шутливо подмигну,
В миг нашей встречи
Я обниму тебя.

Не скучай, моя радость,
Не скучай, я иду,
Не скучай, ты моя любимая.
Жди меня, жди меня,
Не скучай, я иду.

На краю твоих дорог
Мне видится твой взгляд,
Среди тысяч лучей
Сияешь только ты.

Не скучай, моя радость,
Не скучай, я иду,
Не скучай, ты моя любимая.
Жди меня, жди меня,
Не скучай, я иду.
```
