# Оригинал

### Кәрим Тинчурин / Салих Сәйдәшев - Мәйсәрә

```
Чыбылдыгың чуп-чуар,
Эчләрендә кем кунар?
Сызылып моңсу, якты таңнар аткан чакта
Мамык мендәр тешләп кем елар?

Үкси-үкси, Мәйсәрә җан,
Яшь урынына түкмә кан,
Яшь урынына түкмә кан.

Чыбылдыгың бизәген
Ука белән бизәдең,
Бәхилләшеп аерылганда, елый-елый,
Ал яулыгың болгап изәдең,

Үкси-үкси, Мәйсәрә җан,
Яшь урынына түкмә кан,
Яшь урынына түкмә кан.

Чыбылдыгың ак чугын
Бәйрәмнәрдә тагарсың.
Сөйгән ярың, Булат бәгырең исеңә төшсә
Төнлә ялгыз айга карарсың.

Үкси-үкси, Мәйсәрә җан,
Яшь урынына түкмә кан,
Яшь урынына түкмә кан.
```

# Перевод

### Кәрим Тинчурин / Салих Сәйдәшев - Мэйсәрә

```
Твой полог — пёстрый-пёстрый,
Кто заночует внутри?
Когда занимаются тоскливые, светлые рассветы,
Кто плачет, кусая пуховую подушку?

Рыдай, рыдай, душа Мэйсэрэ,
Вместо слёз не пролей кровь,
Вместо слёз не пролей кровь.

Украшенье твоего полога
Ты золотой нитью расшивала,
Прощаясь, расставаясь, плача-плача,
Ты махала своим алым платком,

Рыдай, рыдай, душа Мэйсэрэ,
Вместо слёз не пролей кровь,
Вместо слёз не пролей кровь.

Белую кисть твоего полога
Наденешь по праздникам.
Если вспомнишь любимого, родного Булата,
Ночью одиноко посмотришь на луну.

Рыдай, рыдай, душа Мэйсэрэ,
Вместо слёз не пролей кровь,
Вместо слёз не пролей кровь.
```
