# Оригинал

### АсылъЯр - Карлыгачлар

```
Офыкка җәя канатын

Алсу таңның балкышы.

Мин сине уйлап уянам

Күңелемнең аккошы.

Карлыгачлар оя ясый,

Шуны күрәсем килә.

Үз оямны синең белән

Бергә үрәсем килә.

Таң нуры безнең йөзләрне

Балкытып торсын иде.

Минем сөю йөрәгеңне

Җилкетеп куйсын иде.

Карлыгачым,сәлам бирче

Минем сөйгән ярыма.

Ул да миңа җан атадыр

Күңеленә аккошына
```

# Перевод

###  - Ласточки

```
Раскрывает крылья над горизонтом

Сияние алой зари.

Я просыпаюсь, думая о тебе,

Лебедь моей души.

Ласточки вьют гнездо,

Хочется мне это увидеть.

Своё гнездо с тобою

Хочу вместе свить.

Пусть луч зари наши лица

Озаряет всегда.

Пусть моя любовь твоё сердце

Взволнует, всколыхнёт.

Ласточка моя, передай привет

Моему любимому.

Он тоже, наверное, всей душой тянется ко мне,

К лебедю своей души.
```
