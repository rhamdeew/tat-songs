# Оригинал

### Татар халык җыры - КӨЙМӘ ГЕНӘ КИЛӘ ГЕНӘ

```
Су буенда кыяк үлән,

Кыеп аласы иде;

Мәңге сагынмаслык итеп

Карап каласы иде.

Кушымта:

Көймә генә килә генә,

Көймә генә килә генә,

Көймә генә килә генә,

Эзе юк.

Хаты гына килә генә,

Сүзе генә килә генә,

Сөйләшергә үзе юк.

Мәк чәчәкләре коела,

Былбыл кагынган саен.

Мәк чәчәкләренә карыйм,

Сине сагынган саен.

Кушымта.
```

# Перевод

### Татарская народная песня - Лишь лодочка плывёт

```
У воды растёт осока,
Хотелось бы её срезать;
Чтобы вовек не тосковать,
Хотелось бы наглядеться.

Припев:
Лишь лодочка плывёт,
Лишь лодочка плывёт,
Лишь лодочка плывёт,
А следа её нет.

Лишь письмо от неё приходит,
Лишь слово её приходит,
А самой, чтоб поговорить, нет.

Осыпаются маковые цветы
Всякий раз, как встрепенётся соловей.
Смотрю я на маковые цветы
Всякий раз, как тоскую по тебе.

Припев.
```
