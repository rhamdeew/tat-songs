# Оригинал

### Татар халык җыры - КАР СУЫ

```
Агып ла китте, агып ла китте...

Яулыгым кар суына, шул,

Аһ, җанашым, чыдый алмыйм

Йөрәгем ярсуына, шул,

Йөрәгем ярсуына.

Сикереп-сикереп агадыр кар суы,

Ник басылмый йөрәгем ярсуы?
```

# Перевод

### Татарская народная песня - Снеговая вода

```
Унесло течением, унесло течением...
Мой платок в талую воду,
Ах, любимый мой, не могу вытерпеть
Пыл моего сердца,
Пыл моего сердца.

Скачками течёт талая вода,
Почему не утихает пыл моего сердца?
```
