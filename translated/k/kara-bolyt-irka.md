# Оригинал

### Иркә - Кара болыт

```
Аккошлар юлыннан килә

Яшенле кара болыт

Йөрәктә мәхәббәт әрни

Төзәлмәс яра булып.

Кара болыт, кара болыт,

Минем арттан агылма.

Каударланып йөрәгемнең

Ярасына кагылма.

Карадым кара болытка

Күзләрем каралсын дип

Җилләргә әйттем өздем дә

Болытлар таралсын дип.

Кара болыт, кара болыт,

Минем арттан агылма.

Каударланып йөрәгемнең

Ярасына кагылма.
```

# Перевод

###  - Чёрная туча

```
По пути лебедей идёт

Грозовая чёрная туча.

В сердце болит любовь,

Незаживающей раной.

Чёрная туча, чёрная туча,

Не плыви вслед за мной.

Тревожа,

Не касайся раны моего сердца.

Смотрела я на чёрную тучу,

Чтобы глаза мои почернели.

Ветрам сказала, попросила,

Чтобы тучи развеялись.

Чёрная туча, чёрная туча,

Не плыви вслед за мной.

Тревожа,

Не касайся раны моего сердца.
```
