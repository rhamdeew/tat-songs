# Оригинал

### Камил Гәрәев / Фәрит Хатыйпов - Янаул

```
Мәңге яши күңелләрдә
Гөл бакчалы Янаул.
Янаулга бер килгәннәр,
Мәңгелеккә кала ул.
Янаул, Янаул!
Мәңгелеккә капа ул.

Яңалыкны һәр вакыт та
Алга куя Янаул.
Шуңа да бит чәчкә ата,
Шуңа күрә яңа ул.
Янаул, Янаул!
Тормышында - яңа юл.

Яңаулның киләчәге
Яктылыкка яңа юл.
Янаул, - дип әйтсәләр дә
Йөрәк ярсып яна ул.
Янаул, Янаул!
Яктылыкка - яңа юл.
```

# Перевод

### Камил Гараев / Фарит Хатыпов - Янаул

```
В сердцах живёт навеки
Янаул — садов цветник.
Кто в Янаул однажды
Приехал — остался навек.
Янаул, Янаул!
Навеки он пленяет.

Всегда вперёд новинку
Выдвигает Янаул.
Потому он расцветает,
Потому он вечно нов.
Янаул, Янаул!
В его жизни — новый путь.

Будущее Янаула —
Новый путь к свету.
Лишь имя прозвучало —
Сердце страстно загорится.
Янаул, Янаул!
К свету — новый путь.
```
