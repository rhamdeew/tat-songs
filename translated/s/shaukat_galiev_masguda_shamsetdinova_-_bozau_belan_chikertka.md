# Оригинал

### Шәүкәт Галиев / Мәсгудә Шәмсетдинова - Бозау белән чикерткә

```
Атласа да тын гына,
Тавыш бирә кыңгырау:
Чең, чең, чең, чең...
Ишеткән, ди, чикерткә.

Мин дә монда ялгызау,
Кил бергә сайрыйк, бозау.
Чрик, чрик, чрик, чрик...
Чең, чең, чең...
```

# Перевод

### Шәүкәт Галиев / Мәсгудә Шәмсетдинова - Телёнок и кузнечик

```
Хоть и ступает тихонько,
Колокольчик подаёт голос:
Динь, динь, динь, динь...
Услышал, говорят, кузнечик.

Я тоже здесь одинок,
Приходи, споём вместе, телёнок.
Чрик, чрик, чрик, чрик...
Динь, динь, динь...
```
