# Оригинал

### Салават Фатхетдинов - Адашкан мэхэббэт

```
Айдан тошкэн серле купер
Монлыларга нур булып.
Шул купердэн, шул купердэн
Адашкан мэхэббэт бара,
Адашкан мэхэббэт бара
Язмыш буйлап куылып.

Карлы янгыр уксеп елый
Тэрэзэгэ сугылып.
Янгыр тугел, янгыр тугел
Адашкан мэхэббэт елый,
Адашкан мэхэббэт елый
Тыелып кына, сулыгып.

Гайбэт жыеп жиллэр йори
Ысылдап, я сызгырып.
Жиллэр тугел, жиллэр тугел
Адашкан мэхэббэт йори,
Адашкан мэхэббэт йори
Бэрелеп тэ сугылып.
```

# Перевод

### Салават Фатхетдинов - Заблудившаяся любовь

```
Таинственный мост, что спустился с луны,
Стал лучом для тоскующих.
По этому мосту, по этому мосту
Заблудившаяся любовь идёт,
Заблудившаяся любовь идёт,
Гонимая судьбой.

Снежный дождь рыдает навзрыд,
Ударяясь в окно.
Не дождь это, не дождь это —
Заблудившаяся любовь плачет,
Заблудившаяся любовь плачет,
Сдержанно всхлипывая.

Собирая сплетни, ветры бродят,
Шипя или свистя.
Не ветры это, не ветры это —
Заблудившаяся любовь бродит,
Заблудившаяся любовь бродит,
Ударяясь и разбиваясь.
```
