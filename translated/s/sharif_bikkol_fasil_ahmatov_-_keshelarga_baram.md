# Оригинал

### Шәриф Биккол / Фасил Әхмәтов - Кешеләргә барам

```
Куанычтан җан җылынса,
Якты сукмак ярам;
Шатлыгымны өләшергә
Кешеләргә барам!

Күңелемне юатырга
Бетсә соңгы чарам,
Хәсрәтләрдән арынырга
Кешеләргә барам.

Кемлегемне сынар булсам
Кешеләргә барам!
И, кешеләр, сезнең белән
Өзелмәсен арам!
```

# Перевод

### Шәриф Биккол / Фасил Әхмәтов - К людям иду

```
Когда от радости согревается душа,
Я прокладываю светлую тропу;
Чтобы поделиться своей радостью,
Я иду к людям!

Когда иссякнет последнее средство
Утешить мою душу,
Чтобы освободиться от печалей,
Я иду к людям.

Когда захочу проверить,
Кто я есть,
Я иду к людям!
О люди, пусть с вами
Не прервётся моя связь!
```
