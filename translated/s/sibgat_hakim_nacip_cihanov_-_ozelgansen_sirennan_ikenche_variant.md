# Оригинал

### Сибгат Хәким / Нәҗип Җиһанов - Өзелгәнсең сиреньнән (икенче вариант)

```
Яулыкларың әллә синең, әллә синең чигелгән, чигелгән,
Юлларыма әллә сирень, әллә сирень сибелгән.

Сине күреп, һәммәсе дә, һәммәсе дә сөенгән, сөенгән,
Шатлыкларым әле дә сирень, әле дә сирень, сиреньнәр.

Яшим инде синең тавыш, синең сагыш, синең сүз, синең сүз,
Мөмкин түгел, ничек таныш, ничек кавыш сиреньсез?

Балкый хәтта үзеңнән соң, үзеңнән соң синең ямь, синең ямь,
Әллә инде, өзелгәнсең, өзелгәнсең сиреньнән?
```

# Перевод

### Сибгат Хәким / Нәҗип Җиһанов - Ты будто сорвана с сирени (второй вариант)

```
Неужели твои платки вышиты, вышиты,
Неужели на моём пути рассыпана сирень, сирень?

Увидев тебя, все, все радовались, радовались,
Мои радости и теперь — сирень, сирень, сирень.

Живу теперь твоим голосом, твоей тоской, твоим словом, твоим словом,
Невозможно: как познакомиться, как соединиться без сирени?

Даже после тебя сияет, после тебя, твоя красота, твоя красота,
Неужели ты сорвана, сорвана с сирени?
```
