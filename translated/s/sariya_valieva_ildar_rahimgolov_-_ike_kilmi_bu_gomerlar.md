# Оригинал

### Сәрия Вәлиева / Илдар Рәхимголов - Ике килми бу гомерләр

```
Әйдә дускай ал кулыңа
Моң сандыгы гармуның.
Уйна әйдә моңлы көйләр
Сиртеп күңел кылларын.

Ике килми бу гомерләр,
Кабынмый сүнгән йолдыз.
Бергә яшәү - бәйрам бит ул,
Үтмәсен гомер җырсыз.

Җырлык әле җан дусларым
Безнең яшьлек җырларын.
Санмыйкче вакытларны,
Үткән гомер елларын.

Ике килми бу гомерләр,
Кабынмый сүнгән йолдыз.
Бергә яшәү - бәйрам бит ул,
Үтмәсен гомер җырсыз.

Кошлар яши гел сайрашып,
Кош телендә серләшеп.
Җырларга тиң бу тормышта
Яшикче бергәләшеп.

Ике килми бу гомерләр,
Кабынмый сүнгән йолдыз.
Бергә яшәү - бәйрам бит ул,
Үтмәсен гомер җырсыз.
```

# Перевод

### Сария Валиева / Ильдар Рахимгулов - Эти жизни не слишком долги

```
Давай, дружочек, в руки свои
Гармонь - ларец тоски - возьми.
Играй же тоскливые напевы,
Касаясь струн души.

Не даётся дважды эта жизнь,
Не разгорится погасшая звезда.
Жить вместе - праздник ведь,
Пусть не пройдёт жизнь без песен.

Споём же, друзья души,
Наши песни юности.
Не будем считать время,
Прошедшие годы жизни.

Не даётся дважды эта жизнь,
Не разгорится погасшая звезда.
Жить вместе - праздник ведь,
Пусть не пройдёт жизнь без песен.

Птицы живут, всегда напевая,
На птичьем языке тайны деля.
В этой жизни, подобной песне,
Давайте же жить вместе, дружно.

Не даётся дважды эта жизнь,
Не разгорится погасшая звезда.
Жить вместе - праздник ведь,
Пусть не пройдёт жизнь без песен.
```
