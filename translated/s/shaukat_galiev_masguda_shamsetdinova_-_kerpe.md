# Оригинал

### Шәүкәт Галиев / Мәсгудә Шәмсетдинова - Керпе

```
Ай, һай керпе генәсе,
Уктай үткен энәсе.
Хәтта фил дә җиңелә,
Күрде исә - чигенә.
```

# Перевод

### Шаукат Галиев / Мәсгудә Шәмсетдинова - Ёжик

```
Ай, ой, ёжик же малютка,
Игла его остра, как стрела.
Даже слон - и тот сдаётся,
Лишь увидит - отступает.
```
