# Оригинал

### Шәриф Биккол / Сара Садыкова - Мин табынган күзләр

```
Хыялымда мин табынган күзләр
Көтмәгәндә генә табылды.
Моңа чаклы урап-урап үткән
Юлларыбыз килеп тап булды.

Инде хәзер мәңге әрнер өчен
Күңелемне яра каплады.
Таш эретер көчле сөю утым
Синең йөрәгеңә капмады.

Төшләремә кереп тетрәтмәсен
Хәтерләтеп яшен яшьнәвен.
Үзе газап, үзе бәхет миңа
Бу дөньяда синең яшәвең!

Инде хәзер мәңге әрнер өчен
Күңелемне яра каплады.
Таш эретер көчле сөю утым
Синең йөрәгеңә капмады.
```

# Перевод

```
Глаза, которым я поклонялся в мечтах,
Вдруг неожиданно нашлись.
Наши пути, что раньше кругами
Проходили мимо, вдруг сошлись.

Теперь навеки, то ли вслед боли
Душа моя вся покрылась ранами.
Пламя любви, что камень плавит,
В твоё сердце не попало.

Пусть не проникают в сны мои,
Напоминая о вспышке молнии.
Само мучение, само счастье для меня
Твоя жизнь на этом свете!

Теперь навеки, то ли вслед боли
Душа моя вся покрылась ранами.
```
