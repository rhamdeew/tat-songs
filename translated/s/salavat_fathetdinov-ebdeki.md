# Оригинал

### Салават Фатхетдинов - Эбдеки

```
Яз житкэч, туган ягыма
Кайтам коштай талпынып.
Эбдекигэ, кул буена,
Сабантуйга сагынып.

Эбдеки — Карабиккол
Арасында юллар тар.
Шул юллардан ерак тугел
Сабантуй мэйданы бар.

Шаян жиллэр, житкерегез
Авылыма кайтуымны.
Энкэем, туганнарымны,
Авылымны сагынуымны.

Эбдеки — Карабиккол
Арасында юллар тар.
Шул юллардан ерак тугел
Сабантуй мэйданы бар.

Кул буенда, шул болында
Яшьлегем мизгеллэре.
Шуна рэхэт кабатлавы —
Эбдеки диюлэре.

Эбдеки — Карабиккол
Арасында юллар тар.
Шул юллардан ерак тугел
Сабантуй мэйданы бар.
```

# Перевод

### Салават Фатхетдинов - Эбдеки

```
Когда весна приходит, в родные края
Возвращаюсь, как птица, устремляясь.
В Эбдеки, к берегу реки,
По Сабантую тоскуя.

Эбдеки — Карабиккол,
Между ними дороги узки.
По тем дорогам недалеко
Сабантуйское поле.

Шаловливые ветры, донесите
В деревню мою возвращение,
Моей матери, моим родным —
Мою тоску по родной деревне.

Эбдеки — Карабиккол,
Между ними дороги узки.
По тем дорогам недалеко
Сабантуйское поле.

У реки, на том лугу
Мгновения моей юности.
Так приятно повторять
Эти слова — «Эбдеки».

Эбдеки — Карабиккол,
Между ними дороги узки.
По тем дорогам недалеко
Сабантуйское поле.
```
