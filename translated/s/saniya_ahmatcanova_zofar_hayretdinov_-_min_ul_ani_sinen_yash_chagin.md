# Оригинал

### Сания Әхмәтҗанова / Зөфәр Хәйретдинов - Мин ул, әни, синең яшь чагың

```
Әниемнең ал күлмәген киеп,
Бөтереләм көзге каршында.
Нинди хатирәләр саклыйсың син?
Сер булмаса, сөйлә барсын да.

Сабыем, дип, һаман эндәшсәң дә,
Үсте инде нәни кошчыгың.
Гомер уза, диеп уфтанмале,
Мин ул, әни, синең яшь чагың.

Бала итәкле алсу күлмәгеңне
Бәйрәмнәрдә алып кидеңме?
Талчыбыктай нәзек билләреңә
Ак алъяпкыч бәйләп йөрдеңме?

Сабыем, дип, һаман эндәшсәң дә,
Үсте инде нәни кошчыгың.
Гомер уза, диеп уфтанмале,
Мин ул, әни, синең яшь чагың.

Күлмәкләрнең киям затлыларын:
Йә кыскасын, яки озынын.
Тик әнкәмнең алсу күлмәгеннән
Урам әйләнергә кызыгам.

Сабыем, дип, һаман эндәшсәң дә,
Үсте инде нәни кошчыгың.
Гомер уза, диеп уфтанмале,
Мин ул, әни, синең яшь чагың.
```

# Перевод

### Сания Әхмәтҗанова / Зуфар Хайретдинов - Я был тобой, мама, в твоём детстве

```
Надев мамино алое платье,
Кружусь перед зеркалом.
Какие воспоминания ты хранишь?
Если не секрет, расскажи всё.

Пусть ты всё ещё зовёшь меня малышкой,
Твоя маленькая птичка уже выросла.
Не вздыхай, говоря, что жизнь проходит,
Я, мама, — твоя юность.

Своё розовое платье с оборчатым подолом
Надевала ли ты по праздникам?
На стан, тонкий, словно ивовый прутик,
Повязывала ли белый передник?

Пусть ты всё ещё зовёшь меня малышкой,
Твоя маленькая птичка уже выросла.
Не вздыхай, говоря, что жизнь проходит,
Я, мама, — твоя юность.

Я ношу самые нарядные платья:
То короткие, то длинные.
Но мне так хочется пройтись по улице
В розовом платье моей мамы.

Пусть ты всё ещё зовёшь меня малышкой,
Твоя маленькая птичка уже выросла.
Не вздыхай, говоря, что жизнь проходит,
Я, мама, — твоя юность.
```
