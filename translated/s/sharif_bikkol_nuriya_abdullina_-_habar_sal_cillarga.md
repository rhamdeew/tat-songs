# Оригинал

### Шәриф Биккол / Нурия Абдуллина - Хәбәр сал җилләргә

```
Сагынсаң, саргайсаң, / Кагылсаң, сугылсаң, /
Хәбәр сал җилләргә.
Мин килеп җитәрмен
Син көткән җирләргә.

Сагынсаң, буталсаң, / Сагынсаң, саргайсаң, /
Хәбәр сал җилләргә.
Ерак дип тормамын,
Китәрмен чүлләргә.

Көенсәң, сөенсәң,
Хәбәр сал җилләргә.
Мин алып кайтырмын
Зар иткән илләргә.

Чит-яттан сөелсәң,
Зинһар, дим, белгертмә.
Мин калган тарафка
Җилләрне йөгертмә.
```

# Перевод

### Шариф Биккол / Нурия Абдуллина - Передай весть ветрам

```
Если скучаешь, желтеешь, / Если тебя бьёт и бросает,
Передай весть ветрам.
Я приду
В места, где ты меня ждёшь.

Если скучаешь, теряешься, / Если скучаешь, желтеешь,
Передай весть ветрам.
Не остановит меня даль,
Я отправлюсь в пустыни.

Если печалишься, если радуешься,
Передай весть ветрам.
Я принесу тебя обратно
В края, по которым ты тоскуешь.

Если полюбишь чужого,
Прошу, не выдавай этого.
Не гони ветры
В ту сторону, где остался я.
```
