# Оригинал

### Сәйфи Кудаш / Мөфтәдин Гыйләҗев - Куштирәк

```
Дим ярында моңсу гына
Үсә куштирәккәем.
Куштирәк янында көтә
Сине яшь йөрәккәем.

Куштирәк янында икәү
Тагын күрешсәк иде,
Аерылмаска бар гомергә,
Вәгьдә бирешсәк иде.

Әкрен искән җилгә кушылып
Шаулый куштирәккәем.
Сине сагынып ут эчендә
Кайный яшь йөрәккәем.

Шаула, шаула, бер туктамый,
Шаула, куштирәккәем.
Белсен ул сагынып көткәнне
Минем яшь йөрәккәем.
```

# Перевод

### Сәйфи Кудаш / Мөфтәдин Гильяҗев - Цветочек

```
На берегу Дима так тоскливо
Растёт мой тополёк.
Рядом с тополем ждёт
Тебя моё юное сердце.

Если бы рядом с тополем
Мы ещё встретились опять,
Чтобы не расстаться вовек,
Могли бы мы друг другу клясться.

Сливаясь с тихим ветром,
Шумит мой тополёк.
Без тебя, как в огне,
Горит моё сердце.

Шелести, шелести, не умолкая,
Шелести, тополёк мой.
Пусть знает, что жду и скучаю,
Моё юное сердце.
```
