# Оригинал

### Салават Рәхмәтулла / Рамил Гыймрани - Үзем генә белгән юл белән

```
Үзем генә белгән юллар белән
Төшләремә кереп керәсең.
Сиңа гына сөйләр сүзләрем (серләрем) бар,
Бар әле, бар сине күрәсем.

Яннарыма кил син төшләремдә,
Җырларыма килгән юл белән.
Килми калсаң, үзем барырмын мин
Үзем генә белгән юл белән.

Үзем генә белгән юллар белән
Җырларыма килеп керәсең.
Сиңа гына бирер вәгъдәм бар,
Бар әле, бар сине күрәсем.

Яннарыма кил син төшләремдә,
Җырларыма килгән юл белән.
Килми калсаң, үзем барырмын мин
Үзем генә белгән юл белән.
```

# Перевод

### Салават Рәхмәтулла / Рамил Гыймрани - По дороге, что знаю лишь я

```
По дорогам, которые знаю лишь я,
Ты входишь в мои сны.
Есть слова (тайны), которые я скажу только тебе,
Я всё ещё хочу тебя увидеть.

Приди ко мне в моих снах
Дорогой, пришедшей в мои песни.
Если не придёшь, я сам приду
По дороге, которую знаю лишь я.

По дорогам, которые знаю лишь я,
Ты входишь в мои песни.
Есть обещание, которое я дам только тебе,
Я всё ещё хочу тебя увидеть.

Приди ко мне в моих снах
Дорогой, пришедшей в мои песни.
Если не придёшь, я сам приду
По дороге, которую знаю лишь я.
```
