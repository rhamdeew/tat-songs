# Оригинал

### Сафуан Әлибай / Рим Хәсәнов - Тамчы тама (беренче вариант)

```
Яз турында көй чыгарып,
Тагы тамды тамчылар.
Әллә шатлык яше булып,
Күзләремнән тамдылар.

Чутылдашып тамчы тама,
Чиртеп көмеш кылларын,
Язны гына сагындырып
Әйләнәләр елларым.

Җырлый - җырлый тамчы тамса,
Җирдә гөлләр уяныр,
Сөймәсләр дә сөяр язда,
Уйланмаслар - уйланыр.

Чутылдашып тамчы тама,
Чиртеп көмеш кылларын,
Язны гына сагындырып
Әйләнәләр елларым.

Күңелемә тамчы белән
Язым нурлар яудырсын,
Гашыйк итеп, язлар тагы,
Акыллардан яздырсын.

Чутылдашып тамчы тама,
Чиртеп көмеш кылларын,
Язны гына сагындырып
Әйләнәләр елларым.
```

# Перевод

### Сафуан Алибай / Рим Хасанов - Тамчы Тама (Первый вариант)

```
Выводя мелодию о весне,
Снова закапали капли.
Не слезами ли радости
Они упали из моих глаз?

С перестуком падают капли,
Трогая серебряные струны,
Кружатся мои годы,
Заставляя тосковать лишь по весне.

Если капли падают, напевая,
На земле проснутся цветы,
Весной полюбят даже те, кто не любит,
Задумаются те, кто не задумывался.

С перестуком падают капли,
Трогая серебряные струны,
Кружатся мои годы,
Заставляя тосковать лишь по весне.

Пусть вместе с каплями моя весна
Прольёт лучи в мою душу,
Пусть весна, снова влюбив,
Заставит потерять рассудок.

С перестуком падают капли,
Трогая серебряные струны,
Кружатся мои годы,
Заставляя тосковать лишь по весне.
```
