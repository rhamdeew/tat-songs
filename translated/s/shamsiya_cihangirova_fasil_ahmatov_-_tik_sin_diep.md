# Оригинал

### Шәмсия Җиһангирова / Фасил Әхмәтов - Тик син диеп

```
Тик син диеп,
Янып-көеп,
Үтә лә гомерләрем;
Үткән гомеремне уйлап,
Ярсына күңелләрем.

Тик син диеп
Өзгәләнәм,
Уйланам иртә-кичен;
Ике гомер яшәсәм дә
Янармын синең өчен.

Тик син диеп,
Янып-көеп,
Үтмәс лә гомерләрем -
Очрашырбыз, кавышырбыз,
Ышана күңелләрем.
```

# Перевод

### Шамиля Джихангирова / Фасил Ахматов - Только ты

```
Лишь о тебе,
Горя и страдая,
Проходит моя жизнь;
Думая о прожитой жизни,
Волнуется моя душа.

Лишь о тебе
Я изнываю,
Думаю с утра до вечера;
Даже если проживу две жизни,
Буду гореть ради тебя.

Лишь о тебе,
Горя и страдая,
Не пройдёт моя жизнь —
Мы встретимся, соединимся,
Верит моя душа.
```
