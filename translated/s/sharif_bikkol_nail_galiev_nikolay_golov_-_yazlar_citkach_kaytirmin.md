# Оригинал

### Шәриф Биккол / Наил Галиев (Николай Голов) - Язлар җиткәч кайтырмын

```
Язлар җиткәч, кайтырмын
Кошлар кебек (булып) талпынып;
Басылмасмы йөрәгемдә
Сагыш ялкыны?

Ак каеннар каршылар
Юлларымда тезелеп.
Сагындым, авылым,
Сине өзелеп!

Язлар җиткәч, кайтырмын
Узып җитез җилләрне;
Күргем килә яшьлек эзем
Калган җирләрне.

Былбыл моңын тыңлармын
Таң атканда сызылып.
Сагындым, авылым,
Сине өзелеп!

Язлар җиткәч, кайтырмын
Ташкын булып ашкынып (атлыгып, талпынып);
Ташкыннарга тиндәш булыр
Йөрәк ялкыным (Минем шатлыгым).

Салкын чишмә суларын
Эчәрмен мин иелеп.
Сагындым, авылым,
Сине өзелеп!
```

# Перевод

### Шәриф Биккол / Наил Галиев (Николай Голов) - Когда придет весна, вернусь

```
Когда придёт весна, вернусь,
Как птица, крыльями трепеща;
Не утихнет ли в моём сердце
Пламя тоски?

Белые берёзы встретят,
Выстроившись вдоль моих дорог.
Скучаю, деревенька,
По тебе нестерпимо!

Когда придёт весна, вернусь,
Опережая быстрые ветры;
Хочу увидеть места,
Где остался след моей юности.

Буду слушать соловьиный напев,
Когда заря начнёт разгораться.
Скучаю, деревенька,
По тебе нестерпимо!

Когда придёт весна, вернусь,
Стремясь, словно поток;
Пламя моего сердца
Будет подобно разливу.

Я выпью холодной родниковой воды,
Склонившись.
Скучаю, деревенька,
По тебе нестерпимо!
```
