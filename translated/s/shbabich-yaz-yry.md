# Оригинал

### Ш.Бабич / Рафикъ Сәлмәнов - ЯЗ ҖЫРЫ

```
Яфрак яра чуклы каен

Татлы исен сибеп.

Бөреләрен ачты гөлләр

Язгы тынны сизеп.
Кушымта:
Яз, яз килә

Илгә, дуслар.

Мактап язны,

Котлап безне

Сайрарлар кошлар.
Чәчәк атты туган ягым,

Яшәрделәр кырлар.

Якты кояш чәчә нурын,

Шаулый дәртле җырлар
Кушымта.
Гөрләп илем каршы ала

Хезмәт белән көнне.

Алга, данлы яшьлек, алга,

Иҗат көтә безне!
Кушымта.
```

# Перевод

### Ш.Бабич / Рафикъ Сэлмэнов - Песня весны

```
Кудрявая берёза распускает листья,

Источая сладкий аромат.

Цветы раскрыли свои бутоны,

Почувствовав весеннее дыхание.
Припев:
Весна, весна приходит

В страну, друзья.

Восхваляя весну,

Поздравляя нас,

Будут петь птицы.
Расцвёл мой родной край,

Зазеленели поля.

Яркое солнце рассыпает лучи,

Звучат задорные песни.
Припев.
С гулом мой край встречает

День трудом.

Вперёд, славная юность, вперёд,

Нас ждёт творчество!
Припев.
```
