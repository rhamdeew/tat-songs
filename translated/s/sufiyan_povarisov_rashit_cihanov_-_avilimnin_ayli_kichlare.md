# Оригинал

### Суфиян Поварисов / Рәшит Җиһанов - Авылымның айлы кичләре

```
Язгы моңнар чишмә кебек агыла,
Шаулап тора басу эшләре;
Нурлар бөркеп кырдан каршы ала
Авылымның айлы кичләре.

Урамнарда тәмле булып аңкый
Яңа пешкән икмәк исләре.
Иркәләнә гармун моңнарында
Авылымның айлы кичләре.

Синдә күңелем, уем, тойгыларым,
Йөрәгемнең кайнар хисләре.
Чатнап торган салкында да матур
Авылымның айлы кичләре.
```

# Перевод

### Суфиян Поварисов / Рашит Джиханов - Лунные вечера моего села

```
Весенние напевы струятся, как родник,
Кипит работа в полях;
Рассыпая лучи, с полей встречают меня
Лунные вечера моего села.

На улицах сладко разливается
Аромат свежеиспечённого хлеба.
Нежатся в напевах гармони
Лунные вечера моего села.

В тебе моя душа, мысли, чувства мои,
Горячие чувства моего сердца.
Даже в трескучий мороз прекрасны
Лунные вечера моего села.
```
