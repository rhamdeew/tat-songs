# Оригинал

### Сәрия Мәһдиева / Әбүзәр Солтанов - Гармун моңнары (беренче вариант)

```
Күңелләрне тибрәндерә
Гармун моңнары:
Хәтерләтә үткәннәрне,
Яшьлек елларын.
Күз алдымда сине сагынып
Көтеп алганым,
Синең белән каршылаган
Алсу таңнарым.

Тәүге сөю хисләремне
Онытырлык түгел,
Өмет белән көтте һаман
Тынгысыз күңел.
Кайталмадың, калды бары
Таныш моңнарың.
Ялгызлыкта үтте инде
Гомер елларым.

Күңелләрне тибрәндерә
Гармун моңнары
Хәтерләтә үткәннәрне,
Яшьлек елларын.
Гармуныңны дустың уйный,
Әйдә, уйнасын.
Тик сөйгәне минем кебек
Ялгыз булмасын.
```

# Перевод

### Сәрия Мәһдиева / Әбүзәр Солтанов - Мелодии гармона (первый вариант)

```
Души приводят в трепет
Напевы гармони:
Напоминают о прошлом,
О годах юности.
Перед глазами — как я, тоскуя,
Дождалась тебя,
И встреченные с тобой
Мои алые рассветы.

Чувства первой любви
Невозможно забыть,
Всё ждало с надеждой
Беспокойное сердце.
Ты не вернулся, остались лишь
Твои знакомые напевы.
В одиночестве прошли уже
Годы моей жизни.

Души приводят в трепет
Напевы гармони:
Напоминают о прошлом,
О годах юности.
На твоей гармони играет друг —
Пусть играет.
Только пусть твоя любимая, как я,
Не будет одинока.
```
