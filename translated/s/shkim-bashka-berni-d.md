# Оригинал

### С.Хәким / М.Мозаффаров - БАШКА БЕРНИ ДӘ

```
Туып-үскән шушы җирнең ямен

Алыштырмый икән һич нәрсәң.
Башка берни дә кирәкми,

Үзем чапкан печәннәрне

Бер туйганчы иснәсәм.
Миңа гына шулай тоела микән

Бөтен рәхәтләре соң аның?
Башка берни дә кирәкми,

Үзем тапкан чишмәләрнең

Ятып эчсәм суларын.
Үрләре дә зәңгәр дулкын-дулкын,

Ул үрләрнең чиге кайда соң?
Башка берни дә кирәкми,

Дусларның мин гомрем буе

Тойсам җылы карашын.
```

# Перевод

### С.Хэким / М.Мозаффаров - Больше ничего не нужно

```
Прелесть этой земли, где я родился и вырос,

Ничто, оказывается, не заменит.
Больше ничего не нужно,

Только бы досыта надышаться

Скошенным мною сеном.
Может, мне одному так кажется,

Что во всём этом – его отрада?
Больше ничего не нужно,

Только бы, лёжа, напиться

Воды из найденных мною родников.
Возвышенности синеют волнами,

Где же край этих возвышенностей?
Больше ничего не нужно,

Только бы всю жизнь чувствовать

Тёплый взгляд друзей.
```
