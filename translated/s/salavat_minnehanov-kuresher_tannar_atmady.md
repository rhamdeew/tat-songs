# Оригинал

### Салават Миннеханов - Курешер таннар атмады

```
Ак мамыклар оча микэн
Аккошлар кагынганда.
Жаннарымны кая куйыйм
Назларын сагынганда.

Кул буйлары ямьле булмый
Аккошлар тезелмэсэ.
Мон булып тугелмэс идем
Узэгем озелмэсэ.

Кул ослэре тын гына,
Кунелем тулы мон гына.
Моннар тулы кунелемне
Анлый иде ул гына.

Кул буйлары ямьле булмый
Аккошлар тезелмэсэ.
Мон булып тугелмэс идем
Узэгем озелмэсэ.

Пар канатлар какмады,
Кулгэ аккош кайтмады,
Эрнер инде йорэккэем,
Курешер таннар атмады...

Кул буйлары ямьле булмый
Аккошлар тезелмэсэ.
Мон булып тугелмэс идем
Узэгем озелмэсэ.
```

# Перевод

### Салават Миннеханов - Не наступят встречи зори

```
Белый пух летит,
Когда лебеди взмахивают крыльями.
Куда мне деть свою душу,
Когда тоскую по её ласке?

Берега озера не прекрасны,
Если лебеди не выстроятся в ряд.
Не изливался бы я напевом,
Если бы нутро не разрывалось.

Поверхность озера тиха,
А душа полна лишь напева.
Только она понимала
Мою душу, полную напевов.

Берега озера не прекрасны,
Если лебеди не выстроятся в ряд.
Не изливался бы я напевом,
Если бы нутро не разрывалось.

Парные крылья не взмахнули,
Лебедь не вернулся к озеру.
Теперь будет болеть моё сердце:
Не занялись зори нашей встречи...

Берега озера не прекрасны,
Если лебеди не выстроятся в ряд.
Не изливался бы я напевом,
Если бы нутро не разрывалось.
```
