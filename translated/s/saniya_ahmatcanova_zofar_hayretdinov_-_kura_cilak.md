# Оригинал

### Сания Әхмәтҗанова / Зөфәр Хәйретдинов - Кура җиләк

```
Кура җиләк пешкәндер дип,
Чакырдың, урманнарга;
Икәү бергә күмелдек без
Хуш исле кураларга.

Коела инде куралар -
Җил үтте аралардан.
Ялгызым йөрим адашып,
Куралы аланнарда.

Җем-җем яна кура җиләк -
Җыймыйча булмый түзеп.
Уч тутырып кура җиләк
Ашаттың миңа өзеп.

Коела инде куралар -
Җил үтте аралардан.
Ялгызым йөрим адашып,
Куралы аланнарда.

Иреннәрдә җиләк тәме -
Моңаймый булмый түзеп.
Кура җиләк кабат пешәр,
Тик кем ашатыр өзеп?

Коела инде куралар -
Җил үтте аралардан.
Ялгызым йөрим адашып,
Куралы аланнарда.
```

# Перевод

### Сания Ахметзянова / Зуфар Хайретдинов - Земляника

```
Что созрела малина,
Ты позвала в леса;
Вдвоём мы скрылись в ароматных
Малинниках.

Опустели заросли -
Ветер прошёл меж ними.
Я один брожу потерянный
По полянам малины.

Ярко сверкает малина —
Нельзя, не собрав, утерпеть.
Нарвав полную горсть малины,
Ты кормила меня.

Опустели заросли -
Ветер прошёл меж ними.
Я один брожу потерянный
По полянам малины.

На губах вкус ягоды -
Невозможно сдержаться, чтобы не грустить.
Малина снова зреет,
Но кто сорвёт её и угостит меня?

Опустели заросли -
Ветер прошёл меж ними.
Я один брожу потерянный
По полянам малины.
```
