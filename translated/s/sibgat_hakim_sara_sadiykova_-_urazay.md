# Оригинал

### Сибгат Хәким / Сара Садыкова - Уразай

```
Үзәннәрнең яме синдә,
Бөтен зәңгәрлек синдә.
Нәрсә турында сөйлисең
Агыйдел белән Сөнгә?

Уразай, Уразай,
Ятсам төшләремә керә
Синдә булып узган җәй.

Карыйсың ярлардан ерак,
Борынгы агым суга.
Сокланам синең бүгенге
Бәхетле язмышыңа.

Уразай, Уразай,
Ятсам төшләремә керә
Синдә булып узган жәй.
```

# Перевод

### Сибгат Хаким / Сара Садыкова - Уразай

```
Красота долин — в тебе,
Вся синева — в тебе.
О чём ты рассказываешь
Агидели и Сюни?

Уразай, Уразай,
Когда ложусь, мне снится
Лето, проведённое с тобой.

Ты смотришь вдаль от берегов,
На древнее течение воды.
Я восхищаюсь твоей сегодняшней
Счастливой судьбой.

Уразай, Уразай,
Когда ложусь, мне снится
Лето, проведённое с тобой.
```
