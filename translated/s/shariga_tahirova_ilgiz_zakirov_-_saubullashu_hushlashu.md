# Оригинал

### Шәрига Таһирова / Илгиз Закиров - Саубуллашу (Хушлашу)

```
Томырылып, зәңгәр яулык изәп, поезд чаба,
Ялан тәпи йөгерә яшь (ак) каеннар миңа таба.
Барыр юлым иркен басу, кырлар аша үтә,
Алда мине янар учак булып өмет көтә.

Ыргый поезд, дулкынланып юллар атылып кала,
Туган илем, гүзәл җирем мине назлап бара.
Китми булмый, сукмакларым кырлар аша үтә,
Айлы кичтә янар учак булып өмет көтә.

Юл читендә ялгыз нарат кебек калдың басып,
Кайтыр өчен китеп барам синнән, саубуллашып.
Юллар көтә мине, җырлар (дуслар) көтә, шуңа китәм,
Аерылу синнән (иркәм) бигрәк авыр, авыр икән.
```

# Перевод

### Шәрига Таһирова / Илгиз Закиров - Прощание (Расставание)

```
Клубясь дымком, взмахивая голубым платком, мчится поезд,
Молодые белые берёзки, босоногие, бегут ко мне навстречу.
Мой путь пролегает через просторные луга и поля,
Впереди меня, как горящий костёр, ждёт надежда.

Мчится поезд, волнуясь, дороги мелькают позади,
Родной мой край, прекрасная земля ласкает меня.
Нельзя не уехать, мои тропинки ведут через поля,
В лунную ночь, как горящий костёр, ждёт надежда.

На краю дороги ты стоишь, как одинокая сосна,
Ухожу я от тебя, чтобы вернуться, прощаясь.
Дороги ждут меня, песни ждут, потому уезжаю,
Расставаться с тобой, любимая, так тяжко, так тяжело.
```
