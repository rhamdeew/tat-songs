# Оригинал

### С.Мәһәдиева / Ә.Солтанов - ГАРМУН МОҢНАРЫ

```
Күңелләрне тибрәндерә

Гармун моңнары:

Хәтерләтә үткәннәрне,

Яшьлек елларын.

Күз алдымда сине сагынып

Көтеп алганым,

Синең белән каршылаган

Алсу таңнарым.
Тәүге сөю хисләремне

Онытырлык түгел,

Өмет белән көтте һаман

Тынгысыз күңел.

Кайталмадың, калды бары

Таныш моңнарың.

Ялгызлыкта үтте инде

Гомер елларым.
Күңелләрне тибрәндерә

Гармун моңнары:

Хәтерләтә үткәннәрне,

Яшьлек елларын.

Гармуныңны дустың уйный,

Әйдә, уйнасын.

Тик сөйгәне минем кебек

Ялгыз булмасын.
```

# Перевод

### С.Мэхэдиева / Э.Солтанов - Мелодии гармони

```
Волнуют душу
Напевы гармони:
Напоминают о прошлом,
О годах юности.

Перед глазами встаёт, как я,
Тоскуя, ждала тебя,
Как встречала с тобой
Мои румяные рассветы.

Чувства первой любви моей
Забыть невозможно,
С надеждой всё ждала
Беспокойная душа.

Не вернулся ты, осталось лишь
Знакомое звучание твоей гармони.
В одиночестве прошли уже
Годы моей жизни.

Волнуют душу
Напевы гармони:
Напоминают о прошлом,
О годах юности.

На гармони твоей играет друг,
Пусть играет, пусть.
Только пусть его любимая, как я,
Не останется одинокой.
```
