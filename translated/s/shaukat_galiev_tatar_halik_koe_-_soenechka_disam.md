# Оригинал

### Шәүкәт Галиев / Татар халык көе - Сөенечкә дисәм

```
Кар сулары бетте.
Ярсулары үтте,
Ташлар тәгәрәми ташкында:
Минем генә йөрәк,
Сагынудан йөдәп,
Бәйгедәге аттай ашкына

Аерым торып еллар,
Аймыл булып юллар,
Нигә синнән читтә узган соң?
Бар шул инде парың,
Янып сөйгән ярың,
Кулларыңны аңа сузгансын

Арта уйлар һаман.
Тарта сиңа табан.
Кыен мина ялгыз чакларда,
Сөенечкә дисәм,
Көенечкә икән
Күрешүләр сезнен якларда
```

# Перевод

### Шаукат Галиев / Татарская народная песня - Скучая по тебе

```
Растаяли снежные воды.
Протекли ручьи,
Камни не катятся в наводнении:
Только моё сердце,
Горя от тоски,
Бежит как лошадь в скачке

Отдельно стоят годы,
Дороги становятся тусклыми,
Почему прошёл мимо тебя?
Есть уже пара твоя,
Пылко любимый твой избранник,
Ты протянула к нему свои руки

Мысли всё растут.
Тянет к тебе.
Тяжело мне в эти одинокие времена,
Если сказать - к радости,
А выходит - к горю,
Наши встречи в ваших краях
```
