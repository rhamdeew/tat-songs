# Оригинал

### Сибгат Хәким / Хөснул Вәлиуллин - Иртәнге сихерле юллар

```
Иртәнге сихерле юллар,
Тик юллар юанычым,
Барам, табармын шикелле
Сузылган юллар очын.

Әйтсеннәр күргән-белгәннәр;
Хыялый, дивана дип,
Гомрен юлларда үткәрә,
Юлларда юана дип.

Алдымнан минем юлларга
Сыялмый үтте юллар,
Хыяллар якты булганга,
Хыялый итте еллар.

Иртәнге сихерле юллар,
Тик юллар юанычым,
Барам, табармын шикелле
Узылган юллар очын.
```

# Перевод

### Сибгат Хаким / Хуснул Валиуллин - Утренние волшебные дороги

```
Утренние дороги волшебные,
Только дороги - утешение моё,
Иду, словно найду
Растянутых дорог конец.

Пусть скажут видевшие-знавшие;
Мечтатель, безумец - мол,
Жизнь проводит на дорогах,
На дорогах утешается - мол.

Передо мной, в мои дороги
Не вмещаясь, прошли дороги,
Мечты светлыми были,
Годы сделали мечтателем.

Утренние дороги волшебные,
Только дороги - утешение моё,
Иду, словно найду
Пройденных дорог конец.
```
