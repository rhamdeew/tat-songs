# Оригинал

### Шәмсия Җиһангирова / Рафаэль Билалов - Аерылабыз инде, бәгърем

```
Аерылабыз инде, бәгърем,
Сөелеп туймас чакта.-
Кошларның да канатлары
Икесе ике якта.

Әйтер сүзләрем күп калды,
Аерылырбыз димәдем.
- Назым туя назламадым, назламадым,
Җаным туя сөймәдем.

Күрешербез дип уйладым,
Мәңгегә дип китмәдем.
- Күзләрем туя күрмәдем.
Иренем туя үпмәдем.

Атлар үтәр араларны
Йөгереп кенә үтәрмен.
Җаным туя сөяр өчен, сөяр өчен
Үземнеке итәрмен.
```

# Перевод

### Шәмсия Җиһангирова / Рафаэль Билалов - Расстаемся мы, любимый

```
Расстаёмся мы, любимый,
Когда не успели насытиться любовью.
Даже у птицы два крыла
Находятся по разные стороны.

Так много слов осталось несказанными,
Я не думала, что мы расстанемся.
Не успела вдоволь тебя приласкать,
Не успела вдоволь тебя любить.

Я думала, мы ещё увидимся,
Не уходила навсегда.
Не успела вдоволь насмотреться,
Не успела вдоволь нацеловать тебя.

Расстояния, которые проходят кони,
Я преодолею бегом.
Чтобы любить тебя вдоволь,
Я сделаю тебя своим.
```
