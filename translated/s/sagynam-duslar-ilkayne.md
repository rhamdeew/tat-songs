# Оригинал

### Татар халык җыры - САГЫНАМ, ДУСЛАР, ИЛКӘЙНЕ

```
Сагынам, дуслар, сагынам, дуслар,

Сагынам туган илкәйне, шул,

Сагынам туган илкәйне.

Илкәй белән бергә сагынам

Яшьли сөйгән яркәйне.

Баш куям тезләреңә лә,

Яшь коям эзләреңә, шул,

Яшь коям эзләреңә.

Әллә ниләр бирер идем

”Аһ” дигән сүзләреңә.

Агасың Иделкәем лә,

Биек ярларың белән, шул,

Биек ярларың белән.

Каласың, туган илкәем

Сөйгән ярларым белән.
```

# Перевод

### Татарская народная песня - Скучаю, друзья, по родному краю

```
Тоскую, друзья, тоскую, друзья,
Тоскую по родной земле,
Тоскую по родной земле.

Вместе с родной землёй тоскую
По любимой, что полюбил смолоду.

Кладу голову на твои колени,
Лью слёзы на твои следы,
Лью слёзы на твои следы.

Многое бы отдал
За твои слова «ах».

Течёшь ты, моя родная Идель,
Со своими высокими берегами,
Со своими высокими берегами.

Остаёшься ты, родная моя земля,
С моими любимыми.
```
