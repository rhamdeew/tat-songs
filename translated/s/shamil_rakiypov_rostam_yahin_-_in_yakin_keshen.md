# Оригинал

### Шамил Рәкыйпов / Рөстәм Яхин - Иң якын кешең

```
Энҗедәй карлар бөдрәләреңә,
керфекләреңә,
иреннәреңә
килеп кунганда,
Исеңә төшер, кайдадыр читтә,
шушы мизгелдә
сине сагына
иң якын кешең.

Көмеш тамчылар бөдрәләреңне,
керфекләреңне,
иреннәреңне
килеп үпкәндә,
исеңә төшер, кайдадыр читтә,
шушы мизгелдә
сине юксына
иң сабыр кешең.

Тылсымлы җилләр бөдрәләреңне,
керфекләреңне,
иреннәреңне
иркәләгәндә,
Исеңә төшер, кайдадыр читтә,
шушы мизгелдә
син дип тилмерә
иң тугры кешең ...
```

# Перевод

### Шамил Рәкыйпов / Рөстәм Яхин - Твой самый близкий человек

```
Когда жемчужные снежинки
Опускаются на твои кудри,
На ресницы,
На губы,
Вспомни: где-то вдали,
В этот самый миг,
По тебе тоскует
Твой самый близкий человек.

Когда серебряные капли
Касаются твоих кудрей,
Твоих ресниц,
Твоих губ,
Вспомни: где-то вдали,
В этот самый миг,
По тебе скучает
Твой самый терпеливый человек.

Когда волшебные ветры
Ласкают твои кудри,
Твои ресницы,
Твои губы,
Вспомни: где-то вдали,
В этот самый миг,
По тебе изнывает
Твой самый верный человек...
```
