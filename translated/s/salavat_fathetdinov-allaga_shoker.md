# Оригинал

### Салават Фатхетдинов - Аллага шокер

```
Бер максатсыз, гел далага
Узмасын гомер.
Исэнмесез, яшибез без,
Аллага шокер!

Кайгы белэн, шатлык белэн
Уза бу гомер.
Без бит бергэ, шунсы шатлык,
Аллага шокер!

Алла бирсэ, жырларбыз без,
Узганчы гомер.
Исэнмесез, жырлыйбыз без,
Аллага шокер!
```

# Перевод

### Салават Фатхетдинов - Благодарность Аллаху

```
Пусть жизнь не проходит
Бесцельно и впустую.
Здравствуйте, мы живём,
Хвала Аллаху!

С горем и с радостью
Проходит эта жизнь.
Мы ведь вместе — вот радость,
Хвала Аллаху!

Если Аллах даст, будем петь,
Пока не пройдёт жизнь.
Здравствуйте, мы поём,
Хвала Аллаху!
```
