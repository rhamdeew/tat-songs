# Оригинал

### Шаһивилдан Идрисов / Венер Мөхәммәдиев - Уйларым - Уйларым - Уйларым - хыялларым

```
Еллар аша кире кайтам,
Туган туксаннан узам.
Яңа пешкән икмәк исен
Тагы тойгандай булам.

Әнкәемнең елмаюын
Тагы күргәндәй булам.
Тупылдатып яратуын
Аркамда тоям һаман.

Балачакка кайтарсаң да,
Күкләргә күтәрсәң дә.
Туган җирдән аермагыз
Уйларым - хыялларым.
```

# Перевод

### Шаһивилдан Идрисов / Венер Мухаммадиев - Мои мысли - Мои мысли - Мои мысли - мои мечты

```
Через годы возвращаюсь,
Перехожу родной порог.
Мне снова кажется, что чувствую
Запах свежеиспечённого хлеба.

Мне снова кажется, что вижу
Улыбку моей матери.
Её любовь, с которой она хлопала меня по спине,
Я до сих пор ощущаю.

Верните ли меня в детство,
Поднимите ли к небесам —
Не отделяйте от родной земли
Мои мысли, мои мечты.
```
