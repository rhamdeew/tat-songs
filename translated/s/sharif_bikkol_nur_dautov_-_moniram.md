# Оригинал

### Шәриф Биккол / Нур Даутов - Мөнирәм

```
Яшьлегемә ямь бирә
Җан бизәгем, Мөнирәм.
Бер көн генә торми торсам
Саргаерга өлгерәм.
Әй, сыулым, Мөнирәм!
Кочак-кочак гөл бирәм.
Күзләремә бер кара син
Назларыңа тилмерәм.

Мөнирәм, Мөнирәм,
Җан бизәгем, Мөнирәм!
Мөнирәм, Мөнирәм,
Яшьлегемә ямь бирә.

Яшәүемә җан бирә
Җан үзәгем, Мөнирәм.
Сабырлыгым җуела да
Яннарыңа йөгерәм.
Әй, сыулуым, Мөнирәм!
Кочак-кочак гөл бирәм.
Күзләремә бер кара син
Назларыңа тилмерәм.

Мөнирәм, Мөнирәм,
Җан үзәгем, Мөнирәм!
Мөнирәм, Мөнирәм,
Яшәүемә җан бирә.

Җырларыма моң бирә
Җан гүзәлем, Мөнирәм.
Аны хыял күлләрендә
Гомер буе йөздерәм.
Әй, сыулуым, Мөнирәм!
Кочак-кочак гөл бирәм.
Күзләремә бер кара син
Назларыңа тилмерәм.

Мөнирәм, Мөнирәм,
Җан бизәгем, Мөнирәм!
Мөнирәм, Мөнирәм,
Җырларыма моң бирә.
```

# Перевод

### Шариф Биккол / Нур Даутов - Мунирам

```
Красу моей юности даришь,
Украшение души моей, Мунирам.
Стоит мне лишь день побыть без тебя,
Как я уже успеваю зачахнуть.
О, красавица моя, Мунирам!
Охапки цветов тебе дарю.
Только взгляни мне в глаза —
Я изнываю по твоей нежности.

Мунирам, Мунирам,
Украшение души моей, Мунирам!
Мунирам, Мунирам,
Красу моей юности даришь.

Жизнь мою одушевляешь,
Сердцевина души моей, Мунирам.
Терпение моё кончается,
И я бегу к тебе.
О, красавица моя, Мунирам!
Охапки цветов тебе дарю.
Только взгляни мне в глаза —
Я изнываю по твоей нежности.

Мунирам, Мунирам,
Сердцевина души моей, Мунирам!
Мунирам, Мунирам,
Жизнь мою одушевляешь.

Напев моим песням даришь,
Красавица души моей, Мунирам.
Его по озёрам мечты
Всю жизнь буду пускать плыть.
О, красавица моя, Мунирам!
Охапки цветов тебе дарю.
Только взгляни мне в глаза —
Я изнываю по твоей нежности.

Мунирам, Мунирам,
Украшение души моей, Мунирам!
Мунирам, Мунирам,
Напев моим песням даришь.
```
