# Оригинал

### Шәүкәт Галиев / Мәсгудә Шәмсетдинова - Нәни мәргән

```
Күземне кысып, тынымны тыеп,
Мылтык түтәсен иңемә куеп,
Куян чыкканны сагалап торам,
Атып егарга чамалап торам.

Чыкты ул, чапты, әнә ул, әнә!
Атуын аттым, тимәде янә...
Кургаш салдым да мылтыкны кордым,
Төлкегә табан көпшәне бордым.

Бәхет бер булса була бит инде -
Төлкегә дидем, бүрегә тиде!
Тирдагы абый мактады мине:
Үскәч шәп солдат булырсың, диде.
```

# Перевод

### Шаукат Галиев / Масгуда Шамсетдинова - Бабушка, плачь

```
Прищурив глаза, сдерживая дыханье,
Приклад ружья на плечо положив,
Жду, когда кролик выйдет из укрытья,
Целюсь, чтобы выстрелить уже пора.

Вышел, побежал, вот он, вот!
Выстрел, и снова мимо...
Пулю зарядил я, взвёл ружьё,
Повернул дуло в сторону лисы.

Если счастье одно, то пусть будет -
Метил в лису, а попал в волка!
Старший брат в восхищении от меня:
Вырастешь, будешь хорошим солдатом, сказал.
```
