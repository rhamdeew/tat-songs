# Оригинал

### Татар халык җыры - СУДА БАЛЫК ЙӨЗӘДЕР

```
Суда балык йөзәдер лә,

Балыкчыны сизәдер, ай, сизәдер.

Кушымта:

Әкрен кирәк,

Ипләп кирәк

Ишетергә, сандугач сайрауларын.

Авылыбызда бер матур бар,

Үзәгемне өзәдер, ай, өзәдер.

Кушымта.

Кара бөдрә чәчләре лә,

Шомарадыр тараса, ай, тараса.

Кушымта.

Ушларымны китәрәдер

Бер елмаеп караса, ай, караса.

Кушымта.
```

# Перевод

### Татарская народная песня - В воде, наверное, плавает рыба

```
В воде плавает рыба,
Чует рыбака, ай, чует.

Припев:
Тихо надо,
Осторожно надо,
Слушать пение соловья.

В нашей деревне есть одна красавица,
Терзает моё нутро, ай, терзает.

Припев.

Её чёрные кудрявые волосы
Разглаживаются, если расчесать, ай, расчесать.

Припев.

Уносит мой разум,
Если взглянет, улыбнувшись, ай, взглянет.

Припев.
```
