# Оригинал

### Шамил Маннапов / Сара Садыкова - Керфегеңә тамармын мин

```
Китмә дип күземә карыйсың
Күзләреңдә синең кара урман.
Күзләреңдә синең иген кыры,
Тавышыңда тургай моңы.

Күкрәгемдә типкән чишмә
Ашкындыра мине алга.
Акмый тора алмый чишмә
Еракларга, еракларга.

Бер кайтырмын әле күкрәп,
Яңгыр булып явармын мин;
Яңгыр тамчылары булып
Керфегеңә тамармын мин.
```

# Перевод

### Шамил Маннапов / Сара Садыкова - Каплями дождя на твои ресницы

```
Словно говоря «не уходи», глядишь ты мне в глаза,
В глазах твоих — тёмный лес.
В глазах твоих — хлебное поле,
В голосе твоём — напев жаворонка.

Родник, бьющий в моей груди,
Устремляет меня вперёд.
Не может родник не течь
В дальние, дальние края.

Однажды вернусь, громыхая,
Прольюсь дождём;
Каплями дождя
Упаду на твои ресницы.
```
