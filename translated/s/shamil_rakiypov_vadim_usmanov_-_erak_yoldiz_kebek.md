# Оригинал

### Шамил Рәкыйпов / Вадим Усманов - Ерак йолдыз кебек

```
Йолдызлары үзенә чакырып торган
Тын кичләрне күңелем юксына.
Мәхәббәтем минем,
Ерак йолдыз кебек,
Серле килеш калды шул сиңа...

Йолдызларны болытлар каплап китсә дә,
Йолдызым сүнде дип уйлама.
Мәхәббәтем минем,
Ерак йолдыз кебек,
Күренмичә генә гел яна!

Йолдыз атылгандай ашкынам мин сиңа,
Бер күрешү үзе бер гомер!
Мәхәббәтем минем,
Ерак йолдыз кебек,
Үзенә тартыр, бәгърем, барыбер!

Йолдызлардан сине эзлим, бәгърем, хәзер
Синсез минем юлларым хәтәр.
Мәхәббәтем минем,
Ерак йолдыз кебек,
Үзем сүнгәч тә әле нур чәчәр!
```

# Перевод

### Шамил Ракипов / Вадим Усманов - Как далёкая звезда

```
Сердце моё тоскует по тихим вечерам,
Когда звёзды манят к себе.
Любовь моя,
Как далёкая звезда,
Осталась для тебя загадкой...

Пусть даже облака закроют звёзды,
Не думай, что моя звезда погасла.
Любовь моя,
Как далёкая звезда,
Незримо горит всегда!

Как падающая звезда, я устремляюсь к тебе,
Одна встреча — сама целая жизнь!
Любовь моя,
Как далёкая звезда,
Всё равно притянет к себе, родная!

Среди звёзд ищу тебя теперь, родная,
Без тебя мои дороги опасны.
Любовь моя,
Как далёкая звезда,
Даже когда погасну я, всё ещё будет излучать свет!
```
