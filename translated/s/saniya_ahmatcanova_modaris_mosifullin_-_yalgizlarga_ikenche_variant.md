# Оригинал

### Сания Әхмәтҗанова / Мөдәрис Мөсифуллин - Ялгызларга (икенче вариант)

```
Бар ул, беләм, ялгыз моңланганнар,
Сагышларда ялгыз янганнар;
Яратканым - җаны теләгәнне
Көтеп-көтеп, ялгыз калганнар.

Азмы әллә үзе парлы булып,
Ялгызлыкта гомер иткәннәр!
Сез алардан күпкә бәхетлерәк,
Гомер буе тиңен көткәннәр.

Кызганмагыз, дисез, ник кызганыйм,
Бәхетле без, дисез, ышанам.
Сабырлыкка сезнең мин таң калам,
Горурлыкка сезнең сокланам.
```

# Перевод

### Сания Әхмәтҗанова / Мөдәрис Мөсифуллин - Одиноким (второй вариант)

```
Есть, я знаю, те, кто одиноко поёт с тоской,
Кто одиноко сгорает в печали;
Кто, ожидая и ожидая любимого,
Того, кого желала душа, остался один.

Разве мало тех, кто, имея пару,
Прожил жизнь в одиночестве!
Вы намного счастливее их —
Те, кто всю жизнь ждал себе равного.

«Не жалейте», — говорите. Зачем же мне жалеть?
«Мы счастливы», — говорите. Я верю.
Я поражаюсь вашему терпению,
Восхищаюсь вашей гордостью.
```
