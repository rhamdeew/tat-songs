# Оригинал

### Сания Әхмәтҗанова / Айдар Фәйзрахманов - Гөлбишек

```
Сайлап алып матур төсләр
Күңелем түрләреннән,
Үрим әле гүзәл бишек
Сөюем гөлләреннән.

Кушымта:
Тирбәлербез икәү бергә
Мәхәббәт бишегендә.
Мине сөю, бары сөю
Яшәтә яшьлегемдә.

Бәйләм-бәйләм гөлләр китер,
Үрелсен хисләребез.
Аллы-гөлле хыялларга
Күмелсен кичләребез.

Кушымта:
Тирбәлербез икәү бергә
Мәхәббәт бишегендә.
Мине сөю, бары сөю
Яшәтә яшьлегемдә.

Берәүгә дә бирмим сине,
Тапмадым югалтырга.
Ирек куймам икәү үргән
Хисләрне чуалтырга.

Кушымта:
Тирбәлербез икәү бергә
Мәхәббәт бишегендә.
Мине сөю, бары сөю
Яшәтә яшьлегемдә.
```

# Перевод

### Сания Әхмәтҗанова / Айдар Фәйзрахманов - Колыбель цветов

```
Выбирая прекрасные краски
Из глубин моей души,
Я ещё сплету прекрасную колыбель
Из цветов моей любви.

Припев:
Будем вдвоём качаться
В колыбели любви.
Любовь ко мне, одна лишь любовь
Сохраняет мою юность.

Принеси цветы пучок за пучком,
Пусть сплетутся наши чувства.
Пусть наши вечера
Погрузятся в пёстрые мечты.

В колыбели любви.

Никому тебя не отдам,
Я нашла тебя не для того, чтобы потерять.
Не позволю запутать
Чувства, сплетённые нами вдвоём.
```
