# Оригинал

### Шәриф Биккол / Ризван Хәкимов - Бозма вәгъдәләреңне

```
Сөюләрем көчле,
Һәтәр яшен төсле,
Сак бул, син, ут белән уйнама!
Вәгъдәләрең бозсаң,
Ятларга кул сузсаң,
«Гафү итәр бу!» - дип уйлама.

«Тиң, түгел бит, ул, - дип, -
Миңа гына булл!» - дип,
Хатлар язып сине юл чыкмам,
Төнең тәрәз чиртеп,
«Күрим әле бер!» - дип,
Чакырырсың,
Ә мин, мин чыкмам.
Төнең тәрәз чиртеп,
«Күрим әле бер!» - дип,
Чакырырсың,
Ә мин, мин чыкмам.

Мен газапка түзеп,
Мине дөнья гизеп,
Эзләрсең син,
Ә мин табылмам,
Мин табылмам көтмә,
Синең өчен күктә,
Балкыр йолдыз булып кабынмам.
Мин табылмам көтмә,
Синең өчен күктә,
Балкыр йолдыз булып кабынмам.
```

# Перевод

### Шариф Биккол / Ризван Хәкимов - Не нарушай своих обещаний

```
Моя любовь так сильна,
Как грозная молния,
Осторожнее, не играй с огнём!
Если ты нарушишь обещания,
Протянушь руку другим,
Не думай: «Всё будет прощено!»

«Он тебе не ровня», —
«Будь только моей», —
Писать тебе и вставать на твоём пути не стану,
Ночью в окно постучишь,
«Увидимся хоть раз!» - позовёшь,
А я, я не выйду.
Ночью в окно постучишь,
«Увидимся хоть раз!» - позовёшь,
А я, я не выйду.

Тысячу мук претерпев,
Ради меня весь мир обойдя,
Будешь искать, но меня не найдёшь,
Меня не найдёшь, не жди,
Для тебя на небе
Сияющей звездой не зажгусь.
Меня не найдёшь, не жди,
Для тебя на небе
Сияющей звездой не зажгусь.
```
