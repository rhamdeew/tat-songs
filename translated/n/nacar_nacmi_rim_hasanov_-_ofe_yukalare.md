# Оригинал

### Наҗар Нәҗми / Рим Хәсәнов - Өфе юкәләре

```
Яшьлек урамнары,
Тулы хыяллары,
Без - шатлыкка туймас исәрләр.
Өфе юкәләре
Безнең хакта да әле
Яфрак яра-яра сөйләрләр.

Безнең менгән атлар,
Еллар, аргамаклар,
Көмеш тезген, алтын йөгәннәр.
Өфе юкәләре
Безнең хакта да әле
Чәчәк ата-ата сөйләрләр.

Гомер ике килми,
Утлар ике сүнми,
Без - мең янып тик бер сүнәрләр.
Өфе юкәләре
Онытмаслар әле,
Яфрак коя-коя сөйләрләр.
```

# Перевод

### Наҗар Нәҗми / Рим Хәсәнов - Уфимские липы

```
Улицы юности,
Полные грёз,
Мы — безумцы, ненасытные в радости.
Уфимские липы
О нас ещё
Будут рассказывать, распуская листву.

Наши оседланные кони,
Годы — скакуны,
Серебряные поводья, золотые узды.
Уфимские липы
О нас ещё
Будут рассказывать, расцветая цветами.

Жизнь не приходит дважды,
Огни не гаснут дважды,
Мы — тысячу раз гореть, но угаснуть лишь однажды.
Уфимские липы
Не позабудут нас,
Будут рассказывать, роняя листву.
```
