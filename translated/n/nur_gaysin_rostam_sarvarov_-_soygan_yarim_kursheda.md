# Оригинал

### Нур Гайсин / Рөстәм Сәрвәров - Сөйгән ярым күршедә

```
Мин күз атып йөргөн бер кыз
Яши безнең күршедә;
Аңа гашыйк булуымны
Белми әле берсе дә...

Сизми әле берсе дә,
Яшәсә дә күршедә.

Үзенә дә әйткәнем юк,
Чын күңелдән сөйсәм дә,
Тик аңарга язган хатым
Тузды йөреп кесәмдә...

Тузып бетте кесәмдә,
Үзен өзелеп сөйсәм дә.

Берәрсенә елмайса да,
Өзгәләнә үзәгем;
Әгәр башкага караса,
Ансыз ничек түзәрем...

Ансыз ничек түзәрем,
Өзгәләнер үзәгем.

Тыныч яшәргә теләсәң,
Сөймә икән күршеңне, -
Күргән саен җаның сызлап
Саргайта ул кешене,

Саргайта шул кешене,
Сөймә икән күршене.
```

# Перевод

### Нур Гайсин / Рустам Сарваров - Возлюбленная моя живёт в деревне

```
Девушка, на которую я заглядываюсь,
Живёт по соседству с нами;
Что я люблю её,
Пока не знает никто...

Не догадывается никто,
Хоть и живёт по соседству.

Ей самой не говорил,
Хоть искренне люблю,
Письмо, которое написал для неё,
Истрепалось, в кармане нося...

Истрепалось всё в кармане,
Хоть безумно её люблю.

Даже если кому-то другому улыбнётся,
Сердце моё разрывается;
Если посмотрит на другого,
Как я выношу без неё...

Как я выношу без неё,
Разрывается сердце.

Если хочешь спокойно жить,
Не люби соседку, -
С каждым взглядом сердце ноет,
Человек бледнеет,

Бледнеет человек,
Не люби соседку.
```
