# Оригинал

### Н.Нәҗми / З.Исмәгыйлов - ТАУЛАР ҖЫРЫ

```
Таулар юлын җырсыз үткәнем юк,

Күксел таулар сөя җырларны.

Авырлыкны җырлар җиңеләйтә,

Кыска итә озын юлларны.
Туган кырлар гүзәллеге булып,

Йөрәктән җыр күпме агыла.

Күпләрне бит җырлар очраштыра,

Җыр белән дус, иптәш табыла.
```

# Перевод

### Н.Нэжми / З.Исмэгыйлов - Песня гор

```
Не бывало, чтобы я прошёл горную дорогу без песни,

Синеватые горы любят песни.

Песня облегчает тяготы,

Делает долгий путь короче.
Красотой родных полей

Из сердца льётся песня.

Ведь песни многих сближают,

С песней находится друг, товарищ.
```
