# Оригинал

### Наҗар Нәҗми / Заһир Исмәгыйлев - Батырлар җыры

```
Иярле ат без менгәннәр,
Сay булыгыз, җан сөйгәннәр,
Ил чакыра изге яуга,
Кылыч - билләрдә.

Бәйге түгел яу кырлары,
Мөмкин булмас кайтулары
Барыбызга, бәлки кире,
Туган илләргә.

Алдык яра, йә үлдек без,
Үлем бар дип белмәдек без,
Үттек илләр, үттек юллар
Изге яуларда.

Булмады башкорт кайларда,
Ат эчердек язгы айда
Висла, Одер, Дунай дигән
Ерак ярларда!

Саумы, туып үскән җирләр!
Бар икән дә күрер көннәр.
Шатлыклары канат җәя
Безнең җырларның.

Сагындырган туган яклар,
Тып-тып басып килә атлар,
Дан бөркелә, чаң бөркелә
Безнең юллардан!
Һай, юллардан!
```

# Перевод

### Нажар Нажми / Тагир Исмагилов - Песнь богатырей

```
Сели мы на осёдланных коней,
Будьте здоровы, дорогие наши,
Страна зовёт на битву священную,
Мечи — при поясе.

Это не скачки — поля сражений,
Быть может, не суждено вернуться
Всем нам назад,
В родные края.

Получили раны иль погибли мы,
О том, что есть смерть, не думали мы,
Прошли страны, прошли дороги
В священных битвах.

Каких краёв не видели башкиры?
Коней поили мы в весенний месяц
У Вислы, Одера, Дуная —
На дальних берегах!

Здравствуй, родная земля, где мы выросли!
Есть, видно, и дни свиданий.
Радость наших песен
Расправляет крылья.

По родным краям соскучились,
Тихо-тихо ступают кони,
Славой укрыты, пылью укрыты
Наши дороги!
Эх, с дорог!
```
