# Оригинал

### Наҗар Нәҗми / Нариман Сабитов - Агыйделдә ак томан (икенче вариант)

```
Агыйделдә ак томан,
Параход тавышлары.
Дымлы керфекләр шикелле,
Ярында камышлары.
Ярында камышлары,
Параход тавышлары.
Ярында камышлары,
Параход тавышлары.

Агыйделдә ак томан,
Ат кешни болыннарда.
Ат эзләп йөргән эзләрем
Калган шул урыннарда.
Калган шул урыннарда,
Чыкланган болыннарда.
Калган шул урыннарда,
Чыкланган болыннарда.

Агыйделдә ак томан,
Борылган Идел белән.
Нигә шул кадәр якынсың,
Әй, туган Иделгенәм?!
Әй, туган Иделгенәм!
Йөрәгем синең белән!
Әй, туган Иделгенәм!
Йөрәгем синең белән!
```

# Перевод

### Наҗар Нәҗми / Нариман Сабитов - Белый туман на Агидели (второй вариант)

```
На Агидели белый туман,
Голоса пароходов.
Словно влажные ресницы,
Камыши на её берегу.
Камыши на её берегу,
Голоса пароходов.
Камыши на её берегу,
Голоса пароходов.

На Агидели белый туман,
Конь ржёт на лугах.
Мои следы, где я искал коня,
Остались в тех местах.
Остались в тех местах,
На росистых лугах.
Остались в тех местах,
На росистых лугах.

На Агидели белый туман,
Там, где она поворачивает к Идели.
Почему ты так близка,
Эй, родная моя Идель?!
Эй, родная моя Идель!
Моё сердце с тобой!
Эй, родная моя Идель!
Моё сердце с тобой!
```
