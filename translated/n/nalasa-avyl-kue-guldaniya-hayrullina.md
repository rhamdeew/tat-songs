# Оригинал

### Гөлдания Хәйруллина - Наласа авыл көе

```
Өздереп гармун уйныйлар

Наласа авылында.

Йөрәгемә утлар яктың —

Янам мин ялкынында.

Бала чагым гөрләп үтте

Наласа кырларында.

Сагынуларым, сагышларым

Бу моңлы җырларымда.

Төнбоеклы тирән күлдә

Тезелеп йөзә аккошлар.

Үсеп җиткәч, чит җирләрдә

Йөртә безне язмышлар.
```

# Перевод

###  - Мелодия деревни Наласа

```
Играют на гармони с надрывом

В деревне Наласа.

Ты зажгла огни в моём сердце —

Горю я в его пламени.

Моё детство прошло звонко,

На полях Наласы.

Моя тоска, моя грусть —

В этих моих напевных песнях.

В глубоком озере с кувшинками

Плывут вереницей лебеди.

Повзрослев, по чужим краям

Нас водят судьбы.
```
