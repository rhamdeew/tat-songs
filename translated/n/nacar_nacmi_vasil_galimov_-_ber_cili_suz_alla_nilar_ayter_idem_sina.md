# Оригинал

### Наҗар Нәҗми / Вәсил Галимов - Бер җылы сүз (Әллә ниләр әйтер идем сиңа)

```
Безгә дигән гомер төргәгеннән,
Берәм-берәм еллар коела.
Бер җылы сүз әйтә алмадым кебек,
Әйтә алмадым еллар буена.

Кайгылардан кемнәр азат икән,
Шатлыклардан кемнәр туйган соң?
Син шуларны уртаклашып җирдә
Яшәр өчен генә тугансың.

Синең белән еллар җиңелерәк,
Бәхет юлдаш минем юлыма.
Әллә ниләр әйтер идем сина,
Әйтә алмамдыр гомер буена.
```

# Перевод

### Нажар Нажми / Вәсил Галимов - Одно слово (Все говорил тебе что-нибудь)

```
Из свёртка жизни, что нам отмерен,
Год за годом сыплются года.
Не смог я сказать тебе одно слово,
Не мог сказать все эти годы.

Кто из горя был свободен,
Кто насытился счастьем потом?
Ты разделил это на земле,
Чтобы просто жить родился.

С тобой года легче,
Счастье - спутник моего пути.
Всё бы сказал тебе,
Видно, не смогу сказать за всю жизнь.
```
