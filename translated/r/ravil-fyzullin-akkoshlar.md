# Оригинал

### Равил Фәйзуллин / Фасил Әхмәтов - АККОШЛАР

```
Көзләрдән соң язлар килми,

Алда - салкын ак кышлар.

Китәсез дәмени,

Китәсез дәмени,

Китәсез дәмени, аккошлар?
Әллә ничек үтте яшьлек,

Соң очрашты язмышлар.

Хушлашырга безгә

Иртәрәк бит әле,

Иртәрәк бит әле, аккошлар...
Бездә әле бу донъяга

Күңел тулы алкышлар...

Китәсез дәмени,

Китәсез дәмени,

Китәсез дәмени, аккошлар?
```

# Перевод

### Равил Файзуллин / Фасил Ахметов - Лебеди

```
После осени не приходит весна,

Впереди – холодные белые зимы.

Неужели вы улетаете,

Неужели вы улетаете,

Неужели вы улетаете, лебеди?
Как-то незаметно прошла юность,

Поздно встретились наши судьбы.

Нам ещё рано

Прощаться,

Ещё рано, лебеди...
У нас ведь ещё душа полна

Восторга перед этим миром...

Неужели вы улетаете,

Неужели вы улетаете,

Неужели вы улетаете, лебеди?
```
