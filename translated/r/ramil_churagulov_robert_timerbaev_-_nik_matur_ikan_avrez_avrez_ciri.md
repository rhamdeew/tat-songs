# Оригинал

### Рамил Чурагулов / Роберт Тимербаев - Ник матур икән Әврез!? (Әврез җыры)

```
Түбәнге Әврез авылы
Дөньяда берәү генә.
Аның бары берәүлеген
Беләм, бар җиһан белә.

Әгәр, дустым, безнең авыл,
Ник шулай матур дисәң,
Серен әйтәм - Әврез матур,
Таһир, Зөһрәләр белән!

Хан кызыннан чибәрерәк
Әврезем гүзәлләре.
Кыйгач кашлы, нечкә билле,
Кирәкми бүтәннәре.

Әгәр, дустым, безнең авыл,
Ник шулай матур дисәң,
Серен әйтәм - Әврез матур,
Таһир, Зөһрәләр белән!

Бер типкәндә тимер өзәр
Егетләр дә бар бездә.
Күз салмагыз сез аларга,
Бик кирәк үзебезгә.

Әгәр, дустым, безнең авыл,
Ник шулай матур дисәң,
Серен әйтәм - Әврез матур,
Таһир, Зөһрәләр белән!
```

# Перевод

### Рамил Чурагулов / Роберт Тимербаев - Как красива же Аверез! (Песня Авереза)

```
Село Нижний Аврез
В мире только одно.
Его единственность эту
Я знаю, весь мир знает.

Если спросишь, мой друг, отчего
Наше село так красиво,
Секрет скажу - Аврез красив
Своими Тагирами, Зухрами!

Краше, чем дочь хана,
Девушки моего Авреза.
С бровями стрелками, тонкой талией,
Другие не нужны.

Если спросишь, мой друг, отчего
Наше село так красиво,
Секрет скажу - Аврез красив
Своими Тагирами, Зухрами!

Кулаком железо рвут
Наши парни удалые.
Не пяльтесь вы на них,
Очень нужны нам.

Если спросишь, мой друг, отчего
Наше село так красиво,
Секрет скажу - Аврез красив
Своими Тагирами, Зухрами!
```
