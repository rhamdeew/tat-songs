# Оригинал

### Рәмзинә Тимерова / Роберт Тимербаев - Җир җиләкләре

```
Туган ягым бигрәк ямьле,
Бизәлгән кызлар төсле.
Чәчәкләрен иснәп йөрим,
Бигрәкләр дә хуш исле.

Җир җиләкләрен җыямын
Кәрзиннәрем тулганчы.
Йөрим әле кырларында
Күңелләрем булганчы.

Җир җиләкләре алдымда,
Ашап кара - бал гына.
Әллә инде беткән дисәм,
Тагы да чыга алдыма.

Җир җиләкләрен җыямын
Кәрзиннәрем тулганчы.
Йөрим әле кырларында
Күңелләрем булганчы.

Җиләклектә җиләк җыйдым,
Ятып тауның үренә.
Туган ягым болыннары
Һәрчак күңлем түрендә.

Җир җиләкләрен җыямын
Кәрзиннәрем тулганчы.
Йөрим әле кырларында
Күңелләрем булганчы.
```

# Перевод

### Рәмзинә Тимерова / Роберт Тимербаев - Земляника

```
Родной мой край особенно прекрасен,
Словно украшенные девушки.
Хожу, вдыхая аромат его цветов,
До чего же они душисты.

Землянику собираю,
Пока не наполнятся мои корзины.
Похожу ещё по его полям,
Пока душа не насытится.

Земляника передо мной,
Попробуй - чистый мёд.
Думаю: уж не кончилась ли?
А она снова появляется передо мной.

Землянику собираю,
Пока не наполнятся мои корзины.
Похожу ещё по его полям,
Пока душа не насытится.

На ягоднике собирала землянику,
Лёжа на вершине горы.
Луга родного края
Всегда в глубине моей души.

Землянику собираю,
Пока не наполнятся мои корзины.
Похожу ещё по его полям,
Пока душа не насытится.
```
