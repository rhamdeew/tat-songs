# Оригинал

### Татар халык җыры - РАМАЙ

```
Төнгә каршы берәү моңлы итеп, Рамай,

Аерылышу көен җырлады.

Тын калдылар урман буйлары ла, Рамай,

Чишмәләр дә акмый тыңлады.

Агыйделкәй алкын, суы салкын, Рамай,

Салкын диеп керми калмадым.

Сөйдем сине, бәгърем, чын күңелдән, Рамай,

Аңлашырлык сүзләр тапмадым.

Сәхрәләргә чыгып бер сызгырдың, Рамай,

Чапкан печәннәрем кипсен дип.

Безгә кемнәр теләк теләде икән, Рамай,

Гомерләре аеры үтсен дип.
```

# Перевод

### Татарская народная песня - Рамай

```
Под вечер кто-то, тоскливо, Рамай,
Пел напев расставания.
Затихли опушки леса, Рамай,
И родники, не тек, слушали.

Агидель бурлива, вода холодная, Рамай,
Хоть и холодная, не мог не войти.
Любил я тебя, родная, всем сердцем, Рамай,
Не нашёл слов, чтобы объясниться.

Выйдя в степь, ты свистнул раз, Рамай,
Чтобы скошенное мною сено высохло.
Кто же пожелал нам, Рамай,
Чтобы наши жизни прошли врозь.
```
