# Оригинал

### Рәмзинә Тимерова / Муса Смаков - Кеше бәхетенә үрелмәгез!

```
Бер бересен өзлеп сөйгәннәрне,
Гайбәт утларына салмагыз!
Кагылмагыз, зинһар, пычратмагыз,
Сөю бит ул сафлык - аңлагыз!

Кеше бәхетә үрелмәгез,
Көнләшмәгез, сабыр булыгыз!
Бүген - мин бәхетле, иртәгә - син,
Балкып торсын барыр юлыгыз!

"Кеше сүзе - кеше үтрә ..." - диләр,
Бу сүз бик хак дөрес әйтелгән,
Үлгәннәр бит кире кайталмыйлар,
Әйткән сүзгә соңыннан үкенмә!

Кеше бәхетә үрелмәгез,
Көнләшмәгез, сабыр булыгыз!
Бүген - мин бәхетле, иртәгә - син,
Балкып торсын барыр юлыгыз!
```

# Перевод

### Рамзина Тимерова / Муса Смаков - Не завидуйте счастью человека!

```
Тех, кто любит друг друга безоглядно,
Не бросайте в огонь сплетен!
Не трогайте, прошу, не пачкайте,
Ведь любовь - это чистота, поймите!

Не тянитесь к чужому счастью,
Не завидуйте, будьте терпеливы!
Сегодня - я счастлив, завтра - ты,
Пусть светел будет ваш дальнейший путь!

Говорят: "слово человека - человека губит...",
Эта поговорка сказана очень верно,
Ведь умершие не возвращаются,
Не жалей потом о сказанном слове!

Не тянитесь к чужому счастью,
Не завидуйте, будьте терпеливы!
Сегодня - я счастлив, завтра - ты,
Пусть светел будет ваш дальнейший путь!
```
