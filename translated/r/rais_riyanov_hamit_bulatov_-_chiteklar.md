# Оригинал

### Рәис Риянов / Хәмит Булатов - Читекләр

```
Безнең Арча читекләре
Елтыр ука бизәкле.
Читек кигән чибәр кызлар
Өзә бәгырь-үзәкне.
Эх, укалы читекләр!
Читек кигән кызлар белән
Бию рәхәт, егетләр!

Безнең Арча читекләре,
Үкчәләре түгәрәк.
Сабан туйларын шаулатып
Йөрик әле бергәләп.
Эх, каюлы читекләр!
Читек тегүче бер сылу
Каш сикертте, егетләр!

Безнең Арча читекләре,
Яшеле бар, сарысы.
Читекле кыз - гүзәлем дип
Яна-көя барысы.
Эх, чигүле читекләр!
Читек кигән чибәрләрдән
Колак какмыйк, егетләр!
```

# Перевод

### Рәис Риянов / Хәмит Булатов - Читекләр

```
Наши арские ичиги
Расшиты золотой тесьмой.
Красавицы в ичигах
Сердце рвут мне до нутра.
Эх, ичиги в узорах!
С девушками в ичигах
Плясать в радость, парни!

Наши арские ичиги,
Каблучки у них круглы.
Сабантуй шумит и светится -
Пойдём вместе, что ж, братцы?
Эх, ичиги с узорной каймой!
Одна мастерица-швея
Бровью повела, парни!

Наши арские ичиги -
Есть зелёные, есть жёлтые.
«Дева в ичигах - моя краса», -
Все горят до полноты.
Эх, ичиги с вышивкой!
Красавиц в ичигах, парни,
Не упустим мимо себя!
```
