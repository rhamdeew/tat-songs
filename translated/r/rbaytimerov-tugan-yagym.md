# Оригинал

### Р.Байтимеров / Р.Яхин - ТУГАН ЯГЫМ

```
Күпме юллар йөрдем, донъя күрдем,

Назлы җилләр йөзем сыйпады.

Сиңа кайткач кына, туган ягым,

Күкрәгемә шатлык сыймады.
Тик бер генә көнгә аерылсам да

Ямансулап сине юксынам.

Синнән башка миңа, туган ягым,

Бу донъяда тормыш юк сыман.
Тик бер генә көнгә аерылсам да

Ятим калган кебек буламын.

Тик син генә яшәү матурлыгы,

Гүзәллеге якты донъяның
```

# Перевод

### Р.Байтимеров / Р.Яхин - Родной край мой

```
Сколько дорог я прошёл, мир повидал,
Ласковые ветра гладили моё лицо.
Только когда вернулся к тебе, родной край,
Радость не вмещалась в моей груди.

Даже если расстанусь с тобой на один лишь день,
Тоскую, скучаю по тебе.
Без тебя мне, родной край,
Кажется, нет жизни в этом мире.

Даже если расстанусь на один лишь день,
Чувствую себя словно осиротевшим.
Только ты — красота жизни,
Прелесть светлого мира.
```
