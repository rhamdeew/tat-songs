# Оригинал

### Рәсим Хәбибуллин / Зөлфирә Сәфәргалиева - Туган авылым урамы (икенче вариант)

```
Туган авылым урамын
Кабат-кабат урадым.
Китәрмен дә озакламый,
Кайтырмын диеп уйладым.

Кайталмадым, читтә үтте
Гомеремнең еллары.
Язмышларга язылмаган
Кире кайту юллары.

Чит-ят җирдә үткән еллар
Яшьлегемне урлады.
Гармуным да урамнарны
Минсез генә урады.

Туган авылым урамын
Кабат кайчан урармын?
Яшьлегем җырларын уйнап,
Сузып-сузып җырлармын?

Туган авылым урамын
Сагынып үтә елларым.
Торган саен артта кала,
Аерыла шул юлларым.

Туган авылым урамын
Тагын кайчан урармын?
Бәхет эзләп китәрмен дә
Кайтырмын диеп уйладым.
Бәхет эзләп китәрмен дә
Кайтырмын диеп уйладым...
```

# Перевод

### Расим Хабибуллин / Зөлфирә Сәфәргалиева - Улица моего родного села (второй вариант)

```
По улице родного аула
Кружил я снова и снова.
Уйду — и скоро вернусь,
Думал я.

Не вернулся: на чужбине прошли
Годы моей жизни.
Не вписан в судьбу
Путь обратно домой.

Годы на чужой-далёкой земле
Украли мою юность.
И гармонь моя по улицам
Без меня одна кружила.

По улице родного аула —
Когда снова покружу?
Сыграю песни своей юности,
Протяжно-протяжно спою?

По улице родного аула
С тоской проходят мои годы.
С каждым разом остаётся она позади,
Расходятся мои пути.

По улице родного аула —
Когда снова покружу?
Уйду искать счастье —
Вернусь, думал я.
Уйду искать счастье —
Вернусь, думал я...
```
