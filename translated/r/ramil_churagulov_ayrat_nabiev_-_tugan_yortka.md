# Оригинал

### Рамил Чурагулов / Айрат Нәбиев - Туган йортка

```
Авылыма кайтсам, капкам бикле,
Нигеземә үскән кычыткан.
Моңсу йозак моңсу караш белән
Көтә микән мине бик күптән?

Кайда әткәм?
Кайда әнкәм?!
Кайда минем туганнар?!
Кайда гармун?
Кайда җыр-моң?!
Дуслар кайда булганнар?!
Туган йортның тәрәзләрен
Ник кадаклап куйганнар?!!

Газиз туган авылым урамыннан
Йөгереп йөри чит-ят балалар,
Йорт башында яткан агач тайлар
Йөрәккә ник шом-зар салалар?

Кайда әткәм?
Кайда әнкәм?!
Кайда минем туганнар?!
Кайда гармун?
Кайда җыр-моң?!
Дуслар кайда булганнар?!
Туган йортның тәрәзләрен
Ник кадаклап куйганнар?!!

Авылыма кайтсам, капкам бикле,
Ишегемдә тутык зур йозак.
Чирәмнәргә ятып еласам да,
Кайтмас яшьлек, кайтмас балачак.

Кайда әткәм?
Кайда әнкәм?!
Кайда минем туганнар?!
Кайда гармун?
Кайда җыр-моң?!
Дуслар кайда булганнар?!
Туган йортның тәрәзләрен
Ник кадаклап куйганнар?!!
```

# Перевод

### Рамил Чурагулов / Айрат Нәбиев - К родному дому

```
Вернусь в деревню — ворота заперты,
На фундаменте выросла крапива.
Тоскливый замок с тоскливым взором —
Давно ли ждёт меня?

Где мой отец?
Где моя мать?!
Где мои родные?!
Где гармонь?
Где песни-напев?!
Куда подевались друзья?!
Окна родного дома
Зачем заколотили?!!

По улице любимой родной деревни
Чужие дети носятся гурьбой.
На крыше дома — деревянные коньки —
Зачем вселяют в сердце скорбь и тревогу?

Где мой отец?
Где моя мать?!
Где мои родные?!
Где гармонь?
Где песни-напев?!
Куда подевались друзья?!
Окна родного дома
Зачем заколотили?!!

Вернусь в деревню — ворота заперты,
На двери — ржавый большой замок.
Хоть ляг на траву и плачь —
Не вернётся юность, не вернётся детство.

Где мой отец?
Где моя мать?!
Где мои родные?!
Где гармонь?
Где песни-напев?!
Куда подевались друзья?!
Окна родного дома
Зачем заколотили?!!
```
