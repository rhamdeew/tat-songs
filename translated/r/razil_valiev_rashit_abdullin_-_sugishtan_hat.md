# Оригинал

### Разил Вәлиев / Рәшит Абдуллин - Сугыштан хат

```
Әнкәем, хат язам:
Ничек соң хәлләрең?
Юрама яманга
Килмәсә хәбәрем.

Әткәем, хат язам:
Юк башым игәнем,
Һәрвакыт хәтердә
«Сынатма!» дигәнең.

Сөйгәнем, хат язам
Сугышның үзеннән.
Тик шәүләм сүнмәсен,
Китмәсен күзеңнән.
```

# Перевод

### Разиль Валеев / Рәшит Абдуллин - Письмо с войны

```
Матушка, пишу письмо:
Как твои дела?
Не думай о дурном,
Если нет вести.

Батюшка, пишу письмо:
Голову не гну,
Всегда в памяти жили
Твои слова: «Не подведи!»

Милая, пишу письмо
Прямо из огня войны.
Лишь бы моя тень не угасла,
Не исчезла из твоих глаз.
```
