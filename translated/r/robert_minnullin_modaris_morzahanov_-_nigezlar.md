# Оригинал

### Роберт Миңнуллин / Мөдәрис Морзаханов - Нигезләр

```
Газизләрдән газиз туфрак,
Изгеләрдән изге нигез!
Туган җирнең газизләре
Нигезләрдән бизде, дибез.

Эй илдәшләр, нигездәшләр,
Кайталмыйбыз ни сез, ни без.
Көтә, беләм, туфрак белән
Тигезләнгән азмы нигез?!

Кемдер бизгән, кемдер түзгән,
Кемнәрнедер биздергәннәр,
Өметләрен өздергәннәр -
Күпме шундый без белгәннәр.

Эй илдәшләр, нигездәшләр,
Кайталмыйбыз ни сез, ни без.
Көтә, беләм, туфрак белән
Тигезләнгән азмы нигез?!

Бәргәләнә, өзгәләнә
Бәгырьләре киткәннәрнең,-
Күз яшьләрен түккәннәрнең.
Чит җирне үз иткәннәрнең...

Эй илдәшләр, нигездәшләр,
Кайталмыйбыз ни сез, ни без.
Көтә, беләм, туфрак белән
Тигезләнгән азмы нигез?!
```

# Перевод

```
Дороже всех родная земля,
Из праведников - праведная основа!
Любимцев родного края
От основ своих отреклись, говорим.

О, соотечественники, единомышленники,
Не вернёмся мы обратно - ни вы, ни мы.
Ждёт, знаю, разве мало фундаментов
Уже сровнялось с землёй?!

Кто-то украшал, кто-то строил,
Кого-то заставили украшать,
Надежды их сломили -
Много ли таких, кого мы знали.

О, соотечественники, единомышленники,
Не вернёмся мы обратно - ни вы, ни мы.
Ждёт, знаю, разве мало фундаментов
Уже сровнялось с землёй?!

Ноют, разрываются
Сердца тех, кто уехал, -
Слёзы горькие проливших,
Чужбину сделавших своей...

О, соотечественники, единомышленники,
Не вернёмся мы обратно - ни вы, ни мы.
Ждёт, знаю, разве мало фундаментов
Уже сровнялось с землёй?!
```
