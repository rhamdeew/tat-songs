# Оригинал

### Роберт Миңнуллин / Оскар Усманов - Талбишек

```
Бездә бишек әллә ничек
Талдан-җырдан үрелә.
Җырлы бишек, җылы бишек
Эленә өй түренә.

Ничек җырламасын бишек,
Сөн талларыннан үр дә?
Талбишектә үстем мин дә,
Сизелмимени бер дә?

Җырлый бишек, елый бишек,
Җырлый, елый, моңлана.
Әллә бишек, әллә инде
Бишектә яткан бала.

Ничек җырламасын бишек,
Сөн талларыннан үр дә?
Талбишектә үстем мин дә,
Сизелмимени бер дә?

Сеңгәндер ул талбишеккә
Әнкәмнең моңнары да.
Шулайдыр шул, талбишекнең
Юк шуңа тынганы да.

Ничек җырламасын бишек,
Сөн талларыннан үр дә?
Талбишектә үстем мин дә,
Сизелмимени бер дә?
```

# Перевод

### Роберт Миңнуллин / Оскар Усманов - Ивовая колыбель

```
У нас колыбель — как удивительно —
Из ивы и из песен сплетается.
Певучая колыбель, тёплая колыбель
В красном углу дома подвешена.

Как ей не петь, колыбели,
Сплетённой из ив реки Сёна?
Я тоже вырос в ивовой колыбели —
Разве это совсем не чувствуется?

Поёт колыбель, плачет колыбель,
Поёт, плачет, тоскует.
То ли колыбель, то ли уже
Ребёнок, лежащий в ней.

Как ей не петь, колыбели,
Сплетённой из ив реки Сёна?
Я тоже вырос в ивовой колыбели —
Разве это совсем не чувствуется?

Впитались, наверное, в ту ивовую колыбель
И напевы моей матери.
Оттого ведь ивовой колыбели
Нет покоя, нет тишины.

Как ей не петь, колыбели,
Сплетённой из ив реки Сёна?
Я тоже вырос в ивовой колыбели —
Разве это совсем не чувствуется?
```
