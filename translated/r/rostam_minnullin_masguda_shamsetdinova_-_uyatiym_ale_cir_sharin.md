# Оригинал

### Рөстәм Миңнуллин / Мәсгудә Шәмсетдинова - Уятыйм әле Җир шарын

```
Уятыйм əле Кояшны,
Көннəрем якты булсын,
Уятыйм əле бакчаны,
Көннəрем татлы булсын.

Уятыйм əле Əнине,
Көннəрем җылы булсын,
Уятыйм əле кошларны,
Көннəрем җырлы булсын.

Уятыйм əле дусларны,
Көннəрем якты булсын,
Уятыйм əле Җир шарын,
Көннəрем гөрлəп торсын.
```

# Перевод

### Рөстәм Миңнуллин / Масгуда Шамсетдинова - Стыжусь я, Земной шар

```
Разбужу-ка я Солнце,
Чтоб деньки мои светлыми были,
Разбужу-ка я садик,
Чтоб деньки мои сладкими были.

Разбужу-ка я маму,
Чтоб деньки мои тёплыми были,
Разбужу-ка я птичек,
Чтоб деньки мои песенными были.

Разбужу-ка я друзей,
Чтоб деньки мои светлыми были,
Разбужу-ка я Земной шар,
Чтоб деньки мои звонко гремели.
```
