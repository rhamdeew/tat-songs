# Оригинал

### Ренат Харис / Резеда Ахиярова - Ак теләкләр (икенче вариант)

```
Алтын-алтын яфраклар
Төште, төште учыма.
Алтын-алтын теләкләр
Килделәр тел очыма:

Һәр агачны һәр язда
Яшь яфраклар төрсеннәр.
Кешеләр дә алардан
Гыйбрәт ала күрсеннәр.

Каурый-каурый ак карлар
Кунды, кунды учыма.
Ап-ак, ап-ак теләкләр
Килделәр тел очыма:

Һәр агачны һәр язда
Яшь яфраклар төрсеннәр.
Без барасы ак юллар
Ак бәхеткә илтсеннәр (сумсыннар).

Сәйлән-сәйлән тамчылар
Тамды, тамды учыма.
Матур-матур теләкләр
Килделәр тел очыма:

Һәр агачны һәр язда
Яшь яфраклар төрсеннәр.
Мәхәббәттән көч алып
Чәчәк атсын кешеләр.
```

# Перевод

### Ренат Харис / Резеда Ахиярова - Белые пожелания (второй вариант)

```
Золотые-золотые листья
Упали, упали мне на ладонь.
Золотые-золотые пожелания
Пришли ко мне на кончик языка:

Пусть каждое дерево каждой весной
Одевается молодой листвой.
Пусть и люди у них
Учатся доброму примеру.

Пушистые-пушистые белые снега
Легли, легли мне на ладонь.
Белые-белые пожелания
Пришли ко мне на кончик языка:

Пусть каждое дерево каждой весной
Одевается молодой листвой.
Пусть белые дороги, по которым нам идти,
Ведут к светлому счастью.

Бисеринками-бисеринками капли
Упали, упали мне на ладонь.
Красивые-красивые пожелания
Пришли ко мне на кончик языка:

Пусть каждое дерево каждой весной
Одевается молодой листвой.
Пусть, набравшись силы от любви,
Люди расцветают.
```
