# Оригинал

### Резеда Вәлиева / Ренат Еникеев - Сүрелмәс җырым син (беренче вариант)

```
Юлыма чыгасың.
Кулларың сузасың,
Оныттың, кадерлем, дисең дә.
Онытылмый назларың,
Яшьлегем язлары
Исемдә,
Исемдә,
Исемдә.

Шелтәле карама.
Ят керде арага.
Сагынып яшим, дип, мим генә.
Катлаулы язмышым.
Иң татлы сагышым -
Син генә,
Син генә,
Син генә...

Гомерләр үтсә дә,
Көзләрем җитсә дә,
Көзләрем яз иткән нурым син.
Сүнсәм дә сүрелмәс.
Үлсәм дә өзелмәс
Җырым син,
Җырым син.
Җырым син!
```

# Перевод

### Резеда Вәлиева / Ренат Еникеев - Ты - Ты - Ты - моя бесконечная песня (первый вариант)

```
Выходишь мне навстречу,
Простираешь руки свои,
Ты забыла, родная, будто говоришь.
Не забываются ласки твои,
Весны юности моей
В памяти,
В памяти,
В памяти.

Не смотри с упрёком.
Чужое вкралось между нами.
Скучая, живу, молча лишь,
Сложная судьба моя.
Самая сладкая печаль моя -
Только ты,
Только ты,
Только ты...

Пусть пройдут века,
Пусть мои осени придут,
Ты — свет, что осени мои весной обернул.
Пусть погасну — не угаснет.
Пусть умру — не прервётся
Песня моя,
Песня моя,
Песня моя!
```
