# Оригинал

### Разил Вәлиев / Луиза Батыр-Болгари - Алга, дибез

```
Алга дибез, алга, дибез,
Артка таба барабыз,
Алга барырга кушкан бит
Безгә әби-бабабыз.
Их, их, безгә әби-бабабыз.

«СССР» диеп язылган
Самолет канатына,
Алдынгылар сайланырлар
Совет аппаратына.
Ух, ух, совет аппаратына.

Җирдә оҗмах төзер идем,
Эш килми шул кулымнан.
Алга карап артка бармыйк
Коммунизм юлыннан!
Уф, уф, коммунизм юлыннан!
```

# Перевод

### Разил Вәлиев / Луиза Батыр-Болгари - Вперёд, говорим

```
«Вперёд», говорим мы, «вперёд», говорим,
А сами идём назад,
Ведь идти вперёд велели
Нам наши деды и бабушки.
Их, их, нам наши деды и бабушки.

«СССР» написано
На крыле самолёта,
Передовиков выберут
В советский аппарат.
Ух, ух, в советский аппарат.

Я бы построил рай на земле,
Да работа не идёт из моих рук.
Глядя вперёд, не пойдём назад
По пути коммунизма!
Уф, уф, по пути коммунизма!
```
