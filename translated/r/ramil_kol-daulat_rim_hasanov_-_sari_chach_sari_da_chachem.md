# Оригинал

### Рамил Кол-Дәүләт / Рим Хәсәнов - Сары чәч (Сары да чәчем)

```
Сары да чәчең, ап-ак йөзең,
Көзге каеннарга охшаган.
Үзең юҡта чаукаларны сөеп
Сагышымнан бер аз бушанам.

Сары да чәчең, ап-ак йөзең,
Мәхәббәтем, сары сагышым!
Күзең сирпеп миңа бер карасаң
Ешая шул йөрәк сагышым.

Сары да чәчең, ап-ак йөзең,
Карашларың нигә сагышлы?
Сары да чәчле ак каеннар
Була диләр, авыр язмышлы.
```

# Перевод

### Рамил Кол-Дәүләт / Рим Хасанов - Рыжие волосы (О, рыжие мои волосы)

```
О, русые твои волосы, лицо белее снега,
Похожи на осенние берёзы.
Пока тебя нет, любуясь галками,
Немного отступает моя тоска.

О, русые твои волосы, лицо белее снега,
Любовь моя, светлая моя тоска!
Если бросишь на меня хоть один взгляд,
Учащается тоска в моем сердце.

О, русые твои волосы, лицо белее снега,
Почему во взгляде твоем такая грусть?
Говорят, у русоволосых белых берёз
Тяжёлая судьба бывает.
```
