# Оригинал

### Рәмзинә Тимерова / Роберт Тимербаев - Сагындым авылымны (беренче вариант)

```
Талгын гына Идел ага
Туган ягыма таба.
Бөдрә талларын тирбәтеп,
Кояшта нурлар уйнатып,
Чал дулкыннары ярга кага.

Сагындым авылымны,
Кайчан кайтырмын инде?
Сәлам әйт сөйгән ярыма,
Әткәйгә-әнкәемә лә,
Сәлам әйт тугайларыма /туганнарыма/,

Искә төшә шул чаклар,
Ярым калды еракта.
Шатлыкларын балачакның,
Мәхәббәтем синдә таптым -
Күңелем сиңа тарта.

Сагындым авылымны,
Кайчан кайтырмын инде?
Сәлам әйт сөйгән ярыма,
Әткәйгә-әнкәемә лә,
Сәлам әйт тугайларыма /туганнарыма/.
```

# Перевод

### Рәмзинә Тимерова / Роберт Тимербаев - Соскучилась по деревне (первый вариант)

```
Неторопливо течёт Идель
К моему родному краю.
Качая кудрявые ивы,
Играя лучами на солнце,
Седые волны бьются о берег.

Скучаю по своей деревне,
Когда же я вернусь?
Передай привет моему любимому,
Отцу и матушке моей,
Передай привет моим лугам / моим родным.

Вспоминаются те времена,
Мой любимый остался далеко.
Радости детства,
Свою любовь я нашёл в тебе -
Душа моя тянется к тебе.

Скучаю по своей деревне,
Когда же я вернусь?
Передай привет моему любимому,
Отцу и матушке моей,
Передай привет моим лугам / моим родным.
```
