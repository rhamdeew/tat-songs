# Оригинал

### Равил Галиәкбәров / Венер Мөхәммәдиев - Таң җыры (икенче вариант)

```
Күтәрелә томан
Бишек җыры сыман,
Агыла моң таңнар атканда.
Тыңлыйм таңның җырын,
Туган якның моңын,
Чыңлап чишмәләре акканда.

Балачагым иле,
Ямьле инеш күле,
Җиләкле аланым хуш исе.
Тугайларың гизеп,
Суларыңда йөзеп,
Эх, синдә генә яшисе!

Ак дулкыннар уйный,
Күңел сөенеп туймый,
Тәүге нурлар күлгә сибелә.
Талпындырдың ничек,
Түзим, яшел бишек,
Тагын синдә, синдә тибрәләм.

Тугайларың гизеп,
Суларыңда йюзеп,
Эх, синдә генә яшисе,
Эх, синдә генә яшисе,
Эх, синдә генә яшисе!
```

# Перевод

### Равиль Галиакбаров / Венер Мухаммадиев - Песня рассвета (второй вариант)

```
Поднимается туман
Как колыбельная песня,
Струится грусть, когда рассвета время.
Слушаю я песню рассвета,
Тоску родных мест,
Когда ключи журчат и льются реки.

Моя земля родная,
Милый пруд у ручья,
Ягодный мой луг, полный аромата.
По твоим лугам бродя,
В твоих водах плавая,
Ах, лишь в тебе жить хочу!

Играют белые волны,
Душа ликует, не устанет,
Первые лучи на озеро льются.
Как же ты маняще,
Ты, зелёная колыбель,
И снова в тебе, в тебе качаюсь.

По твоим лугам бродя,
В твоих водах плавая,
Ах, лишь в тебе жить хочу,
Ах, лишь в тебе жить хочу,
Ах, лишь в тебе жить хочу!
```
