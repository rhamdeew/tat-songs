# Оригинал

### Рәис Риянов / Ризван Хәкимов - Өфедә бар сөйгәнем

```
Өфе юллары карурман,
Өфе юллары озын.
Шунда сөйдем ил гүзәлен -
Урал таулары кызын.

Төшеп Йөрүзән буена,
Җиләген кабалмадым.
Өфе юлына чыкмыйча,
Һич тынгы табалмадым.

Зәңгәрле күлмәк кигәнем -
Өфедә бар сөйгәнем.
«Уф!..» дигәннәрне бетерә
Бары Өфе дигәнем.

Өфе кичләрен сихерли
Айның балкып чыгышы...
Җаныңны назлап эретә
Саф мәхәббәт сулышы.
```

# Перевод

### Раис Риянов / Ризван Хәкимов - Любимая в Уфе

```
Дороги Уфы - глухие леса,
Дороги Уфы длинны.
Там любил я красивую -
Дочь Уральских гор.

Спустился к берегу Юрюзани,
Не успел отведать её ягод.
Не выходя на уфимскую дорогу,
Ни одного отдыха не нашел.

Надел синюю рубаху -
Любимая в Уфе.
Все мои вздохи «Уф!..» прекращает
Лишь одно слово «Уфа».

Вечера Уфы околдовывает
Восход сияющей луны...
Твою душу нежно растапливает
Дыхание чистой любви.
```
