# Оригинал

### Ренат Харис / Эльмир Низамов - Өмет йолдызы

```
Җилләр исә,
сулар ага,
кояшны Ай алыштыра.
Кайдандыр галәм түреннән
йолдыз нуры агып тора.

Болытлар килә,
болытлар китә -
томанлы юллар адаштыра.
Өмет йолдызы
яктылыгыннан
күңелем түремдә балкыш тора.

Туры юллар,
урау юллар
аера һәм кавыштыра.
Өмет дигән йолдыз сүнсә
кайгыларга сабыштыра.

Болытлар килә,
болытлар китә -
томанлы юллар адаштыра.
Өмет йолдызы
яктылыгыннан
күңелем түремдә балкыш тора.
```

# Перевод

### Ренат Харис / Эльмир Низамов - Звезда надежды

```
Ветры дуют,
воды текут,
луну сменяет солнце.
Откуда-то из глубины вселенной
льётся звёздный свет.

Облака приходят,
облака уходят -
туманные дороги сбивают с пути.
От света
звезды надежды
в глубине моей души стоит сияние.

Прямые дороги,
извилистые дороги
разлучают и соединяют.
Если погаснет звезда по имени надежда,
она бросит в печали.

Облака приходят,
облака уходят -
туманные дороги сбивают с пути.
От света
звезды надежды
в глубине моей души стоит сияние.
```
