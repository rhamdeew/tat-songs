# Оригинал

### Разим Вәлиуллин / Таһир Асылгәрәй - Камыш сылу

```
Һай, камыш сылукай
Җырлале, моң булсын.

Сагышлар ярасын
Басарлык җыр тусын.

Камышым, сылуым
Кубызлар кушылсын.

Яшь кызлар ушыннан
Язарлык җыр тусын.

Кураем, уйнале
Егетләр ут алсын.

Очкыннар чәчрәтеп
Биерлек көй калсын.

Камышым сылуым
Сыз да сыз төрлесен.

Әбиләр - апайлар,
Агайлар - бабайлар,
Малайлар - шалайлар
Барсыда биесен.
```

# Перевод

### Разим Вәлиуллин / Тахир Асылгараев - Камыш красавица

```
Ой, камыш красавица,
Пойте, пусть звучит мелодия.

Пусть скорби утихнут,
Звучать способная песня пусть родится.

Мой камыш, моя красавица,
Пусть кубызы зазвучат.

Ради молодых девушек
Слагаемая песня пусть народится.

Мой курай, играй,
Парни пусть загорятся.

Искры разбрасывая,
Танцевальная мелодия пусть зазвучит.

Мой камыш, моя красавица,
Играй да играй по-разному.

Бабушки - тётушки,
Дяди - дедушки,
Парни - ребята,
Все пусть танцуют.
```
