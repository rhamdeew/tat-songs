# Оригинал

### Билгесез - Кашка тау

```
Туган авылым тау битендә,
Утлары якты яна.
Безне сагынып кайтканны,
Көтеп торалар әнә.

Корсак буе сагындыра,
Сагындыра Кашка тау.
Кайтырбыз сиңа авылым,
Булаек без исән сау.

Авылымнан илһам алам,
Күңелләр канатлана.
Туган җирләр онытылмый,
Йөрәкләрдә саклана.

Корсак буе сагындыра,
Сагындыра Кашка тау.
Кайтырбыз сиңа авылым,
Булаек без исән сау.

Корсак суында коенып,
Чишмәләрдән су эчәм.
Өяңкәләргә, талларга,
Йәшлек серемне чишәм.

Корсак буе сагындыра,
Сагындыра Кашка тау.
Кайтырбыз сиңа авылым,
Булаек без исән сау.

Сандугачлы язгы кичтә
Күктә сердәш ай йөзә.
Сагышлы гармун тавышы,
Әй, үзәкләрне өзә.

Корсак буе сагындыра,
Сагындыра Кашка тау.
Кайтырбыз сиңа авылым,
Булаек без исән сау.
```

# Перевод

### Билгесез - Кашка тау

```
Родная деревня моя на склоне горы,
Огни её ярко горят.
Те, кто скучает и возвращается к нам,
Ждут вон там.

По берегам Корсака скучаю,
Скучаю по Кашка тау.
Вернемся к тебе, деревня моя,
Пусть будем мы здоровы и живы.

И вдохновенье беру я из деревни,
Сердца расправляют крылья.
Родные земли не забываются,
В сердцах они хранятся.

По берегам Корсака скучаю,
Скучаю по Кашка тау.
Вернемся к тебе, деревня моя,
Пусть будем мы здоровы и живы.

Купаясь в воде Корсака,
Пью из родника воду.
Клёнам, ивам,
Открываю я молодости тайну.

По берегам Корсака скучаю,
Скучаю по Кашка тау.
Вернемся к тебе, деревня моя,
Пусть будем мы здоровы и живы.

Весенним вечером с соловьями
По небу плывёт луна-наперсница.
Гармонь тоскливая поет,
Да, душу разрывает.

По берегам Корсака скучаю,
Скучаю по Кашка тау.
Вернемся к тебе, деревня моя,
Пусть будем мы здоровы и живы.
```
