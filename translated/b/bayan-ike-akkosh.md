# Оригинал

### Ә.Баян / Б.Гайсин - ИКЕ АККОШ

```
Һаваларда оча ике аккош,

Каурыйлары җиргә коела.

Янып сөйгән күңел канатлана,

Мәңге талмас кебек тоела.
Һаваларда очкан ике аккош

Аерылмыйча яшәр гел бергә.

Без очарбыз бәхет киңлегендә

Синең белән икәү гомергә.
Һаваларда очкан ике аккош

Талгын гына канат кагына.

Әллә нигә, бергә чакларда да

Күңелем һаман сине сагына.
Һаваларда очкан ике аккош,

Еракларга китә моңнары.

Киләчәккә аккош юлы булып

Китсен безнең яшьлек еллары.
```

# Перевод

### Э.Баян / Б.Гайсин - Два лебедя

```
В небесах летят два лебедя,
Их перья падают на землю.
Пылко влюблённая душа окрыляется,
Кажется, что вовеки не устанет.

Два лебедя, летящих в небе,
Будут жить вечно вместе, неразлучно.
Мы будем летать в просторах счастья
С тобой вдвоём всю жизнь.

Два лебедя, летящих в небе,
Плавно взмахивают крыльями.
Почему-то даже когда мы вместе,
Душа моя всё равно тоскует по тебе.

Два лебедя, летящих в небе,
Их напевы уносятся вдаль.
Пусть же наши годы юности
Уйдут в будущее лебединым путём.
```
