# Оригинал

### Башкорт халык җыры - Карабай* (өченче вариант)

```
Там, там, тамчы, там,
Тамганыңны яратам.
Синең тамганыңны карап,
Күңелемне юуатам.

Иртә дә кил, кич тә кил,
Тәрәзәмне чиртә кил.
Чиртүеңнән танырмын да
Каршы чыгып алырмын.

Ике килен - килендәш,
Берсе ялкау, берсе яшь.
Тарак юк дип җавап бирә
Чәч тарарга иренгәч.

* - шул көйне иҗат итүче курайчының исеме
```

# Перевод

### Башкирская народная песня - Карабай* (третий вариант)

```
Там, там, капля, там,
Родинку твою люблю.
На родинку твою глядя,
Утешаю свою душу.

Рано приди, поздно приди,
В окно моё постучи.
По стуку узнаю тебя
И выйду навстречу, встречу.

Две невестки, роднёй друг другу,
Одна ленива, другая молода.
Отвечает, что гребня нет,
Когда лень ей волосы расчесать.

* - имя композитора этой мелодии
```
