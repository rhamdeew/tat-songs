# Оригинал

### Барый Ногманов / Абрар Габдрахманов - Кара күзләр (икенче вариант)

```
Өздереп, көйдереп карады кара күзләр,
Өзелгән сөюне ялгады кара күзләр;
Ак нур сипте, ак нур сипте гүя
Таң йолдызы, таң йолдызы миңа.

Йөрәкләр талпынып, тартылды ничә еллар,
Юлларны аерып, кагылды искән җилләр;
Тик хис кенә, тик хис кенә ташты,
Моң күңелдән, моң күңелдән акты.

Мөлдерәп, сагышым чайпылыр чагы иде,
Язмышым язлыкмый очратты тагы сине:
Ак нур сибеп, ак нур сибеп яна
Кара күзләрең, кара күзләрең бага.
```

# Перевод

### Барый Ногманов / Абрар Габдрахманов - Чёрные глаза (альтернативная версия)

```
Разрывая, обжигая, глядели чёрные глаза,
Оборванную любовь вновь соединили чёрные глаза;
Белый свет пролили, белый свет пролили, будто
Утренняя звезда, утренняя звезда, на меня.

Сердца, трепеща, тянулись друг к другу сколько лет,
Пути разделяя, касались повеявшие ветра;
Лишь чувство одно, лишь чувство одно перелилось,
Тоска из души, тоска из души струилась.

Тоскуя, чаша печали моей была готова перелиться,
Судьба моя нежданно вновь свела меня с тобой:
Белый свет изливая, белый свет изливая, горят
Твои чёрные глаза, твои чёрные глаза, глядя.
```
