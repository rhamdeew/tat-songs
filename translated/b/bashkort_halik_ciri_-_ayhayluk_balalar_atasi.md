# Оригинал

### Башкорт халык җыры - Әйһәйлүк (Балалар атасы)

```
Иртәнчәккәй торып, тышка чыксам,
Әйһәйлүк,
Бер кыз килә сыер да, ай һәүкәләп,
һәпем, һәпәүләкәем.
Бер аз гына торып сөйләшкәнчә,
Әйһәйлүк,
Карт анасы йөри шул, ай һәүкәләп,
һәпем, һәпәүләкәем.
Сызылып кына чыккан, мыегымны,
Әйһәйлүк,
Кызлар сорый чәчмәүдә, әй, чугына,
һәпем, һәпәүләкәем.
Сызылып кына чыккан, мыегымны,
Әйһәйлүк,
Вәгъдә иттем сөйгән дә кызыма,
һәпем, һәпәүләкәйем.
```

# Перевод

### Башкирская народная песня - Айхайлюк (Отец детей)

```
Встав утром пораньше, выйду наружу,
Айхайлюк,
Девушка идёт, гоня корову, ай, покачиваясь,
хэпем, хэпэвлякэем.
Не успев и немного поговорить,
Айхайлюк,
Старая мать идет следом, ай, покачиваясь,
хэпем, хэпэвлякэем.
Только пробился мой ус,
Айхайлюк,
Девушки о нём спрашивают, ай, о кисточке его,
хэпем, хэпэвлякэем.
Только пробился мой ус,
Айхайлюк,
Обещал я любимой своей девушке,
хэпем, хэпэвлякэйем.
```
