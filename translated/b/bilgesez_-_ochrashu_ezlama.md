# Оригинал

### Билгесез - Очрашу эзләмә

```
Еллар аркылы
Килдең кичегеп,
Үткән сөюне
Искә төшереп.
Кабат очрашу
Кирәкме икән?
Олы хисләрне,
Уятып, иркәм?!

Булып кал бары
Яшьлек ялгышым,
Күңел түремдә -
Назым, сагышым
Эзләмә мине,
Хәзер без үткән.
Гомерләр үткән,
Соң инде, иркәм...

Әйләнеп кайтмас,
Яшьлек тә - үткән.
Тәүге сөюләр...
Беренче үпкән...
Тормыш йомгагын
Инде без сүткән.
Язмышта безне
Башкалар көткән...

Булып кал бары
Яшьлек ялгышым,
Күңел түремдә -
Назым, сагышым
Эзләмә мине,
Хәзер без үткән.
Гомерләр үткән,
Соң инде, иркәм...
```

# Перевод

### Билгесез - Не искәтеп очрашу

```
Через года
Ты пришла с опозданием,
Напомнив
Прошлую любовь.
Нужна ли встреча
Снова?
Разве пробуждать
Сильные чувства?!

Останься просто
Моя молодая ошибка,
В моём сердце -
Моя нежность, тоска
Не ищи меня,
Сейчас мы прошли.
Жизни прошли,
Уже поздно, любимая моя...

Не вернётся,
Молодость тоже прошла.
Первая любовь...
Первый поцелуй...
Клубок жизни
Мы уже размотали.
Другие ждут нас
В судьбе...

Останься просто
Моя молодая ошибка,
В моём сердце -
Моя нежность, тоска
Не ищи меня,
Сейчас мы прошли.
Жизни прошли,
Уже поздно, любимая моя...
```
