# Оригинал

### Башкорт халык җыры - Таулар биек (икенче вариант)

```
Таулар биек, таулар биек,
Таулар биек менәргә.
Бачкычлар юк, бачкычлар юк,
Шул тауларга менәргә.

Болындагы чәчәкләрне
Тапамам дигән идем.
Туып үскән авылымны
Ташламам дигән идем.

Болындагы чәчәкләрне
Тапарга туры килде.
Туып үскән авылымны
Ташларга туры килде.
```

# Перевод

### Башкирская народная песня - Высокие горы (второй вариант)

```
Горы высоки, горы высоки,
Горы высоки, взойти.
Лестниц нет, лестниц нет,
На те горы взойти.

Цветы на лугу
Не растопчу, говорил я.
Село, где вырос
Не оставлю, говорил я.

Цветы на лугу
Пришлось растоптать.
Село, где вырос
Пришлось оставить.
```
