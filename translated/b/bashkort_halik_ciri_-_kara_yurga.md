# Оригинал

### Башкорт халык җыры - Кара юрга

```
Йомры матур тоягыңны
Дагаларбыз, юргам.
Кырач матур ялларыңны
Укаларбыз, юргам.
Өстеңдәге сылыуыңны
Төшерәле, юргам
Һайт, кара юргам,
Тайт, кара юргам.

Башыңдагы йөгәнеңне
Көмешләрбез, юргам,
Кара-кырпу үңдегеңне
Нагышларбыз, юргам.
Өстеңдәге сылыуыңны
Төшерәле, юргам.
Һайт, кара юргам,
Тайт, кара юргам.
```

# Перевод

### Башкирская народная песня - Черный журавль

```
Твоё круглое красивое копытце
Подкуём, мой иноходец.
Твою жёсткую красивую гриву
Разошьём тесьмой, мой иноходец.
Красавицу, что на тебе,
Ссадим наземь, мой иноходец.
Гей, вороной мой иноходец,
Эх, вороной мой иноходец.

Уздечку твою на голове
Посеребрим, мой иноходец,
Твою чёрно-гладкую масть
Разукрасим узором, мой иноходец.
Красавицу, что на тебе,
Ссадим наземь, мой иноходец.
Гей, вороной мой иноходец,
Эх, вороной мой иноходец.
```
