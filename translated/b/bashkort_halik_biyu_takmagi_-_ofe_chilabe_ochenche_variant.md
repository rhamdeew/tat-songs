# Оригинал

### Башкорт халык бию такмагы - Өфе - Өфе - Өфе - Чиләбе (өченче вариант)

```
Ардагы дуслык юлын,
Без корычтан салабыз.

Өфе, Чиләбе,
Пешә кура җиләге.

Дәртле җырлар җырлый-җырлый
Без шул юлдан барабыз.

Өфе, Чиләбе,
Пешә кура җиләге.

Бергәләшеп эшләгәндә,
Җиңел юллар табыла.

Өфе, Чиләбе,
Пешә кура җиләге.

Тормыш юлын үзгәртәек,
Яңыртаек тагын да.

Өфе, Чиләбе,
Пешә кура җиләге.
```

# Перевод

### Народный танец башкир - Уфа - Уфа - Уфа - Челабинск (третий вариант)

```
Дорогу дружбы, что впереди,
Мы сталью сложим.

Уфа, Челябинск,
Поспевает ягода малины.

Песни задорные поём-поём,
Мы по той дороге идём.

Уфа, Челябинск,
Поспевает ягода малины.

Вместе работая,
Лёгкие тропинки находим.

Уфа, Челябинск,
Поспевает ягода малины.

Путь жизни изменяем,
Ещё больше обновляем.

Уфа, Челябинск,
Поспевает ягода малины.
```
