# Оригинал

### Татар халык җыры - БИК ЕРАКТА ИДЕК БЕЗ

```
Ай, әле бик еракта идек без,

Җитмеш чакрым җирне килдек без.

Ак калфакның табылган чагы*.

Ак калфакның табылган чагы,

Туганнарның сагынган чагы.

Җитмеш чакрымны якын итеп без,

Бер күрешер өчен килдек без.

Ак калфакның табылган чагы.

Ак калфакның табылган чагы,

Туганнарның сагынган чагы.
```

# Перевод

### Татарская народная песня - Мы были очень далеко

```
Ай, мы были ещё очень далеко,
Семьдесят вёрст земли мы прошли.
Пора, когда нашёлся белый калфак.
Пора, когда нашёлся белый калфак,
Пора, когда родные соскучились.

Семьдесят вёрст сочтя близкими,
Мы пришли, чтобы хоть раз повидаться.
Пора, когда нашёлся белый калфак.
Пора, когда нашёлся белый калфак,
Пора, когда родные соскучились.
```
