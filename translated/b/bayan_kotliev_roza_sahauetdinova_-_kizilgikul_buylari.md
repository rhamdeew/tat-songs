# Оригинал

### Баян Котлыев / Роза Сәхәүетдинова - Кызылгыкүл буйлары

```
Кызылгыкүл сулары,
Яшел тугай буйлары.
Кошлар моңы бөдрә таллар да.

Ташкын сулар аккач,
Балан чәчәк аткач.
Күлгә киләм йөрәк талган да.

Кызылгыкүл язлары,
Табигатьнең назлары.
Күлдә казлар язга куана.

Төшләремдә күрдем,
Син аккошы күлнең.
Сабыр йөрәк көтә, юана.

Кызылгыкүл буйларын,
Күп тирәкле юлларын.
Бергә үтәр идек тагын да.

Бик сагындым иркәм,
Ерак юлга китәм.
Юксынырмын ялгыз чагымда.
```

# Перевод

### Баян Котлиев / Роза Сахаутдинова - Берега Кызылгика

```
Кызылгыкүл сулары,
Яшел тугай буйлары.
Кошлар моңы бөдрә таллар да.

Ташкын сулар аккач,
Балан чәчәк аткач.
Күлгә киләм йөрәк талган да.

Кызылгыкүл язлары,
Табигатьнең назлары.
Күлдә казлар язга куана.

Төшләремдә күрдем,
Син аккошы күлнең.
Сабыр йөрәк көтә, юана.

Кызылгыкүл буйларын,
Күп тирәкле юлларын.
Бергә үтәр идек тагын да.

Бик сагындым иркәм,
Ерак юлга китәм.
Юксынырмын ялгыз чагымда.

Воды Кызылгика,
Зелёные берега поймы.
Тоскующий напев птиц и кудрявые ивы.

Когда полые воды текут,
Когда калина расцветает.
Я приду к озеру, сердце уставшее.

Вёсны Кызылгика,
Ласки природы.
Гуси на озере радуются весне.

Во сне я видел,
Ты - лебедь озера.
Терпеливое сердце ждёт, утешается.

По берегам Кызылгика,
По тополиным дорогам.
Вместе пройдём ещё раз.

Очень соскучился, родной,
Ухожу в далёкий путь.
Буду тосковать в одиночестве.
```
