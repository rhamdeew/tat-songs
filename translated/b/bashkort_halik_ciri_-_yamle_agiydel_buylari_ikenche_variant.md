# Оригинал

### Башкорт халык җыры - Ямьле Агыйдел буйлары (икенче вариант)

```
Агыйделкәйләрнең, ай, кичкәндә
Бер җырладым ишкәкләр ишкәндә.

Ямьле Агыйдел буйлары ла
Бетерәдер хәсрәтле уйларны.

Бер җырладым, бәгърем, бер еладым
Туган җирләр искә лә төшкәндә.

Ямьле Агыйдел буйлары ла
Бетерәдер хәсрәтле уйларны.
```

# Перевод

### Башкирская народная песня - Берега Ямель-Агидель (второй вариант)

```
Переправляясь через Агидель, ай,
Спел я песню, вёслами гребя.

Красивые берега Агидели
Развеют тоскливые мысли.

Спел я песню, любимая, поплакал,
Когда вспомнил родные края.

Красивые берега Агидели
Развеют тоскливые мысли.
```
