# Оригинал

### Башкорт халык җыры - Карабай* (икенче вариант)

```
Җилфер-җилфер җил исә,
Җитен тамырын җил кисә.
Егет үсә, кыз үсә, һай,
Егет күңелен кыз өзә.

Әллиләү генәем,
Бәллиләү генәем,
Кара карлыгачкаем да,
Сары сандугачкаем.

Әллиләү генәем,
Бәллиләү генәем,
Әсмәбикә тыпырдатып
Биеп килә генәем.

Өй түрендә бакчада,
Син тирәк булсаң иде.
Шул тирәкнең төпләрендә
Мин җиләк булсам иде.

Иртә дә кил, кич тә кил,
Тәрәзәмне чиртә кил.
Чиртүеңнән танырмын да
Каршы чыгып алырмын.

* - шул көйне иҗат итүче курайчының исеме
```

# Перевод

### Башкирская народная песня - Карабай* (второй вариант)

```
Дует, дует ветер,
Ветер срезает корни льна.
Юноша растёт, девушка растёт, ох,
Девушка похищает сердце юноши.

Я только Аллила,
Я только Баллила,
Чёрная ласточка моя,
Жёлтый соловей мой.

Я только Аллила,
Я только Баллила,
Асмабика, притопывая,
Танцуя, идёт.

В саду за домом,
Если бы ты был тополем.
У подножия этого тополя
Я бы стала земляникой.

Приходи утром и вечером,
Стучи в моё окно.
По стуку твоему узнаю
И выйду навстречу.

* - имя музыканта, создавшего эту мелодию
```
