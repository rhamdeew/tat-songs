# Оригинал

### Билгесез - Ачы балан

```
Өй түрендәге баланны
Кисмә - ярамас, балам.
Язмышыңа кагылмасын
Балан ачысы, балам.

Балакаем, балан ачы,
Ашама, берүк, өзеп.
Ачы баланның тәмнәре
Гомергә калыр сеңеп.

Озакламас карлар явар,
Җыя торчы баланын.
Язмыш юлы якты булсын,
Әй, Ходаем, баламның.

Балакаем, балан ачы,
Ашама, берүк, өзеп.
Ачы баланның тәмнәре
Гомергә калыр сеңеп.

Балан ачы булса да ул,
Чәчәге матур аның.
Авыр чакта ярдәм сузган,
Онытма, Ходай барын.

Балакаем, балан ачы,
Ашама, берүк, өзеп.
Ачы баланның тәмнәре
Гомергә калыр сеңеп.
```

# Перевод

### Билгесез - Горькое дитя

```
Калину в красном углу дома
Не режь — нельзя, дитя моё.
Пусть не коснётся твоей судьбы
Горечь калины, дитя моё.

Дитятко моё, калина горька,
Не ешь её, сорвав.
Вкус горькой калины
Останется навек, впитавшись в память.

Скоро пойдут снега,
Собирай же свою калину.
Пусть путь судьбы будет светлым,
О, Боже мой, моего дитя.

Дитятко моё, калина горька,
Не ешь её, сорвав.
Вкус горькой калины
Останется навек, впитавшись в память.

Хоть калина и горька,
Цветок её красив.
В трудный час протянула помощь,
Не забывай, что есть Господь.

Дитятко моё, калина горька,
Не ешь её, сорвав.
Вкус горькой калины
Останется навек, впитавшись в память.
```
