# Оригинал

### Башкорт халык җыры - Уел (беренче вариант)

```
Әрәмәгә керсәм, үлән сирәк,
Сахраларга чыксам, җир җиләк;
Эчемдә генә минем утлар яна,
Ник җилкенә икән бу йөрәк?

Ай-һай гына диеп бер кычкырсам,
Яңгырыйдыр кыя ташлары;
Табылмаган дөнья малы өчен
Каңгырыйдыр егет башлары.

Арыслан ла киек, ай, алдырмас,
Каршысында биек тау булса;
Егет тә генә кеше һич кайгырмас,
Газиз башы аның сау булса.
```

# Перевод

### Башкирская народная песня - Уэл (первый вариант)

```
Если войду в чащу, травы редки,
Если выйду в степи — земляника;
Только внутри меня горят огни,
Почему же трепещет это сердце?

Если крикну я только «ай-яй»,
Отзываются эхом скальные камни;
Из-за ненайденного мирского богатства
Скитаются головы юношей.

Лев тоже дикий зверь, ай, не даст себя одолеть,
Если перед ним высокая гора;
Юноша тоже лишь человек, никогда не тужит,
Если цела его драгоценная голова.
```
