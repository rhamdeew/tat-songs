# Оригинал

### Башкорт халык җыры - Уел (өченче вариант)

```
Ике лә генә егет печән чаба
Уел буйкаенда ла чабында.
Кайда ла гына йүреми, ниләр күрми
Ир-егеткәй исән дә чагында.

Менгән генә атым, ай, кир булыр,
Тибенгесе аның да тир булыр.
Урал буйкаеның асыл егете
Данкайлары чыгыр да ир булыр.

Уелып кына аккан Уел суы
Уйландыра уйчан да ирләрне,
Уйландырып калмый, моңландыра,
Сагындыра туган да җирләрне.
```

# Перевод

### Башкирская народная песня - Уйал (третий вариант)

```
Только двое парней косят сено
Вдоль берегов Уйала косят.
Где ни бродит, чего ни видит,
Пока молодец жив-здоров.

Конь мой лишь вскочу — будет диким,
Стремя его тоже в поту будет.
Настоящий юноша с берегов Урала
Прославится и станет мужчиной.

Просто текущие воды Уйала
Задумчиво настроили мужчин,
Не оставляя в покое, томительно,
Тоскуют по родным землям.
```
