# Оригинал

### Билгесез - Егет без

```
Ачы бураннарда,
Куе томаннарда,
Давылларда җилкән кебек без.
Җиһаннан нур алган,
Нигезләрдә калган,
Милләт өчен янган егет без...

Авылда чыныккан,
Көлмәгән сыныктан,
Тормыш арбасында дегет без.
Дөньяны агарткан,
Үз илен яраткан,
"Яшим" дип жан аткан егет без.

Үз йөзен саклаган,
Ышаныч аклаган,
Асылташлы, нурлы йөзек без.
Тормыш юлларында,
Гомер елларында,
Тарихларга керер өзек без.

Авылда чыныккан,
Көлмәгән сыныктан,
Тормыш арбасында дегет без.
```
