# Оригинал

### Башкорт халык җыры - Хәтирә (беренче вариант)

```
Капка төбендә торасың,*
Нечкә билең бөгәсең, Хәтирәм,
Нечкә билләреңне бөгеп,
Кем өчен өзеләсең, Хәтирәм? (Кемнең эчен өзәсең, Хәтирәм!)

Без урамнан үткән чакта,
Капкаң булсын кагарга, Хәтирәм,
Бер дә хәйлә табалмасаң,
Чык тәрәзә ябарга, Хәтирәм,

Аллы гөлле чәчәк бирсәм,
Кадарсыңмы түшеңә, Хәтирәм?
Кич ятканда уйлап ятам,
Кермәссеңме төшемә, Хәтирәм?

* - һәр юлы ике кабатлана
```

# Перевод

### Башкирская народная песня - Хатиля (первый вариант)

```
Ты стоишь у ворот,*
Сгибаешь тонкий стан, Хатиля,
Сгибая тонкий стан,
Для кого ты тоскуешь, Хатиля? (Чьё сердце ты разрываешь, Хатиля!)

Когда мы проходим по улице,
Пусть будут твои ворота, чтоб постучать, Хатиля,
Если ты не найдешь никакого выхода,
Выйди и закрой окно, Хатиля,

Если подарю тебе пёстрый цветок,
Приколешь ли его на грудь, Хатиля?
Лежа в постели вечером, думаю,
Не войдешь ли ты в мой сон, Хатиля?

* - каждый раз повторяется дважды
```
