# Оригинал

### Баян Котлыев / Нур Даутов - Хуш инде тугаем

```
Эй, тургаем, киң тугаем,
Ак чәчәкле юлларың.
Ак чәчәкләр кебек калдың,
Безнең яшьлек еллары.

Хуш инде тугаем,
Елда кайт тургаем.
Тагы да, ояга, тирәккә.
Туган як тугае,
Һава да тургае,
Моң-зары сызыла йөрәккә.

Эй, тургаем, тугаемны,
Тошләремдә буйладым.
Моңнарыңны изге уйга,
Кайтыр юлга юрадым.

Хуш инде тугаем,
Елда кайт тургаем.
Тагы да, ояга, тирәккә.
Туган як тугае,
Һава да тургае,
Моң-зары сызыла йөрәккә.

Эй, тургаем, күңелемдә,
Мәңге яшәр тугаем.
Кабат чакыр яшьлегемә,
Сайра-сайра тургаем.

Хуш инде тугаем,
Елда кайт тургаем.
Тагы да, ояга, тирәккә.
Туган як тугае,
Һава да тургае,
Моң-зары сызыла йөрәккә.
```

# Перевод

### Баян Котлиев / Нур Даутов - С тобой мы просыпаемся

```
Эй, жаворонок мой, мой широкий луг,
Дороги твои в белых цветах.
Остались, словно белые цветы,
Наши годы молодости.

Прощай же, луг мой,
Возвращайся каждый год, жаворонок мой.
Снова - к гнезду, к тополю.
Луг родного края,
Жаворонок небес,
Тоска-печаль отзывается в сердце.

Эй, жаворонок мой, луг мой,
Я прошёл тобою в своих снах.
Твои напевы в святую мысль,
Предсказал я как дорогу возвращения.

Прощай же, луг мой,
Возвращайся каждый год, жаворонок мой.
Снова - к гнезду, к тополю.
Луг родного края,
Жаворонок небес,
Тоска-печаль отзывается в сердце.

Эй, жаворонок мой, в моей душе,
Вечно будет жить мой луг.
Позови снова в мою юность,
Распевая, распевая, жаворонок мой.

Прощай же, луг мой,
Возвращайся каждый год, жаворонок мой.
Снова - к гнезду, к тополю.
Луг родного края,
Жаворонок небес,
Тоска-печаль отзывается в сердце.
```
