# Оригинал

### Фаил Шәфигуллин / Фәрит Хатыйпов - Яз җыры (өченче вариант)

```
Офыкка кара әле -
Көн белән төн кавышкан.
Серләрен тыңла әле -
Сайрар кошлар табышкан.

Ташлап китмә,
Мәхрүм итмә,
Мине татлы сагыштан.
Бәлки бу
Моңлы җыр
Сагыштан
Тугандыр...

Карасана, күрсәнә -
Бөтен җиһан яңарган.
Яшь бөре исе килә
Тирәкләрдән, таллардан.

Ташлап китмә,
Мәхрүм итмә,
Мине язгы таңнардан.
Бәлки бу
Моңлы җыр
Таңнардан
Тугандыр?

Тәрәзәмнең төбендә
Яран гөл яфрак ярган.
Йөрәгемнең түрендә
Җырланмаган җыр калган.

Ташлап китмә,
Мәхрүм итмә,
Мине назлы җырлардан.
Бәлки бу
Моңлы җыр
Сөюдән
Тугандыр?..
```

# Перевод

### Фаиль Шафигуллин / Фарит Хатыпов - Песня лета (третий вариант)

```
Посмотри на горизонт -
День с ночью переплелись.
Послушай их тайну -
Певчие птицы спелись.

Не уходи,
Не отвергай,
Меня от сладкой тоски.
Возможно, эта
Задушевная песня
Родилась
Из тоски...

Посмотри, оглянись -
Весь мир обновился.
Молодых почек запах
Идёт с тополей, с ив.

Не уходи,
Не отвергай,
Меня от весенних зорь.
Возможно, эта
Задушевная песня
Родилась
Из зорь?

Под моим окном
Роза листок пустила.
В глубине моего сердца
Неспетая песня осталась.

Не уходи,
Не отвергай,
Меня от нежных песен.
Возможно, эта
Задушевная песня
От любви
Родилась?..
```
