# Оригинал

### Фатыйх Кәрим / Әнвәр Бакиров - Сагындым (беренче вариант)

```
Идел буйларына тагын
Әйләнеп кайтсам иде,
Ал чәчәкләр арасында
Бер җырлап ятсам иде.

Җир җиләге белән мине
Иркәм сыйласа иде,
Элеккечә бер иркәләп,
Башым сыйпаса иде.
```

# Перевод

### Фатыйх Карим / Анвар Бакиров - Соскучился (первый вариант)

```
Вернуться бы опять
К берегам Идели,
Среди алых цветов
Полежать бы, напевая песню.

Чтоб земляникой меня
Угостила любимая,
Как прежде, приласкав,
Погладила бы голову мою.
```
