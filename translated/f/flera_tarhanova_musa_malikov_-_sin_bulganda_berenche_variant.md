# Оригинал

### Флера Тарханова / Муса Маликов - Син булганда (беренче вариант)

```
Син булганда чиксез рәхәт миңа -
Күзләремдә - яшәү чаткысы;
Яратуның бу илаһи көчен
Тик саклыйсы иде, саклыйсы!

Син булганда, күгем балкый минем -
Дөньям тула якты хис белән;
Үбеп озатуым иртә таңнан
Бәхет булып кайта кич белән.

Син булганда җаным тыныч минем -
Тоям һәрчак синең терәкне;
Күргән газапларым төссезләнә -
Телеп-телеп алмый йөрәкне.

Син булганда, күгем балкый минем -
Дөньям тула якты хис белән;
Үбеп озатуым иртә таңнан
Бәхет булып кайта кич белән.
Син булганда, күгем балкый минем -
Дөньям тула якты хис белән;
Үбеп озатуым иртә таңнан
Бәхет булып кайта кич белән.
Бәхет булып кайта кич белән...
```

# Перевод

### Флера Тарханова / Муса Маликов - Когда ты рядом (первый вариант)

```
Когда ты рядом - бесконечный покой для меня -
В моих глазах - вспышка жизни;
Эту божественную силу любви
Только береги, береги!

Когда ты рядом, мое небо светлеет -
Мир мой наполняется ярким чувством;
Провожаю, целуя, рано утром -
Счастьем это возвращается к вечеру.

Когда ты рядом, душа моя спокойна -
Всегда чувствую твою поддержку;
Мои пережитые муки блекнут -
Не терзают, не режут сердце.
```
