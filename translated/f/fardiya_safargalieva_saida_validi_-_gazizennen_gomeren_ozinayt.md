# Оригинал

### Фәрдия Сәфәргалиева / Сәидә Вәлиди - Газизеңнең гомерен озынайт

```
Кулың болгап калдың су буенда,
Ярның бу ягына чыкмадың.
Яулык алып күз яшеңне сөрттең,
Еладың шул, түзмәдең...

Ерак димә, ара ерак димә,
Туган йортка юлны эзләп тап.
Чал чәчләрен сыйпап әнкәеңнең,
Газизеңнең гомерен озынайт.

Кулың болгап калдың су буенда,
«Хәерле юл сиңа, балам», - дип.
Мин карадым борылып, кул болгадым,
Кабатладым: «Тиздән кайтам», - дип.

Ерак димә, ара ерак димә,
Туган йортка юлны эзләп тап.
Чал чәчләрен сыйпап әнкәеңнең,
Газизеңнең гомерен озынайт.
```

# Перевод

### Фардия Сефаргалиева / Саида Валиди - Продлит жизнь твоего дорогого человека

```
Осталась ты, махая рукой, у воды,
На эту сторону берега не вышла.
Платком вытерла слёзы свои,
Плакала, не могла успокоиться...

Не говори «далеко», не говори «путь далёк»,
Найди дорогу к родному дому.
Гладя поседевшие волосы твоей матери,
Продлишь жизнь твоего близкого.

Осталась ты, махая рукой, у воды,
«Счастливого пути тебе, дитя моё», - сказала.
Я обернулся, махнул рукой,
Повторил: «Скоро вернусь».

Не говори «далеко», не говори «путь далёк»,
Найди дорогу к родному дому.
Гладя поседевшие волосы твоей матери,
Продлишь жизнь твоего близкого.
```
