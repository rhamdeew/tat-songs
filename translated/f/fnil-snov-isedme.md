# Оригинал

### Фәнил Әсәнов / Тәлгать Шәрипов - ИСЕҢДӘМЕ?

```
Исеңдәме, иркәм,

Таныштык без икәү,

Җылы яктан кошлар кайтканда.

Көннәр аяз иде,

Күңелдә яз иде

Яшьлегебез чәчәк атканда,

Яшьлегебез чәчәк атканда.
Гөлләр үскән Димдә

Синең белән бергә

Каршыладык күпме язларны?!

Кошлар җырын тыңлап,

Тугайларны буйлап,

Чәчәкләрдән җыйдык назларны,

Чәчәкләрдән җыйдык назларны.
Язлар бик тиз үтә,

Көзен кошлар китә...

Минутларны куып Дим ага.

Кошлар белән бергә,

Еллар очып үтә,

Әллә күңел шуңа моңлана,

Әллә күңел шуңа моңлана.
```

# Перевод

### Фаниль Асанов / Талгать Шарипов - Помнишь ли?

```
Помнишь ли, родная,

Мы познакомились с тобой,

Когда птицы прилетали из тёплых краёв.

Дни были ясные,

В душе была весна,

Когда цвела наша юность,

Когда цвела наша юность.
На Деме, где растут цветы,

Сколько вёсен

Мы встретили вместе с тобой?!

Слушая пение птиц,

Гуляя вдоль пойменных лугов,

Мы собирали ласки из цветов,

Мы собирали ласки из цветов.
Вёсны проходят очень быстро,

Осенью птицы улетают...

Дема течёт, обгоняя минуты.

Вместе с птицами

Пролетают годы,

То ли поэтому душа грустит,

То ли поэтому душа грустит.
```
