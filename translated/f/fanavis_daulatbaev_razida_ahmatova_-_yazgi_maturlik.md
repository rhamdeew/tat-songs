# Оригинал

### Фәнәвис Дәүләтбаев / Рәзидә Әхмәтова - Язгы матурлык

```
Чәчәккә күмелде, күмелде
Шомыртлар, сиреньнәр.
Җаннарны сихерли, сихерли
Туган җир, синең ямь!

Кыр, алан, болыннар, болыннар
Яшелдән киенә.
Тәбигать яшәрә, яшәрә,
Күңелләр сөенә.

Тыңлап шул туймаслык, туймаслык
Кошларның сайравын.
Тылсымы язларның - язларның -
Агыла җанда моң.

Кыр, алан, болыннар, болыннар
Яшелдән киенә.
Тәбигать яшәрә, яшәрә,
Күңелләр сөенә.

Үләннәр өстенә, өстенә
Чәчәкләр сибелгән.
Яратып туймаслык, туймаслык
Туган җир, синең ямь!

Кыр, алан, болыннар, болыннар
Яшелдән киенә.
Тәбигать яшәрә, яшәрә,
Күңелләр сөенә.
```

# Перевод

```
Цветами покрылись, покрылись
Черёмухи, сирень.
Души околдовает, околдовает
Родная земля, твоя краса!

Поле, луг, равнины, равнины
Зеленью наряжаются.
Природа оживает, оживает,
Сердца ликуют.

Не наслушаться, не наслушаться
Птичьего пения.
Волшебство весны - весны -
По душе стелется тоска.

Поле, луг, равнины, равнины
Зеленью наряжаются.
Природа оживает, оживает,
Сердца ликуют.

Над травами, над травами
Цветы рассыпались.
Не налюбуюсь, не налюбуюсь
Родная земля, твоя краса!

Поле, луг, равнины, равнины
Зеленью наряжаются.
Природа оживает, оживает,
Сердца ликуют.
```
