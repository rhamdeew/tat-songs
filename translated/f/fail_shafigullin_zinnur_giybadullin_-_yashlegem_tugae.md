# Оригинал

### Фаил Шәфигуллин / Зиннур Гыйбадуллин - Яшьлегем тугае

```
Ничәнче мәртәбә
Нурланып яз килде,
Тургайлар канатын кагынды.
Күзләрең сагышлы,
Дип әйтте бер тургай,
Нишлим соң, тургаем, сагындым.

Ничәнче мәртәбә
Тургайлар килделәр.
Тугайлар яшәрде, ямьләнде.
Өздереп сайрады,
Сайрады бер тургай,
Читендер сагыну хәлләре.

Өздереп сайрама,
Хәлемне сорама -
Ул үзе аңлар бер, тургаем.
Минем күк сагынып,
Кайтыр ул, тургаем:
Онытмас яшьлеге тугаен.
```

# Перевод

### Фаиль Шафигуллин / Зиннур Гибадуллин - Мой юный тугай

```
В который уже раз
Пришла весна, сияя,
Жаворонки крыльями взмахнули.
Глаза твои полны тоски —
Сказал один жаворонок.
Что мне делать, мой жаворонок, — затосковал я.

В который уже раз
Прилетели жаворонки.
Тугаи зазеленели, похорошели.
Надрывно пел,
Пел один жаворонок —
Тяжелы муки тоски.

Не пой надрывно,
Не спрашивай о моём состоянии —
Она сама поймёт когда-нибудь, мой жаворонок.
Тоскуя по мне,
Вернётся она, мой жаворонок:
Не забудет тугай своей юности.
```
