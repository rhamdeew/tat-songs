# Оригинал

### Фәнәвис Дәүләтбаев / Рәсимә Денисламова - Гашыйклар көне

```
Җан яраткан кешесенә
Күңел тартыла.
Чын гашыйклар утка керә
Сөю хакына.

Йөрәкләрнең мәхәббәтне
Ачыклар көне.
Араларны якынайтсын
Гашыйклар көне!

Күңелләрне ташламасын
Ярату хисе.
Шат уйларда,тойгыларда
Яшәсен кеше.

Йөрәкләрнең мәхәббәтне
Ачыклар көне.
Араларны якынайтсын
Гашыйклар көне!

Шашып типсен, ярсып типсен
Йөрәкләр бергә.
Чын ихластан яратулар
Булсын гомергә!

Йөрәкләрнең мәхәббәтне
Ачыклар көне.
Араларны якынайтсын
Гашыйклар көне!
```

# Перевод

### Фәнәвис Дәүләтбаев / Рәсимә Денисламова - День влюблённых

```
Душа тянется к любимому человеку,
Сердце зовёт.
Настоящие влюблённые в огонь входят
Ради права любить.

День, когда сердца
Открывают любовь.
Пусть сблизит расстояния
День влюблённых!

Пусть чувство любви
Не покидает сердца.
Пусть человек живёт
В счастливых мыслях, в чувствах.

День, когда сердца
Открывают любовь.
Пусть сблизит расстояния
День влюблённых!

Пусть бьются неистово, пусть бьются страстно,
Вместе сердца.
Пусть настоящая любовь
Пребудет на всю жизнь!

День, когда сердца
Открывают любовь.
Пусть сблизит расстояния
День влюблённых!
```
