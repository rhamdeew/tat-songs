# Оригинал

### Фирая Зыятдинова / Луиза Батыр-Болгари - Бердәнберем син минем

```
Алтыным ла син, диеп,
Ялкыным ла син, диеп
Үстерәм бәбкәемне
Иркәләп, сөеп.
Улыкаем син минем,
Юлыма нур сибүче
Бәхетем минем.
Бәлли-бәү, бәлли-бәү.

Син минем ышанычым,
Бердәнберем дигәнем;
Син - бөркетем, лачыным,
Илгә бүләгем.
Матур булып үсәрсең,
Батыр булып үсәрсең,
Ак өметем син минем,
Бәхетем минем.
Бәлли-бәү, бәлли-бәү,
Бәлли-бәү, бәлли-бәү.
```

# Перевод

### Фирая Зыятдинова / Луиза Батыр-Болгари - Ты моя единственная

```
Ты моё золото, говорю,
Ты моё пламя, говорю,
Ращу своё дитя,
Лаская и любя.
Ты мой сыночек,
Свет, озаряющий мой путь,
Моё счастье.
Баю-бай, баю-бай.

Ты моя надежда,
Мой единственный, говорю;
Ты мой орёл, мой сокол,
Мой подарок стране.
Вырастешь красивым,
Вырастешь смелым,
Ты моя светлая надежда,
Моё счастье.
Баю-бай, баю-бай,
Баю-бай, баю-бай.
```
