# Оригинал

### Фәнәвис Дәүләтбаев / Рәсимә Денисламова - Асылкошым - Асылкошым - Асылкошым - сандугачым

```
Асылкошым минем - сандугачым,
Ничәнче кат сиңа талпынам.
Йөрәгемдә булган сөю хисен
Әйтергә соң никләр тартынам?

Асылкошым минем - сандугачым,
Уйларымда сине чакырам.
Күңелемә рәхәт булып китә
Күрмәсәм дә сине якыннан.

Асылкошым минем - сандугачым,
Күз алдымда һәрчак буй-сының.
Хыялымда синең белән яшим,
Тоясыңмы икән син шуны?

Асылкошым минем - сандугачым,
Күңел кат-кат сиңа тартыла.
Мин күптәннән үлеп гашыйк сиңа,
Тик әйтергә генә тартынам.
```

# Перевод

### Фанавис Давлетбаев / Рассимя Денисламова - Милый моя - Милый моя - Милый моя - соловей мой

```
Милый моя - соловей мой,
Который раз к тебе стремлюсь.
Чувство любви, что в моем сердце,
Почему же стесняюсь сказать?

Милый моя - соловей мой,
В мыслях своих зову тебя.
Душе становится отрадно,
Даже если не вижу тебя вблизи.

Милый моя - соловей мой,
Перед глазами всегда твой образ.
В мечтах живу с тобой,
Чувствуешь ли ты это?

Милый моя - соловей мой,
Душа снова и снова к тебе тянется.
Я уже давно безумно влюблена в тебя,
Только сказать стесняюсь.
```
