# Оригинал

### Хәйдәр Бигичев - Галиябану

```
Татар халык җыры

Тәрәзәдән карыйсың ла,

Карап кемне таныйсың?

Карап күзең талдырганчы,

Галиябану, сылуым иркәм,

Ник чакырып алмыйсың?

Тәрәзәңне ачып куеп,

Кемгә күлмәк кистең син?

Кара кашым, карлыгачым,

Галиябану, сылуым иркәм,.

Кем бәхетенә үстең син?

Тәрәзә төбем каты бал,

Ашыйсың килсә, ватып ал;

Сөюләрең чыннан булса,

Галиябану, сылуым иркәм,

Тәрәзәдән тартып ал.
```

# Перевод

###  - Галиябану

```
Татарская народная песня

Смотришь ты в своё окно,
Кого же ты там узнаёшь?
Чем глазам своим уставать, глядя,
Галиябану, красавица, родная моя,
Почему не позовёшь меня к себе?

Открыв своё окно,
Кому ты платье шила?
Чернобровая моя, ласточка моя,
Галиябану, красавица, родная моя,
Для чьего счастья ты выросла?

Подоконник мой — твёрдый мёд,
Если хочешь отведать — разбей и возьми;
Если любовь твоя настоящая,
Галиябану, красавица, родная моя,
Через окно меня к себе притяни.
```
