# Оригинал

### Гөлшат Зәйнәшева / Мөфтәдин Гыйләҗев - Туган көн вальсы (икенче вариант)

```
Котлап сине туган көнеңдә
Алтын кояш сибә нурларын.
Кояш балкыган язгы иртәдәй,
Якты булсын, якты булсын
Тормыш юлларың.

Яшьлегебез матур булганга,
Матур җырлар килә күңелгә.
Мактап яшьлекнең матур таңнарын
Җырла, дускай, җырла, дускай,
Туган көнеңдә.

Шаулап-гөрләп сүнмәс дәрт белән
Шат җыр булып яшә син җирдә.
Туган көнеңдә тагын бер теләк:
Мәңге яшь бул, мәңге яшь бул,
Картайма бер дә.
```

# Перевод

### Гөлшат Зайнашева / Мөфтәдин Гыйләҗев - Вальс дня рождения (второй вариант)

```
Поздравляя в твой день рождения,
Солнце золотое льёт лучи.
Словно ясное весеннее утро,
Светлыми, светлыми
Пусть будут твои пути.

Оттого что юность наша прекрасна,
Красивые песни в душу приходят.
Воспевая рассветы юности,
Пой, дружок, пой, дружок,
В день рождения твой.

Шумно-гулко, с неугасающей страстью
Живи на земле, как радостная песня.
В день рождения ещё одно желание:
Будь вечно молод, будь вечно молод,
Никогда не старей.
```
