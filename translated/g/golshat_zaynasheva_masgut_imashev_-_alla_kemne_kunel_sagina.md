# Оригинал

### Гөлшат Зәйнәшева / Мәсгут Имашев - Әллә кемне күңел сагына

```
Йөгереп кенә төштем су буена,
Ялгыз аккош канат кагына.
Канатларым өзелеп,
Бәгырьләрем сызылып,
Әллә кемне күңел сагына.
Җәйге кичтә карыйм зәңгәр күккә,
Ай нурлана, йолдыз кабына.
Еллар буе көтеп,
Кавышу өмет итеп,
Әллә кемне күңел сагына.
Бер ялгызың калып, моңайганда
Җырлыйм дисәң - җырлар табыла.
Бер утырып җырлыйм,
Бер утырып елыйм,
Әллә кемне күңел сагына.
Әллә кемне күңел сагына...
```

# Перевод

### Гөлшат Зайнашева / Мәсгут Имашев - Сердце тоскует по кому-то

```
Сбежала к реке я, торопясь бегом,
Одинокий лебедь бьёт крылом.
Крылья мои надломлены,
Нутро моё изнывает,
По кому-то душа тоскует.
В летний вечер в синее небо гляжу,
Луна сияет, звезда зажигается.
Годами ожидая,
Надеясь на встречу,
По кому-то душа тоскует.
В одиночестве, когда нападёт тоска,
Захочешь петь — и песни найдутся.
То сижу и пою,
То сижу и плачу,
По кому-то душа тоскует.
По кому-то душа тоскует...
```
