# Оригинал

### Г.Зәйнәшева / Ч.Зиннәтуллина - АЕРЫЛМАГЫЗ

```
Су буенда ялгыз аккош,

Каерылган канатлары;

Канатларны каера ул

Аерылу газаплары.
Кушымта:
Аерылмагыз, аерылмагыз,
Булса да сәбәпләре.

Канатларны каера ул

Аерылу сәгатьләре.

Ят кошны пар итмәс аккош,

Ялгыз канат какса да.

Без дә бергә булалмабыз,

Сулар үргә акса да.
Кушымта.
Ялгыз аккош күргән саен

Өзелә бәгырьләрем.

Нигә соң бергә чакларның

Белмәдек кадерләрен?
Кушымта.
```

# Перевод

### Г.Зэйнэшева / Ч.Зиннэтуллина - Не расставайтесь

```
На берегу реки одинокий лебедь,

Его крылья надломлены;

Крылья ему надламывают

Муки расставания.
Припев:
Не расставайтесь, не расставайтесь,
Даже если есть причины.

Крылья ему надламывают

Часы расставания.

Не станет лебедь парой чужой птице,

Даже взмахивая одиноким крылом.

И мы не сможем быть вместе,

Даже если реки потекут вспять.
Припев.
Каждый раз, видя одинокого лебедя,

Рвётся моё сердце.

Почему же мы не знали цены

Тем временам, когда были вместе?
Припев.
```
