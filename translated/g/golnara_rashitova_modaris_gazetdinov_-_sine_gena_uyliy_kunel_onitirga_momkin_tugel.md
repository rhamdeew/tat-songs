# Оригинал

### Гөлнара Рәшитова / Мөдәрис Газетдинов - Сине генә уйлый күңел (Онытырга мөмкин түгел)

```
Оныттың да мени дисең,
Үпкә катыш һәрбер сүзең,
Сагыш тулы ике күзең,
Яралы кош сыман үзең.

Онытырга мөмкин түгел,
Сине генә уйлый күңел!
Син дип тибә минем йөрәк,
Бары тик син миңа кирәк!

Яудырасың катлы-катлы
Сорауларың бер-бер артлы.
Барысына тик бер җавап:
Яратамын сине чынлап!

Онытырга мөмкин түгел,
Сине генә уйлый күңел!
Син дип тибә минем йөрәк,
Бары тик син миңа кирәк!

Күрми торсам өннәремдә,
Керәсең син төшләремә.
Үпкәләмә бервакыт та,
Онытмадым синең хакта.

Онытырга мөмкин түгел,
Сине генә уйлый күңел!
Син дип тибә минем йөрәк,
Бары тик син миңа кирәк!
```

# Перевод

### Гульнара Рахимова / Мударис Газетдинов - Душа думает только о тебе (Забыть невозможно)

```
Ты говоришь: «Забыл, что ли?»,
Каждое слово твоё полно обиды,
Глаза твои полны тоски,
Ты словно раненая птица.

Забыть невозможно,
Душа думает только о тебе!
Сердце зовёт тебя,
Только ты мне и нужен!

Сыплешь ты вопрос за вопросом,
Один за другим вопросы твои.
На всё один ответ:
Я люблю тебя искренне!

Забыть невозможно,
Душа думает только о тебе!
Сердце зовёт тебя,
Только ты мне и нужен!

Если наяву не вижу тебя,
Ты входишь в мои сны.
Не обижайся никогда,
Я не забыл о тебе.

Забыть невозможно,
Душа думает только о тебе!
Сердце зовёт тебя,
Только ты мне и нужен!
```
