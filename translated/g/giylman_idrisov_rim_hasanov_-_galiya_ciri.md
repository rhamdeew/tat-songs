# Оригинал

### Гыйльман Идрисов / Рим Хәсәнов - Галия җыры

```
Айның якты нуры җиргә атылганда,
Чәчләремнән сыйпап җилләр искәндә.
Хисләр ташый микән
Яшьли сөйгән ярым
Тәүге умырзая бүләк иткәндә?

Сәлам белән бергә, хатлар китерсәләр
Үтеп киткән язның кипкән гөлләрен.
һәр тибеше саен йөрәк көтә микән
Тиздән килеп җитәр кавышу көннәре.
```

# Перевод

### Гыйльман Идрисов / Рим Хәсәнов - Песня Галии

```
Когда ясный лунный свет льётся на землю,
Когда ветры гладят мои волосы,
Не переполняются ли чувства,
Когда любимый, которого я полюбила в юности,
Дарит первый подснежник?

Если вместе с приветом письма принесут
Засохшие цветы ушедшей весны,
Не ждёт ли сердце с каждым ударом
Скорого наступления дней встречи?
```
