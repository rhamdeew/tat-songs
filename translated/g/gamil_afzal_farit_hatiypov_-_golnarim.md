# Оригинал

### Гамил Афзал / Фәрит Хатыйпов - Гөлнарым

```
Сандугачтай сайрап уйнадың да
Кына гөлләренә кунмадың.
Гөлнарым,
Үкенечкә ярым булмадың.

Яулыгыңны болгап җырладың да
Йөрәкләрне телде моңнарың.
Гөлнарым,
Борылмалы киткән юлларың.

Сине сагынып уйлар уйладым да
Чишмә буйларыннан урадым.
Гөлнарым,
Күз алдымда зифа буйларың
```

# Перевод

### Гамил Афзал / Фарит Хатыпов - Гөлнарым

```
Ты, как соловей, резвилась и пела,
Но на цветы хны не присела.
Гөлнарым,
Ты так и не стала моей — лишь сожаление.

Ты, махая платочком, выводила песню,
Твои напевы сердца разрезали.
Гөлнарым,
Извилисты ушедшие дороги твои.

Тоскуя по тебе, думал я думы,
Кружил вдоль родниковых берегов.
Гөлнарым,
Перед глазами — твой стройный стан.
```
