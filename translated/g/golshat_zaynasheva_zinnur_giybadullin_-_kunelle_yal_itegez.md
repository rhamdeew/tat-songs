# Оригинал

### Гөлшат Зәйнәшева / Зиннур Гыйбадуллин - Күңелле ял итегез

```
Ал шәфәкътә, алтын сыман
Кызарып, кояш бата.
Йолдызларга көлемсерәп,
Зәңгәр күктә ай калка.

Эштә үткәндер көнегез,
Ямьле булсын кичегез.
Ай сокланып йөрсен күктә,
Күңелле ял итегез.

Йөрәкләрне җилкендереп,
Яңгырый гармун чыңы.
Әйдә, дустым, вальс биик,
Ардырмыйк гармунчыны.

Очып әйләнәсе килә,
Яшьлекне канат итеп.
Таңны каршылыйсы килә,
Йолдызга барып җитеп!
```

# Перевод

### Гөлшат Зәйнәшева / Зиннур Гыйбадуллин - Веселого отдыха

```
В алой заре, словно золото,
Краснея, садится солнце.
Улыбаясь звёздам,
В синем небе восходит луна.

День ваш, наверное, прошёл в труде,
Пусть красивым будет ваш вечер.
Пусть луна любуется в небе,
Отдыхайте весело.

Будоража сердца,
Звучит звон гармони.
Давай, друг мой, станцуем вальс,
Не будем утомлять гармониста.

Хочется кружиться в полёте,
Сделав молодость крыльями.
Хочется встретить рассвет,
Долетев до звезды!
```
