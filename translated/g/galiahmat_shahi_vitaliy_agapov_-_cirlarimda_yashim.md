# Оригинал

### Галиәхмәт Шаһи / Виталий Агапов - Җырларымда яшим

```
Урман төшкән сагышларга,
Көзнең сулышын тоеп.
Усак җиргә келәм җәйгән,
Төсле яфраклар коеп.

Кайчан сугар, кайда сугар
Йөрәгемдәге яшен?
Бу дөньяда бер яшәсәм,
Җырларымда мең яшим.

Каен белән өрәңге дә
Сары ялкын эчендә.
Сирин яфраклары гына
Җәйдәге үз төсендә.

Кайчан сугар, кайда сугар
Йөрәгемдәге яшен?
Бу дөньяда бер яшәсәм,
Җырларымда мең яшим.

Вакыт җиткәч, көзләр килә,
Куеп булмый киртәләр.
Ачы җилләр туган якны
Көзгә куып кертәләр.

Кайчан сугар, кайда сугар
Йөрәгемдәге яшен?
Бу дөньяда бер яшәсәм,
Җырларымда мең яшим.

Күңелемә алтын көзләр
Шигъри илһамын сала.
Йөрәгемнең бер кисәге
Үткән җәйләрдә кала.

Кайчан сугар, кайда сугар
Йөрәгемдәге яшен?
Бу дөньяда бер яшәсәм,
Җырларымда мең яшим.
```

# Перевод

### Галиәхмәт Шаһи / Виталий Агапов - Я живу в моих песнях

```
В лес опускаются тоски,
Ощущая дыхание осени.
Осина расстелила на земле ковёр,
Рассыпая разноцветные листья.

Когда ударит, где ударит
Молния в моём сердце?
Хоть в этом мире живу лишь раз,
В песнях моих живу тысячу раз.

Берёза с клёном тоже
Внутри жёлтого пламени.
Только листья сирени
В своём летнем цвете.

Когда ударит, где ударит
Молния в моём сердце?
Хоть в этом мире живу лишь раз,
В песнях моих живу тысячу раз.

Когда приходит время, приходят осени,
Нельзя поставить преграды.
Холодные ветра гонят
Родной край в осень.

Когда ударит, где ударит
Молния в моём сердце?
Хоть в этом мире живу лишь раз,
В песнях моих живу тысячу раз.

Золотые осени в моём сердце
Приносят поэтическое вдохновение.
Одна часть моего сердца
Остается в прошедших летах.

Когда ударит, где ударит
Молния в моём сердце?
Хоть в этом мире живу лишь раз,
В песнях моих живу тысячу раз.
```
