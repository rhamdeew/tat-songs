# Оригинал

### Гөлнур Куатова / Гүзәллия Хәкимҗанова - Үз юлым белән киләм

```
Сукмак салып бу тормышка
Үз юлым белән киләм.
Кайгылларда елап калам,
Бәхеткә ихлас көләм.

Минем дә бар, синең дә бар, -
Бу тормышта үз юлың.
Язмышта бит биреп тора -
Бер сулакай, бер уңын.

Кеше эзе миңа түгел,
Үземнеке - үземә.
Ялгышлар да, уңышлар да,
Канат бирә күңелгә.

Минем дә бар, синең дә бар, -
Бу тормышта үз юлың.
Язмышта бит биреп тора -
Бер сулакай, бер уңын.

Алга барам, юллар ярам,
Туктап калу ярамый.
Язмыш бит ул төрле хәлдә
Кешене сынып карый.

Минем дә бар, синең дә бар, -
Бу тормышта үз юлың.
Язмышта бит биреп тора -
Бер сулакай, бер уңын.
```

# Перевод

### Гульнар Куватова / Гузель Хакимжанова - Приду по своей дороге

```
След оставляя в этой жизни,
По своей дороге иду.
В горестях слёзы лью, оставаясь,
Счастью искренне смеюсь.

У тебя есть, у меня есть -
Своя дорога в жизни.
Ведь судьба чередует всегда -
То провал, то удачу.

Чужой след не для меня,
Свой - для себя.
Ошибки и успехи тоже
Крылья душевные.

У тебя есть, у меня есть -
Своя дорога в жизни.
Ведь судьба чередует всегда -
То провал, то удачу.

Иду вперёд, дороги пробиваю,
Останавливаться не годится.
Ведь судьба в разных обстоятельствах
Испытывает человека.

У тебя есть, у меня есть -
Своя дорога в жизни.
Ведь судьба чередует всегда -
То провал, то удачу.
```
