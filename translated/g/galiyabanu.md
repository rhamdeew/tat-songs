# Оригинал

### Татар халык җыры - ГАЛИЯБАНУ

```
Тәрәзәдән карыйсың ла,

Карап кемне таныйсың?

Карап күзең талдырганчы,

Галиябануым, сылуым, иркәм,

Ник чакырып алмыйсың?

Тәрәзәңне ачып куеп

Кемгә күлмәк кистең син?

Кара кашым, карлыгачым,

Галиябануым, сылуым, иркәм,

Кем бәхетенә үстең син?

Тәрәзә төбем каты бал,

Ашыйсың килсә ватып ал.

Сөюләрең чыннан булса,

Галиябануым, сылуым, иркәм,

Тәрәзәдән тартып ал.

Читән аша төшкән чакта

Бүрәнәгә абындым.

Минуты ай, сәгате ел,

Галиябануым, сылуым, иркәм,

Шул кадәрле сагындым.
```

# Перевод

### Татарская народная песня - Галиябану

```
Смотришь ты из окна,
Глядя, кого узнаёшь?
Пока не утомишь глаза, глядя,
Галиябану моя, красавица моя, любимая моя,
Почему не позовёшь меня?

Открыв своё окно,
Кому платье кроила ты?
Чернобровая моя, ласточка моя,
Галиябану моя, красавица моя, любимая моя,
Для чьего счастья выросла ты?

На моём подоконнике – твёрдый мёд,
Если захочешь есть, отломи и возьми.
Если твоя любовь настоящая,
Галиябану моя, красавица моя, любимая моя,
Через окно возьми меня.

Когда перелезал через плетень,
Споткнулся о бревно.
Минута – как месяц, час – как год,
Галиябану моя, красавица моя, любимая моя,
Настолько я соскучился.
```
