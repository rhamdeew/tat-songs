# Оригинал

### Гөлшат Зәйнәшева / Азат Хөсәенов - Куаныч күле

```
Куаныч күле кайда? -
Идел буе тугайда.
Идел буенда йөрдек,
Куаныч күлен күрдек.

И Куаныч күлләре,
Тирән булган элгәре.
Суы беткән, саеккан,
Шуңа күрә боеккан.

И Куаныч күлләре,
Күл читендә гөлләре.
Күл буйлары ямансу,
Килмәгән кыр үрдәге!..

Җыйналыйк җөй көннәрне,
Чистартыйк без күлләрне.
Тирән булса Куаныч,
Безгә булыр юаныч!
```

# Перевод

### Гульшат Зайнашева / Азат Хусаинов - Озеро радости

```
Где же озеро Радости? -
В пойменном лугу у Волги.
Мы гуляли на берегу Волги,
Озеро Радости видели.

О, озёра Радости,
Глубокими были прежде.
Вода иссякла, обмелело,
Потому и загрустило оно.

О, озёра Радости,
На краю озера - цветы.
Берега озера печальны,
Не прилетела полевая утка!..

Соберёмся в летние дни,
Очистим мы озёра.
Если глубоким будет Куаныч,
Будет нам утешением!
```
