# Оригинал

### Габдельфат Сафин - Ялгыз парлылар

```
Безнен бэхет шулай корылган
Бэхетлэргэ сою уралган
Парлыларга ап-ак мэхэббэт
Телэм, телэм итеп туралган

Чибэрлэрне чибэр яратыр
Сою урманын каратыр
Монсуланып калган ялгызларга
Бэхет жебен кемнэр таратыр

Бэхетлелэр йори парланып
Сою урманына алданып
Э ялгызлар кала ишен котеп
Килер диеп сою алданып

Чибэрлэрне чибэр яратыр
Сою урманын каратыр
Монсуланып калган ялгызларга
Бэхет жебен кемнэр таратыр

Ялгызларны куру кызганыч
Ялгыз калу конен аяныч
Парлыларны сою назлаганда
Аларны сон кемнэр яратыр

Чибэрлэрне чибэр яратыр
Сою урманын каратыр
Монсуланып калган ялгызларга
Бэхет жебен кемнэр таратыр?
```

# Перевод

### Габдельфат Сафин - Одинокие красавицы

```
Наше счастье так устроено,
К счастливым любовь притягивается,
Парам белоснежная любовь
Желанная, желанная скроена.

Красивых любят красивые,
Любовный лес осматривают,
Печальным одиноким девушкам
Кто нить счастья раздаст?

Счастливые ходят парами,
Любовным лесом обольщаясь,
А одинокие остаются в надежде,
Что придёт любовь, обманываясь.

Красивых любят красивые,
Любовный лес осматривают,
Печальным одиноким девушкам
Кто нить счастья раздаст?

Одиноких - жалость пустая,
Одинокой остаться - горе.
Когда любовь пары балует,
Их (одиноких) потом кто полюбит?

Красивых любят красивые,
Любовный лес осматривают,
Печальным одиноким девушкам
Кто нить счастья раздаст?
```
