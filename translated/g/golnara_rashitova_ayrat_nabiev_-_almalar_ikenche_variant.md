# Оригинал

### Гөлнара Рәшитова / Айрат Нәбиев - Алмалар (икенче вариант)

```
Алмалар үсә икән,
Өзелеп төшә икән.
Алма кебек дуслар барда
Күңелләр үсә икән.

Алмалары ал гына,
Тәмләп кара, бал гына.
Дуслар белән аралашу
Күңелләрдә ял гына.

Алмалар уңган икән,
Бәхеткә булган икән.
Серләремне бүлешердәй
Дуслар табылган икән.

Алмалары ал гына,
Тәмләп кара, бал гына.
Дуслар белән аралашу
Күңелләрдә ял гына.

Алмаларны өзәрбез,
Өстәлләргә тезәрбез.
Дуслар белән бу дөньяларда
Дәрьяларны гизәрбез.

Алмалары ал гына,
Тәмләп кара, бал гына.
Дуслар белән аралашу
Күңелләрдә ял гына.
```

# Перевод

### Гульнара Рашитова / Айрат Набиев - Яблоки (второй вариант)

```
Яблоки, оказывается, растут,
Созрев, падают с ветвей.
Когда есть друзья, подобные яблокам,
И душа, оказывается, расцветает.

Яблоки такие румяные,
Попробуй на вкус - чистый мёд.
Общение с друзьями
Для души - настоящий отдых.

Яблоки, оказывается, поспели,
На счастье они уродились.
Нашлись друзья,
С которыми можно делиться тайнами.

Яблоки такие румяные,
Попробуй на вкус - чистый мёд.
Общение с друзьями
Для души - настоящий отдых.

Яблоки мы сорвём,
Разложим их на столах.
С друзьями в этом мире
Будем странствовать по морям.

Яблоки такие румяные,
Попробуй на вкус - чистый мёд.
Общение с друзьями
Для души - настоящий отдых.
```
