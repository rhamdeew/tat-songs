# Оригинал

### Г.Зәйнәшева / Татар халык - ТАЛЬЯН ГАРМУН (яңа)

```
Уйна тальян гармуныңны,

Яшьлек әрәм узмасын шул;

Моңсызлар да бер моңлансын,

Йөрәкләре сызлансын.
Уйна тальян гармуныңны,

Телләре лә батмасын шул,

Уят үзәкләрен өзеп,

Кызлар йоклап ятмасын.
Уйна тальян гармуныңны

Безнең авыл көенә лә;

Тәрәз саен моңнар тулып

Керсен авыл өенә.
Уйна тальян гармуныңны,

Егетләр җырлап үтсен шул;

Туган авылыннан киткәннәр

Ишетсә яшен түксен.
```

# Перевод

### Г.Зэйнэшева / Татар халык - Тальянка (новая)

```
Играй на своей тальянке-гармони,

Пусть юность не пройдёт впустую;

Пусть и те, кто без напева, затоскуют,

Пусть заноют их сердца.
Играй на своей тальянке-гармони,

Пусть не умолкнут её язычки,

Разбуди самое нутро,

Пусть девушки не спят.
Играй на своей тальянке-гармони

И на мотив нашей деревни;

Пусть напевы, наполнив каждое окно,

Войдут в дома деревни.
Играй на своей тальянке-гармони,

Пусть парни пройдут с песней;

Пусть те, кто уехал из родной деревни,

Услышав, прольют слёзы.
```
