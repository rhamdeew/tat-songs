# Оригинал

### Габделхак Шәмсетдинов / Зөфәр Хәйретдинов - Оныт инде...

```
Оныт инде мине мәңгелеккә,
Йөрәгеңнән алып ташла да...
Гафу итмә мине, гафу итмә -
Алыштырдым сине башкага.

Кичер, димим, очрашулар эзләп
Юлларыңа чыкмыйм хәзер мин...
Мәңге төзәнмәслек яра булып
Йөрәгемдә калдың, кадерлем.

Ялгышларым сагышларга салды.
Мин һаман да сине юксынам...
Бу дөньяда синнән кадерлерәк,
Синнән якын һичкем юк сыман.

Оныт инде мине мәңгелеккә,
Йөрәгеңнән алып ташла да...
Гафу итмә мине, гафу итмә -
Алыштырдым сине башкага.
```

# Перевод

### Габделхак Шәмсетдинов / Зуфар Хайретдинов - Забудь меня...

```
Забудь меня навечно,
Вычеркни из сердца...
Не прощай меня, не прощай -
Я заменил тебя другой.

Не скажу «прости», ища встреч
На твои пути не выйду я...
Навсегда оставшись болью
В моем сердце ты остался, милый.

Мои ошибки повергли меня в тоску.
Я всё ещё тоскую по тебе...
В этом мире дороже тебя,
Ближе тебя, кажется, нет никого.

Забудь меня навечно,
Вычеркни из сердца...
Не прощай меня, не прощай -
Я заменил тебя другой.
```
