# Оригинал

### Г.Зәйнәшева / З.Исмәгыйлов - САГЫНЫРМЫН УРАЛ ТАУ БУЙЛАРЫН

```
Сагынырмын Урал тау буйларын,

Тын кичләрен, курай моңнарын.

Сагынырмын алсу таң атканда

Яңгыраган башкорт җырларын.
Буйларында Урал тауларының

Чәчәк атты яшьлек елларым.

Кая гына китеп яшәсәм дә,

Урал, сине мактап җырлармын.
```

# Перевод

### Г.Зэйнэшева / З.Исмэгыйлов - Буду скучать по склонам Уральских гор

```
Буду тосковать по склонам Уральских гор,
По тихим вечерам, по напевам курая.
Буду тосковать по башкирским песням,
Что звучали на алой заре.

На склонах Уральских гор
Расцвели годы моей юности.
Куда бы я ни уехал жить,
Урал, буду петь, восхваляя тебя.
```
