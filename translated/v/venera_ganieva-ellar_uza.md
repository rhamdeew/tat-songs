# Оригинал

### Венера Ганиева - Еллар уза

```
Еллар чаба, арымый,
Артка таба карамый.
Яшьлек кала кул болгап,
Гузэл таннарын уйлап.

Козлэр килэ дэ житэ,
Йорэк язларны котэ.
Уткэн яшьлек тугайлары
Мине сагынып котэ.

Кала буранлы кышлар,
Язга урам нык назлар.
Сунмэс ометлэр кала,
Гомер дигэн ат чаба.

Козлэр килэ дэ житэ,
Йорэк язларны котэ.
Уткэн яшьлек тугайлары
Мине сагынып котэ.

Еллар чакыра алга,
Матур бэхетле танга.
Йорэк яна, ашкына,
Исэн булсын баш кына.

Козлэр килэ дэ житэ,
Йорэк язларны котэ.
Уткэн яшьлек тугайлары
Мине сагынып котэ.
```

# Перевод

### Венера Ганиева - Годы проходят

```
Годы бегут, не устают,
Назад не оглядываются.
Юность остается, рукой махнув,
Вспоминая прекрасные рассветы.

Осени приходят, настают,
Сердце ждёт вёсны.
Прошедшей юности луга
Скучают по мне.

Остаются вьюжные зимы,
Весной улица сильно нежится.
Остаются негасимые надежды,
Скачет конь по имени жизнь.

Осени приходят, настают,
Сердце ждёт вёсны.
Прошедшей юности луга
Скучают по мне.

Годы зовут вперед,
К прекрасному счастливому рассвету.
Сердце горит, стремится,
Пусть только голова остается здоровой.

Осени приходят, настают,
Сердце ждёт вёсны.
Прошедшей юности луга
Скучают по мне.
```
