# Оригинал

### Лилия Биктимерова - Озата барма

```
Татар халык җыры

Озата барма, иркәм, озата барма,

Олы юл бит, бәлки адашмам.

Синең серле зәңгәр күзләреңне

Башка күзләр белән алмашмам.

Озата барма, иркәм, кайталмассың,

Сүзең барыбер әйтә алмассың.

Сөям дигән йомшак сүзең белән

Күңелемне юата алмассың.

Озата барып, иркәм, кайткан чакта,

Хәтфә чәчәкләрен таптама.

Вакытлыча гына озаткан булып,

Яшь йөрәккәемә ут салма.
```

# Перевод

###  - Не провожай

```
Татарская народная песня

Не провожай меня, любимый, не провожай,

Ведь дорога дальняя, может, не заблужусь.

Твои таинственные синие глаза

Не заменю другими глазами.

Не провожай, любимый, не сможешь вернуться,

Слова своего всё равно не сможешь сказать.

Мягким словом «люблю»

Не сможешь утешить мою душу.

Проводив меня и возвращаясь, любимый,

Не топчи бархатные цветы.

Проводив меня лишь на время,

Не разжигай огонь в моём молодом сердце.
```
