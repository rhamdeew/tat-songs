# Оригинал

### Гүзәл Уразова - Оча курмә

```
Тан калып торам,

Очар кошларны куреп.

Офыклар читенэ чыгам

Юлларын кузлэрмен дип

Ялгыш юллар сайласан

Пар канатсыз каласын, кошлар белэн..

Юлларын кургэннэргэ

Ярата белгэннэргэ, бэхет колэ...

Юлларын сорамыйм

Очмыйча торалмый кунел генэ...

Турем тулы яра

Янган утка таба, оча курмэ...

Син ялгыш анлама

Эйлэнечтэн юл туры

Без генэ жинэ торган

Сынаулар белэн тулы

Ялгыш юллар сайласан

Пар канатсыз каласын, куклэр белэн...

Сынаулар уткэннэргэ

Сагынып коткэннэргэ, бэхет колэ...

Юлларын сорамыйм

Очмыйча торалмый кунел генэ...

Турем тулы яра

Янган утка таба, оча курмэ...
```

# Перевод

### Гузал Уразова - Не смотри, как улетает

```
Стою, удивляясь,

Видя летящих птиц.

Выхожу к краю горизонта,

Чтобы проследить их путь.

Если выберешь неверный путь,

Останешься без пары крыльев, вместе с птицами...

Тем, кто видел их путь,

Тем, кто умел любить, улыбается счастье...

Не спрашиваю про путь,

Лишь душа не может не лететь...

Грудь моя полна раны,

Не улетай к горящему огню...

Ты не пойми неправильно,

От кружения путь прямой.

Лишь мы способны преодолеть

Полное испытаний.

Если выберешь неверный путь,

Останешься без пары крыльев, вместе с небесами...

Тем, кто прошёл испытания,

Тем, кто ждал, тоскуя, улыбается счастье...

Не спрашиваю про путь,

Лишь душа не может не лететь...

Грудь моя полна раны,

Не улетай к горящему огню...
```
