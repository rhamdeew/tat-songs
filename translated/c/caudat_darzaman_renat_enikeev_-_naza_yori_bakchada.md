# Оригинал

### Җәүдәт Дәрзаман / Ренат Еникеев - Наза йөри бакчада

```
Кояш күптəн батса да,
Наза йөри бакчада.
Су сибə чилəк-чилəк,
Авыз эченнəн көйлəп:

«Чəчəклəрем ал булсын,
Бал кортына бал булсын.
Үзем эшлим барын да -
Əниемə ял булсын».

Сузылып яр буена,
Чəчəклəр су коена.
Зур тамчы китсə тиеп,
Куялар биеп-биеп.
```

# Перевод

### 

```
Хоть солнце давно зашло,
Наза всё ходит в саду.
Поливает ведро за ведром,
Тихонько напевая:

«Пусть мои цветы будут алыми,
Пусть для пчёл в них будет мёд.
Я сама всё сделаю -
Пусть мама отдохнёт».

Вытянувшись вдоль берега,
Цветы купаются в воде.
Стоит крупной капле задеть их -
И они пускаются в пляс.
```
