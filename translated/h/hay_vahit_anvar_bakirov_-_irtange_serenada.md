# Оригинал

### Хәй Вахит / Әнвәр Бакиров - Иртәнге серенада

```
Күмелгәнсең ак мамык мендәргә,
Толымнарың җәеп син, иркәм.
Сине өзелеп сагынып,
Сөю белән янып,
Тәрәзәңне чиртәм мин иртән.

Вакыт инде... Уян, иркәм, уян,
Керфегеңне күтәр, күзең ач!
Нинди гүзәл ал таң,
Нурлар сибә чулпан,
Тал-тирәктә сайрый сандугач.

Шатлык көен сузып, бар табигать
Көтә сине - гөлләр иркәсен.
Уян, иркәм, уян,
Тан нуры белән ян,
Каршы алыйк без эш иртән!

Вакыт инде... Уян, иркәм, уян,
Керфегеңне күтәр, күзең ач!
Нинди гүзәл ал таң,
Нурлар сибә чулпан,
Тал-тирәктә сайрый сандугач.
```

# Перевод

### Хай Вахит / Анвар Бакиров - Утренняя серенада

```
Ты зарылась в белые пуховые подушки,
Раскинув косы свои, любимая.
Тоскуя по тебе всё сильней,
Горя любовью,
Утром в окно к тебе стучу.

Пора уже... Проснись, любимая, проснись,
Подними ресницы, открой глаза!
Как прекрасен алый рассвет,
Рассыпает лучи Чулпан,
В иве-тополе поёт соловей.

Вся природа, напевая песню радости,
Ждёт тебя - любимицу цветов.
Проснись, любимая, проснись,
Гори с лучами зари,
Встретим вместе рабочее утро!

Пора уже... Проснись, любимая, проснись,
Подними ресницы, открой глаза!
Как прекрасен алый рассвет,
Рассыпает лучи Чулпан,
В иве-тополе поёт соловей.
```
