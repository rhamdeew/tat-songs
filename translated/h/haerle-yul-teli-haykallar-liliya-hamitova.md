# Оригинал

### Лилия Хәмитова - Хәерле юл тели һәйкәлләр

```
Һәлакәттән безне кисәткәндәй,

Юл буенда кала һәйкәлләр.

Бу юлларда күпме яшь гомерләр

Фани дөньялардан киткәннәр.

Сак йөрегез зур юлларда,

Юлыкмый хәвефләргә.

Хәерле юл барчагызга

Киләчәк гомерләрдә.

Сак йөрегез зур юлларда,

Юлыкмый хәвефләргә.

Куелмасын һәйкәлләр дә

Озын юл буйларында.

Күрәчәккә ахры җилкенгәндәй,

Ашкындык шул, безне күрегез.

Тик бер генә килә бит гомерләр

Яшәү кадерләрен белегез.

Сак йөрегез зур юлларда,

Юлыкмый хәвефләргә.

Хәерле юл барчагызга

Киләчәк гомерләрдә.

Сак йөрегез зур юлларда,

Юлыкмый хәвефләргә.

Куелмасын һәйкәлләр дә

Озын юл буйларында.

Юл чыгарга сакчы фәрештәдәй

Хәерле юл тели һәйкәлләр.

Исән-имин сезне күрсен, диләр,

Ераклардан өзелеп көткәннәр.

Сак йөрегез зур юлларда,

Юлыкмый хәвефләргә.

Хәерле юл барчагызга

Киләчәк гомерләрдә.

Сак йөрегез зур юлларда,

Юлыкмый хәвефләргә.

Куелмасын һәйкәлләр дә

Озын юл буйларында.
```
