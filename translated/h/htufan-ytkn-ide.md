# Оригинал

### Х.Туфан / Ә.Бакиров - ӘЙТКӘН ИДЕҢ

```
Әйткән идең; “Әгәр сөя калсаң,

Миннән башка берәр бүтәнне,

Сөй бары тик миннән яхшыракны,

Сөймә ләкин миннән түбәнне.
Юлыктым мин быел бер чәчәккә,

Көтмәгәндә, уйламаганда,

Нәкъ синдәйгә, синең шикеллегә,

Әйтерсең лә синең давамга...
Тормышымның синнән соңгысында

Тапканым юк иде һич кемне.

Нишләргә соң? Бир бер киңәш миңа:

Ул һәр яктан синең шикелле.
```

# Перевод

### Х.Туфан / Э.Бакиров - Ты говорил

```
Ты говорила: «Если полюбишь
Кого-то другого, кроме меня,
Люби только того, кто лучше меня,
Не люби того, кто хуже меня».

Повстречал я в этом году один цветок,
Неожиданно, не думая,
Точь-в-точь такой, как ты, похожий на тебя,
Будто он — продолжение тебя...

В моей жизни, после тебя,
Не находил я никого.
Что же делать? Дай мне совет:
Она во всём похожа на тебя.
```
