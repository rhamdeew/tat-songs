# Оригинал

### Мансур Шиһапов / Рим Хәсәнов - Яз җыры (беренче вариант)

```
Җылы нурлар җир өстеннән бөркелә,
Йөрәкләрне җилкендереп яз килә.

Язны котлап җырлаек, дуслар,
Безгә кушылып сайрый кошлар.
Зәңгәр күктә сөенешеп
Яна, яна йолдызлар.

Кояшка таба үрелә саф гөлләр,
Хезмәт җырына күмелә күңелләр.

Язны котлап җырлаек, дуслар,
Безгә кушылып сайрый кошлар.
Зәңгәр күктә сөенешеп
Яна, яна йолдызлар.

Бәхет балкый һәр кешенең йөзендә,
Безне сагынып язлар килә үзе дә!..

Язны котлап җырлаек, дуслар,
Безгә кушылып сайрый кошлар.
Зәңгәр күктә сөенешеп
Яна, яна йолдызлар.
```

# Перевод

### Мансур Шиһапов / Рим Хасанов - Песня весны (первый вариант)

```
Тёплые лучи струятся над землёй,
Весна приходит, волнуя сердца.

В честь весны споём, друзья,
Птицы поют вместе с нами.
В синем небе, радуясь,
Горят, горят звёзды.

К солнцу тянутся чистые цветы,
Души погружаются в песню труда.

В честь весны споём, друзья,
Птицы поют вместе с нами.
В синем небе, радуясь,
Горят, горят звёзды.

Счастье сияет на лице каждого,
И сама весна приходит, соскучившись по нам!..

В честь весны споём, друзья,
Птицы поют вместе с нами.
В синем небе, радуясь,
Горят, горят звёзды.
```
