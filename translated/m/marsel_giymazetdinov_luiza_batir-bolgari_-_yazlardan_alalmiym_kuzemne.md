# Оригинал

### Марсель Гыймазетдинов / Луиза Батыр-Болгари - Язлардан алалмыйм күземне

```
Бәхеткә төренгән,
Шатлыкка күмелгән
Беренче ярату язлары.
Сагынып язларны,
Эзләп бу якларны
Тезелеп кайта кыр казлары.

Көнләшмә, тулган Ай,
Яныңда Зөһрә бар,
Бәхетле сана син үзеңне.
Сөюгә күмелгән,
Шатлыкка төренгән
Язлардан алалмыйм күземне.

Бар җиһан яшәрә,
Дәрт ташый яшьләрдән,
Һәркемгә яз сөю өләшә.
Яр таба ярларны,
Яз сыный аларны
Парлардан хәтта Ай көнләшә.

Көнләшмә, тулган Ай,
Яныңда Зөһрә бар,
Бәхетле сана син үзеңне.
Сөюгә күмелгән,
Шатлыкка төренгән
Язлардан алалмыйм күземне.
```

# Перевод

### Марсель Гыймазетдинов / Луиза Батыр-Болгари - Не могу отвести глаз от весны

```
Окутанные счастьем,
Утопающие в радости -
Весны первой любви.
Тоскуя по веснам,
Разыскивая эти края,
Вереницами возвращаются дикие гуси.

Не ревнуй, полная Луна,
Рядом с тобой есть Зухра,
Считай себя счастливой.
От весен, утопающих в любви,
Окутанных радостью,
Я не могу отвести глаз.

Вся вселенная молодеет,
В молодых переливается пыл,
Каждому весна раздаёт любовь.
Любимые находят любимых,
Весна испытывает их,
Даже Луна завидует парам.

Не ревнуй, полная Луна,
Рядом с тобой есть Зухра,
Считай себя счастливой.
От весен, утопающих в любви,
Окутанных радостью,
Я не могу отвести глаз.
```
