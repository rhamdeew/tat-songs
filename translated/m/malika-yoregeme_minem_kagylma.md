# Оригинал

### Малика - Йорэгемэ минем кагылма

```
Язлар килде, уз кадерен белеп,
Сою булып керде кунелгэ.
Яфракларга тулган боре булып
Бэгыремэ кереп тугелэ.

Син яралар салма, кирэк тугел,
Йорэгемэ минем кагылма.
Утте инде язлар, сонладым дип
Каеннарга килеп сарылма.

Утте дисен язлар, союлэрем минем
Козлэргэчэ дэвам иттелэр.
Э аккошлар сурелдерми аны
Кайсы якка алып киттелэр?

Яфракларга сары сагыш ингэн,
Кошлар китэ туган ягыннан.
Кошлар белэн бергэ саубуллашам
Яшьлегемдэ сойгэн ярымнан.
```

# Перевод

### Малика - Не касайся моего сердца

```
Весна пришла, познав свою ценность,
Вошла любовью в душу мою.
Словно почки, полные листвой,
В мою грудь проникла насквозь.

Ты не наноси мне ран, не надо,
Не касайся моего сердца.
Прошла уже весна, «опоздала», говоря,
Не приходи обниматься с берёзами.

Говоришь, прошла весна, а любовь моя
До самой осени продолжалась.
А белые лебеди, не угасив её,
В какую сторону унесли?

В листву проникла желтая печаль,
Птицы улетают с родной стороны.
Вместе с птицами прощаюсь я
С любимым из моей юности.
```
