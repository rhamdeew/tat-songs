# Оригинал

### Мөхәммәт Садри / Фәрит Хатыйпов - Дөньяда ул булгач

```
Карашым шәфәкътә,
Яңа ай, йолдызда...
Күңелем - сөйкемле
Ут кебек бер кызда!
Әй, энҗе тешләре,
Оялчан күзләре...
Әй, аның назланып
«Кит!» дигән сүзләре.

Мин аны күрүгә,
Атылсам каршына,
«Китсәнә, кит!» - ди ул,
Кызара, тарсына.
«Китсәнә, кит!» - ди ул,
Бер сүз дә әйтмә, ди.
Күңеле эндәшә:
«Калдырып китмә!» - ди.

«Калдырып китмә!» - ди
Күңеле, күзләре;
Әй, көләч йөзләре
Әй, шаян сүзләре!..
Дөньяда ул булгач,
Кояшлы һәрбер таң!
Яратам мин аны,
Өзелеп яратам!
```

# Перевод

### Мухаммат Садри / Фарит Хатипов - Когда она есть на свете

```
Взгляд мой — на закате,
На новом месяце, в звёздах...
Вся душа моя — в одной
Прелестной, как огонь, девушке!
О, жемчужные зубы её,
Застенчивые глаза...
О, как кокетливо
Она говорит: «Уходи!»

Стоит мне увидеть её,
Кинуться ей навстречу —
«Ну уходи, уходи!» — говорит она,
Краснея, смущается.
«Ну уходи, уходи!» — говорит она,
«Ни слова не говори», — велит.
А душа её шепчет:
«Не уходи, не оставляй!»

«Не уходи, не оставляй!» —
Говорят душа её, глаза её;
О, смеющееся лицо её,
О, задорные слова её!..
Пока она есть на свете —
Каждое утро солнечное!
Люблю я её,
Люблю самозабвенно!
```
