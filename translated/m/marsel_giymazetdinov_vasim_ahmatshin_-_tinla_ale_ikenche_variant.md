# Оригинал

### Марсель Гыймазетдинов / Вәсим Әхмәтшин - Тыңла әле (икенче вариант)

```
Тыңла эле: бер моң ишетелә,
Ул моңнарым чыга йөрәктәй.
Шул моңнарым язмышларны жиңеп
Яшәргә бит безне өйрәткән.

Тыңла әле, бер моң ишетелә -
Таныш алар күптән, күптәнге.
Сине көтәм таныш моңнар аша,
Якын итә алмыйм бүтәнне.

Тыңла әле, таныш моңнар ага
Талгын аккан сулар шикелле.
Гомерем буе көтәм,
Аңларсың дип, иркәм,
Башкаларны сөюем икеле.

Тыңла әле, бер моң ишетелә,
Бу моң әллә минем сагышмы?
Сөюемне кире каккан өчен
Сиңа диеп әйткән каргышмы?
```

# Перевод

### Марсель Гыймазетдинов / Васим Ахметшин - Послушай же (второй вариант)

```
Послушай же: звучит один напев,
Этот напев мой льётся, будто из сердца.
Этот напев мой, судьбы победив,
Научил нас жить.

Послушай же, звучит один напев -
Знаком он с давних пор, издавна.
Жду тебя сквозь знакомые напевы,
Не могу приблизить другого.

Послушай же, знакомые напевы текут
Подобно медленно текущим водам.
Всю жизнь свою жду,
Думая, что поймёшь, родная,
Едва ли смогу полюбить другую.

Послушай же, звучит один напев,
Может, этот напев - моя тоска?
Или проклятие, сказанное тебе,
За то, что ты отвергла мою любовь?
```
