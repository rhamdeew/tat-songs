# Оригинал

### Зиннур Насыйбуллин / Фәтхерахман Әхмәдиев - АЛТЫН ТУЙ ҖЫРЫ

```
Илле ел бергә гомер иттегез,

Авыр елларны бергә үттегез;

Барысы да уртак булды:

Кайгыларны бергә җиңдегез,

Бер шатлыкны ике иттегез.
Алтын туегыз бик мөбәрәк икән,

Табыннарыгыз түгәрәк икән.

Гомер юлларын кичкәндә

Сүрелмәслек хис кирәк икән,

Аны саклар көч кирәк икән.
Табынга уртак шатлыклар куелган,

Бөтен туганнар бергә җыелган.

Соңарган кунак шикелле,

Яшьлек үзе шушы табынга

Килеп керер кебек тоела.
```

# Перевод

### Зиннур Насыйбуллин / Фатерахман Ахмадиев - Песня золотой свадьбы

```
Пятьдесят лет вы прожили вместе,

Вместе прошли тяжёлые годы;

Всё у вас было общим:

Вместе преодолевали горести,

Одну радость превращали в две.
Ваша золотая свадьба, оказывается, благословенна,

Ваши столы накрыты по кругу.

Оказывается, проходя жизненный путь,

Нужно неугасимое чувство,

Нужна сила, чтобы его беречь.
На стол поставлены общие радости,

Собрались вместе все родные.

Кажется, будто сама юность,

Словно запоздавший гость,

Вот-вот войдёт за этот стол.
```
