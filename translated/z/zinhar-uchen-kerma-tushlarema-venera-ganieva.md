# Оригинал

### Венера Ганиева - Зинһар өчен, кермә төшләремә…

```
Зинһар өчен, кермә төшләремә…

Мин бит сине күптән оныттым.

Җәй җилләре күптән, күптән агарттылар,

Тараттылар сагыш болытын.

Зинһар өчен, кермә төшләремә.

Уянам да никтер боегам.

Әйтерсең лә, су алмакчы булам

Күптән кипкән сусыз коедан.

Зинһар өчен, кермә төшләремә,

Таң атуга төшләр өзелә.

Көннәремне, елларымны алдың,

Төннәремне калдыр үземә.

Зинһар өчен, кермә төшләремә…

Үртәмәче, көлмә ерактан.

Сине түгел, мин бит яшьлегемне

Шулай сагынам, шулай яратам.

Зинһар өчен, кермә төшләремә…

Минем хәлгә кемнәр төшенә?—

Сөям хәзер бары, бары хыялымда,

Яшим хәзер бары төшемдә.
```

# Перевод

### Венера Ганиева - Прошу тебя, не приходи в мои сны…

```
Прошу тебя, не приходи в мои сны…
Ведь я давно уже забыла тебя.
Летние ветра давно, давно всё отбелили,
Развеяли тучу тоски.

Прошу тебя, не приходи в мои сны.
Просыпаюсь и почему-то грущу.
Будто пытаюсь набрать воды
Из давно высохшего, безводного колодца.

Прошу тебя, не приходи в мои сны,
С рассветом сны обрываются.
Дни мои, годы мои ты забрал,
Оставь мне хотя бы мои ночи.

Прошу тебя, не приходи в мои сны…
Не мучай меня, не смейся издалека.
Не по тебе — по своей молодости
Я так тоскую, так её люблю.

Прошу тебя, не приходи в мои сны…
Кто поймёт моё состояние? —
Люблю теперь лишь, лишь в своих мечтах,
Живу теперь лишь во сне.
```
