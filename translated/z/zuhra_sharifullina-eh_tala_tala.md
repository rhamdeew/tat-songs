# Оригинал

### Зухра Шарифуллина - Эх тала тала

```
Сандугачлар иялэшкэн
Су эчэргэ милэштэн.
Кайгыларым бетэр иде
Сине куреп сойлэшсэм.

Эх, тала, тала, тала,
Тала ике белэгем.
Нигэ тала, нигэ яна
Икэн минем йорэгем?

Агыйлделгэ басма салдым
Каенын сайлап кына.
Яннарына барыр идем
Кош булып сайрап кына.

Эх, тала, тала, тала,
Тала ике белэгем.
Нигэ тала, нигэ яна
Икэн минем йорэгем?

Агыйделкэйне кичкэндэ
Жырлыйм ишкэк ишкэндэ.
Озелэ узэк, яна йорэк
Жаныем искэ тошкэндэ.

Эх, тала, тала, тала,
Тала ике белэгем.
Нигэ тала, нигэ яна
Икэн минем йорэгем?

Агыйдел суы тирбэлэ
Уртасында сал булса.
Суга салсан, калкып чыгар,
Безгэ насыйп яр булса

Эх, тала, тала, тала,
Тала ике белэгем.
Нигэ тала, нигэ яна
Икэн минем йорэгем?
```

# Перевод

### Зухра Шарифуллина - Ах степь, степь

```
Соловьи слетаются
Пить воду у рябины.
Горе моё утихло бы,
Если б с тобой поговорить.

Ах, немеют, немеют, немеют,
Немеют мои руки обе.
Отчего немеют, отчего горит
Моё сердце - почему?

На Агидель мостик кинул
Из берёзы выбирая.
К милой хотел бы я пойти
Птицей песни распевая.

Ах, немеют, немеют, немеют,
Немеют мои руки обе.
Отчего немеют, отчего горит
Моё сердце - почему?

Переправляясь через Агидель
Пою, вёсла погружая.
Рвётся нутро, горит сердце,
Когда родной на память приходит.

Ах, немеют, немеют, немеют,
Немеют мои руки обе.
Отчего немеют, отчего горит
Моё сердце - почему?

Вода Агидели колышет
Плот посредине реки.
В воду бросишь — всплывёт наверх,
Если суждена нам любовь.

Ах, немеют, немеют, немеют,
Немеют мои руки обе.
Отчего немеют, отчего горит
Моё сердце - почему?
```
