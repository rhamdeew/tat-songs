# Оригинал

### З.Вәли / Ф.Әхмәтов - ЯРАТА ИДЕК ИДЕЛ БУЙЛАРЫН

```
Ярата идек Идел шаулавын

Икәү генә бергә тыңларга.
Бергә тыңларга,

Бергә карарга

Сандугачлы язгы таңнарга.
Ярата идек Идел буенда

Икәү генә бергә йөрергә.

Айлы кичләр дә,

Кайнар хисләр дә

Онытылмас, дустым, гомергә.
Ярата идек Идел тавына

Икәү генә бергә менәргә.
Яшьлек бирелми,

Хисләр сүрелми –

Кабынмаган алар сүнәргә.
```

# Перевод

### З.Вэли / Ф.Эхмэтов - Мы любили берега Волги

```
Мы любили слушать шум Волги

Вдвоём, только вдвоём.
Вместе слушать,

Вместе смотреть

На вешние зори с соловьями.
Мы любили гулять по берегу Волги

Вдвоём, только вдвоём.

И лунные вечера,

И жаркие чувства

Не забудутся, друг мой, вовек.
Мы любили подниматься

На волжскую гору вдвоём.
Юность не сдаётся,

Чувства не гаснут –

Ведь не разгоревшись, им не угаснуть.
```
