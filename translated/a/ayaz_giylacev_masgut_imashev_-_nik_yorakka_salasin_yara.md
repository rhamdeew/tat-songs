# Оригинал

### Аяз Гыйләҗев / Мәсгут Имашев - Ник йөрәккә саласың яра?

```
Көлүеңне сөям нурландырып,
Нигә моңланасың бу ара?
Офыклар ак, көннәр, күкләр аяз.
Ник төшәсең авыр уйларга?

Сүзләрең бит һәрчак кайнар иде,
Нигә салкын алар бу ара?
Матур күзкәйләрең кырыс карый.
Ник йөрәккә саласың яра?
```

# Перевод

### Аяз Гилязев / Мәсгут Имашев - Зачем наносишь ты сердцу рану?

```
Люблю твой смех, лучами озаряющий,
Зачем же грустью ты полна?
Горизонты светлы, дни ясны, небеса чисты.
Зачем впадаешь ты в тяжёлые думы?

Слова твои всегда огнём горели,
Зачем же холодом веют теперь они?
Твои прекрасные очи сурово смотрят.
Зачем наносишь ты сердцу рану?
```
