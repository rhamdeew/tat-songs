# Оригинал

### Асаф Вәлиев - Аерылмагыз

```
Су буенда ялгыз аккош,

Каерылган канатлары.

Канатларны каера ул

Аерылу газаплары.

Аерылмагыз, аерылмагыз,

Булса да сәбәпләре.

Канатларны каера ул

Аерылу сәгатьләре.

Ят кошны пар итмәс аккош,

Ялгыз канат какса да.

Без дә бергә булалмабыз,

Сулар үргә акса да.

Ялгыз аккош күргән саен

Өзелә бәгырьләрем.

Нигә без бергә чакларның

Белмибез кадерләрен?!

Су буенда ялгыз аккош,

Каерылган канатлары.

Канатларны каера ул

Аерылу газаплары.

Аерылмагыз, аерылмагыз,

Булса да сәбәпләре.

Гомерләрне кыскарта ул

Аерылу сәгатьләре.
```

# Перевод

###  - Не расставайтесь

```
На берегу реки — одинокий лебедь,
Надломлены его крылья.
Крылья ломает
Мука разлуки.

Не расставайтесь, не расставайтесь,
Даже если есть причины.
Крылья ломают
Часы разлуки.

Чужую птицу лебедь в пару не возьмёт,
Даже маши он одиноким крылом.
И мы не сможем быть вместе,
Даже если реки потекут вспять.

Каждый раз, увидев одинокого лебедя,
Разрывается моё сердце.
Почему мы не знаем цены
Тем временам, когда были вместе?!

На берегу реки — одинокий лебедь,
Надломлены его крылья.
Крылья ломает
Мука разлуки.

Не расставайтесь, не расставайтесь,
Даже если есть причины.
Укорачивают жизнь
Часы разлуки.
```
