# Оригинал

### Энҗе Гөбәйдуллина - Әнием бар шул минем

```
Бигрэк нурлы йозлэрен дип

Ян бэгырем кузлэрен дип

Бишек жырын койлэгэн

Куенына алып ятып

Тоннэр буе матур-матур

Экиятлэр сойлэгэн

Энием бар шул минем.

Бэхетле тормышлар телэп

Миннэн аерылмаска телэп

Саубуллашып калучы

Сагынып хатлар салучы

Куанып каршы алучы

Энием бар шул минем.

Нурлы йозеннен сырларын

Киметсэ иде жырларым

Купме кургэн кулымны

Бигрэк сабыр инде узен

Жан газабы хэрбер сузен

Эни исэн бул куз нурым

Озын булсын гомерен.

Куенынна алып ятып

Тоннэр буе матур-матур

Хикэятлэр сойлэгэн

Энием бар шул минем.
```

# Перевод

###  - Есть же у меня мама

```
Говоря "как лучезарно её лицо",
Говоря "как родны её глаза",
Напевавшая колыбельную,
Взяв в объятья, укладываясь,
Ночи напролёт красивые-красивые
Сказки рассказывавшая —
Ведь есть у меня мама.

Желая счастливой жизни,
Желая не расставаться со мной,
Та, что остаётся, прощаясь,
Та, что пишет с тоской письма,
Та, что радостно встречает —
Ведь есть у меня мама.

Морщины на её светлом лице
Пусть бы уменьшили мои песни.
Сколько повидали мои руки,
Как же ты терпелива сама,
Душевная мука в каждом твоём слове —
Мама, будь жива, свет очей моих,
Пусть долгим будет твой век.

Взяв в объятья, укладываясь,
Ночи напролёт красивые-красивые
Истории рассказывавшая —
Ведь есть у меня мама.
```
