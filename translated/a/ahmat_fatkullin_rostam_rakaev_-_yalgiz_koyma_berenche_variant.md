# Оригинал

### Әхмәт Фәткуллин / Рөстәм Ракаев - Ялгыз көймә (беренче вариант)

```
Ялгыз көймә су кырында
Күптән инде мине көтә.
Ерак илгә — туган җиргә
Диңгез аша мине илтә.

Ерак җиргә минем юлым,
Ишкәк ишеп армас кулым.
Сагыш тулы күңелләрем,
Күз алдымда тик син, туган җирем.

Ялгыз көймә, чиксез диңгез,
Бик еракта туган нигез.
Аккош булып кайтыр идем
Язлар җиткәч сиңа, туган җирем.

Ерак җиргә минем юлым,
Ишкәк ишеп армас кулым.
Сагыш тулы күңелләрем,
Күз алдымда тик син, туган җирем.

Минем җилкән ак бәхеттәй,
Өмет, сагыну юлдашлары.
Туган җиргә кайтып җитсәм,
Үтәр иде сагышларым.

Ерак җиргә минем юлым,
Ишкәк ишеп армас кулым.
Сагыш тулы күңелләрем,
Күз алдымда тик син, туган җирем.
```

# Перевод

### Ахмат Фаткуллин / Рустем Ракаев - Не жги одиноко (первый вариант)

```
Одинокая лодка у воды
Давно уже меня ждёт.
В далёкий край — в родимый край
Через море меня везёт.

В далёкий край лежит мой путь,
Весло гребёт — не устанет рука.
Тоской полна душа моя,
Перед глазами лишь ты, родная земля.

Одинокая лодка, бескрайнее море,
Так далеко родной очаг.
Лебедем белым вернулся б я,
Когда придёт весна к тебе, родная земля.

В далёкий край лежит мой путь,
Весло гребёт — не устанет рука.
Тоской полна душа моя,
Перед глазами лишь ты, родная земля.

Мой парус белый, как счастья свет,
Надежда и тоска — мои спутники.
Если б в родной край вернуться смог,
Прошла бы вся тоска моя.

В далёкий край лежит мой путь,
Весло гребёт — не устанет рука.
Тоской полна душа моя,
Перед глазами лишь ты, родная земля.
```
