# Оригинал

### Абдулхак Игебаев / Рәүф Мортазин - Миңнурый

```
Уйсуларга ап-ак келәм,
Агачларны бәс сыра;
Күңелемдә таң елмайсын,
Кил, чибәрем Миңнурый.

Сөюемә ялкын да бир,
Якты да бир, Миңнурий.
Нур күрмәсә, язгы гөл дә,
Чәчкә чыгармый, корый.

Шаярма син йөрәк белән,
Йөрәк бит — ут, Миңнурый
Сөяр булсаң, ихлас сөй,
Йөремә, кызый, юри.
```

# Перевод

### Абдулхак Игебаев / Рәүф Мортазин - Миннурий

```
На низины лёг белоснежный ковёр,
Деревья иней окутал;
Пусть в душе моей улыбнётся рассвет,
Приди, красавица моя, Миңнурый.

Дай пламени моей любви,
Дай света мне, Миңнурий.
Ведь без лучей весенний цветок
Не распустится, увянет.

Не играй ты с сердцем моим,
Сердце ведь — огонь, Миңнурий.
Если любишь, люби искренне,
Не води, милая, нарочно.
```
