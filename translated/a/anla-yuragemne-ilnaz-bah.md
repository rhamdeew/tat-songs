# Оригинал

### Илназ Бах - Аңла йөрәгемне

```
Хатларын,ны алам, юксынудан янам,

Мин сине hаман да озелеп яратам.

Кайт инде , кайт, жаным, газаплама юкка,

Яндырма, койдермэ, тузэр хэл юк башка.

Ан,ла йорэгемне, тынла йорэгемне,

Утенэм, ялварам, каршы килмэ инде.

Кагыл йоземдэге кайнар яшьлэремэ

Синсез мэгънэ дэ юк ж,ирдэ яшэвемэ.

Купме вакыт узды инде аерылганга,

Хэзер башка берэу тора яннарын,да.

Мин сине ан,лармын , хэтта кичерермен,

Тик нишлэтергэ сон, янган йорэгемне?

Ан,ла йорэгемне, тынла йорэгемне,

Утенэм, ялварам, каршы килмэ инде.

Кагыл йоземдэге кайнар яшьлэремэ

Синсез мэгънэ дэ юк ж,ирдэ яшэвемэ.
```

# Перевод

###  - Пойми моё сердце

```
Получаю письма твои, сгораю от тоски,
Всё ещё безмерно люблю тебя.
Вернись же, вернись, душа моя, не мучай напрасно,
Не жги, не пали — сил терпеть больше нет.

Пойми моё сердце, услышь моё сердце,
Прошу, умоляю, не противься больше.
Коснись горячих слёз на моём лице,
Без тебя нет смысла жить на этой земле.

Сколько времени прошло уже с разлуки,
Теперь рядом с тобой стоит другой человек.
Я пойму тебя, даже прощу,
Но что делать с моим горящим сердцем?

Пойми моё сердце, услышь моё сердце,
Прошу, умоляю, не противься больше.
Коснись горячих слёз на моём лице,
Без тебя нет смысла жить на этой земле.
```
