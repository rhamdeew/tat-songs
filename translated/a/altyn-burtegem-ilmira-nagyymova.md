# Оригинал

### Илмира Нәгыймова - Алтын бөртегем

```
Синдәйләр бар дип уйламадым,

Бар җиһанны иңләдем.

Табалмадым җаным сине,

Хәзинәгә тиңләдем.

Куш-та:

Син кунелем сандыгында,

Минем алтын бертегем.

Бәхет нурлары тарала,

Бер сирпелсәң керфеген.

Табалмадым, бу доньяда,

Бәгърем сиңа тиңнәрне.

Бер кем дә алтыштыра алмый,

Синен көчле иңнәрне.

Куш-та.

Син яшьлектә куңелемдә,

Сунмәс учаклар яктың.

Булмый болай синсез яшәп,

Мин сина кире кайттым.

Куш-та.
```

# Перевод

###  - Моё золотое зёрнышко

```
Не думал я, что есть такие, как ты,
Обошёл весь мир.
Не мог найти тебя, душа моя,
Приравнял тебя к сокровищу.

Припев:
Ты в сундуке моей души,
Моё золотое зёрнышко.
Лучи счастья рассыпаются,
Стоит лишь взмахнуть тебе ресницей.

Не мог найти я в этом мире,
Родная, равных тебе.
Никто не сможет заменить
Твои сильные плечи.

Припев.

Ты в юности горела в моей душе
Незатухающим костром.
Не могу так жить без тебя,
Вернулся я к тебе снова.

Припев.
```
