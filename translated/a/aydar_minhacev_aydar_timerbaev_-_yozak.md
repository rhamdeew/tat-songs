# Оригинал

### Айдар Минһаҗев / Айдар Тимербаев - Йозак

```
Сагындырган идең инде,
Күрешмәдек шул озак.
Килгән идем менә бүген,
Синең ишектә йозак.

Таныш йозак, салкын йозак
Каршымда тора эленеп.
Бикле шул синең йөрәгең дә
Миңа шул йозак кебек.

Ачып керә идем үзем
Шул йозакны мин элек.
Кулымда ачкыч булса да
Хәзер булмый шул кереп.

Таныш йозак, салкын йозак
Каршымда тора эленеп.
Бикле шул синең йөрәгең дә
Миңа шул йозак кебек.

Безнең сөю кайнарлыгын
Йозак күптән оныткан.
Учларыма алам аны
Гүя сине җылытам.

Таныш йозак, салкын йозак
Каршымда тора эленеп.
Бикле шул синең йөрәгең дә
Миңа шул йозак кебек.
```

# Перевод

### Айдар Минһаҗев / Айдар Тимербаев - Замок

```
Я тосковал по тебе уже,
Не виделись мы так долго.
Вот сегодня я пришёл —
На твоей двери замок.

Знакомый замок, холодный замок
Повис передо мной.
И сердце твоё заперто для меня,
Как тот замок.

Я сам открывал бы и входил
В прежние времена.
Хоть ключ у меня в руке,
Теперь не войти.

Знакомый замок, холодный замок
Повис передо мной.
И сердце твоё заперто для меня,
Как тот замок.

Жар нашей любви
Замок давно уже забыл.
Беру его на ладони —
Словно тебя согреваю.

Знакомый замок, холодный замок
Повис передо мной.
И сердце твоё заперто для меня,
Как тот замок.
```
