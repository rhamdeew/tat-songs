# Оригинал

### Асылъяр - Ялгыз конбагыш

```
Юл буенда ялгыз калган
Сары чэчэк - сары конбагыш.
Нигэ синен кузлэреннэн
Тугелэ сон мон тулы сагыш?
Юл буенда конбагыш,
Ник тугелэ монсулы сагыш?

Яшел чирэм юл буенда,
Горур баскан ялгыз конбагыш.
Горурлыгын баш идерми,
Эллэ уткэн юлларын ялгыш.
Эйтче мина, конбагыш,
Уткэн юлынмы эллэ ялгыш?

Яшел чирэм юллар буе
Конбагыштай куккэ урелэ.
Хыялларым канатланып
Чирэмле юл буйлап йогерэ.
Анлата ла конбагыш:
Ялгызлык ул - гомерлек сагыш.
```

# Перевод

### Асылъяр - Одинокий подсолнух

```
У дороги одиноко оставшийся
Желтый цветок - желтый подсолнух.
Почему из твоих глаз
Льется эта печаль, полная тоски?
У дороги подсолнух,
Почему льется печальная тоска?

Зеленая трава у дороги,
Гордо стоящий одинокий подсолнух.
Гордость не даёт голову склонить,
Или пройденные дороги неправильны?
Скажи мне, подсолнух,
Пройденный ли путь неправилен?

Зеленая трава вдоль дорог
Как подсолнух к небу тянется.
Мечты мои окрыленные
По травянистой дороге бегут.
Объясняет подсолнух:
Одиночество - это вечная печаль.
```
