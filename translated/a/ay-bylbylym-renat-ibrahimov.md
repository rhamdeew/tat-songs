# Оригинал

### Ренат Ибраһимов - Ай былбылым

```
Татар - Башкорт халык җыры

Ай былбылым, вай былбылым,

Агыйделнең камышы;

Таң алдыннан чут-чут килә

Сандугачлар тавышы.

Ай былбылым, вай былбылым,

Агыйделдә таң ата;

Таңнар ата, өзелә үзәк,

Җырлата да елата.

Ай былбылым, вай былбылым,

Кунып сайрый талларга;

Синең хакта серләремне

Сөйлим сандугачларга.
```

# Перевод

###  - Ай, соловей мой

```
Татарско-башкирская народная песня

Ах, соловей мой, ах, соловей,
Камыши реки Агидель;
Перед рассветом чут-чут раздаётся
Голос соловьёв.

Ах, соловей мой, ах, соловей,
На Агидели занимается заря;
Занимается заря, нутро разрывается,
То петь заставляет, то плакать.

Ах, соловей мой, ах, соловей,
Сидя на ивах, поёт;
О тебе мои тайны
Рассказываю соловьям.
```
