# Оригинал

### Татар халык җыры - АЙ-ҺАЙ, ГӨЛКӘЕМ

```
Җирән атым, ай, ялларын

Алтын тарак белән лә

Тарыймын шул,

Ай-һай, гөлкәем.

Сез дусларым килә дигәч,

Кайда калку – шуннан ла

Карыймын шул,

Ай-һай, гөлкәем.

Алмагачның алмаларын

Былбыл кошлар кунып ла

Ашасын шул,

Ай-һай, гөлкәем.

Уйнап җибәр, тартып җибәр –

Былбыл кошлар сайравына

Охшасын шул,

Ай-һай, гөлкәем.
```

# Перевод

### Татарская народная песня - Ай-һай, цветочек мой

```
Гриву моего рыжего коня
Золотым гребнем
Расчёсываю,
Ай-хай, цветочек мой.

Когда говорят, что вы, друзья мои, идёте,
На возвышенность, откуда видно,
Смотрю я,
Ай-хай, цветочек мой.

Яблоки яблони
Пусть соловьи, садясь,
Едят,
Ай-хай, цветочек мой.

Заиграй, растяни меха –
На пение соловьёв
Пусть будет похоже,
Ай-хай, цветочек мой.
```
