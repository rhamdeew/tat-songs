# Оригинал

### Эльмира Шәрифуллина / Рәис Нәгыймов - Актанышым - Актанышым - Актанышым - ак илем

```
Актанышым - ак илем,
Ак илемдә - ак көнем.
Илдө-көндә, тирә-юньдә
Шөһрәт казанган җирем.

Актанышым - ак илем.
Канат чыгарган җирем.
Еллар буйлап күп йөредем,
Тапмадым сиңа тиңен.

Басуларың, кырларың -
Бәрәкәт иңгән җирем.
Болындагы чәчәкләрең
Күңелдә таба тиңен.

Актанышым - ак илем,
Ак илемдә - ак көнем.
Мәрхәмәтле кочагыңда
Оятлы булмас йөзем.
```

# Перевод

### Эльмира Шәрифуллина / Райс Нагимов - Актаныш - Актаныш - Актаныш - белое мое поле

```
Актаныш мой - белый край мой,
В белом краю моём - белый день мой.
Во всех краях, в окрестностях
Земля моя, обретшая славу.

Актаныш мой - белый край мой.
Земля, что дала мне крылья.
Много лет ходил я повсюду,
Тебе равного не нашёл я.

Пашни твои, поля твои -
Благодатная земля моя.
Цветы твои на лугу
Находят себе равных в душе.

Актаныш мой - белый край мой,
В белом краю моём - белый день мой.
В твоих милосердных объятиях
Не будет стыдным лицо моё.
```
