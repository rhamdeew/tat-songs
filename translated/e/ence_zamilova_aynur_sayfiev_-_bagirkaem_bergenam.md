# Оригинал

### Энҗе Замилова / Айнур Сәйфиев - Бәгырькәем, бергенәм

```
Бәгырькәем, бергенәм,
Өзелеп сине сөям.
Синсез яшәве күңелсез,
Яннарыңа мин киләм.

Төшләремдә сине күрдем,
Каршыма килә идең.
Сөясеңме, сөймисеңме,
Җанкисәгем, син мине?

Бәгырькәем, бергенәм,
Өзелеп сине сөям.
Синсез яшәве күңелсез,
Яннарыңа мин киләм.

Шаян итеп сөйләүләриң
Нур бөркетә җаныма.
Сагынуга чик-чама юк,
Барам әле яныңа.

Бәгырькәем, бергенәм,
Өзелеп сине сөям.
Синсез яшәве күңелсез,
Яннарыңа мин киләм.

Сиңа киткән юлларым да
Гел чәчкәгә күмелгән.
Үзеңә дә чибәрлекне
Ходаем чиксез биргән.

Бәгырькәем, бергенәм,
Өзелеп сине сөям.
Синсез яшәве күңелсез,
Яннарыңа мин киләм.
```

```
Дорогой мой, единственный мой,
Люблю тебя всей душой.
Без тебя жить - не по себе,
К тебе я иду, любимый.

Во снах видела тебя,
Навстречу ты шёл мне.
Любишь ты меня или нет,
Скажи, моя душа?

Дорогой мой, единственный мой,
Люблю тебя всей душой.
Без тебя жить - не по себе,
К тебе я иду, любимый.

Твои игривые слова
Светом озаряют мою душу.
Нет границ тоске по тебе,
Иду я всё рядом с тобой.

Дорогой мой, единственный мой,
Люблю тебя всей душой.
Без тебя жить - не по себе,
К тебе я иду, любимый.

Дороги, что ведут к тебе,
Всегда цветами устланы.
И тебе самому красоту
Бог даровал безгранично.

Дорогой мой, единственный мой,
Люблю тебя всей душой.
Без тебя жить - не по себе,
К тебе я иду, любимый.
```
