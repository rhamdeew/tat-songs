# Оригинал

### Эльмира Җәлилова / Эльмир Низамов - Сине сагынып

```
сине күрдем, инде белдем
җирдә ярату барын.
синең сулышың ишетми
яшәү юк моннан ары!

яп-якты яна дөньяда
яраткан кеше генә.
синең исем ишетелә,
синең исем ишетелә
йөрәгем тибешендә.

кушымта:

сине сагынып йөдим мин,
тик сине уйлап йөрим.
минем янып яратудан
офыкта кояш эри.

синең йөздә, синең күздә
яшәүнең җете төсе.
иртәләрин уянам мин
тик сине күрер өчен.

син - минем көләч көннәрем,
син - кояшы төннәрнең.
инде беләм, мин бу җиргә
инде беләм, мин бу җиргә
сине эзләп килгәнмен.
```

# Перевод

### Эльмира Джалилова / Эльмир Низамов - С тоской по тебе

```
Тебя увидев, я теперь узнала,
Что на земле есть любовь.
Не слыша твоего дыхания,
Мне дальше не жить!

В этом мире ярко горит
Лишь человек, который любит.
Твоё имя слышится,
Твоё имя слышится
В биении моего сердца.

Припев:

Тоскуя по тебе, хожу я,
Только о тебе думаю.
От моей пылающей любви
На горизонте тает солнце.

В твоём лице, в твоих глазах -
Яркий цвет жизни.
По утрам я просыпаюсь
Лишь ради того, чтобы увидеть тебя.

Ты - мои улыбчивые дни,
Ты - солнце моих ночей.
Теперь я знаю: на эту землю,
Теперь я знаю: на эту землю
Я пришла искать тебя.
```
