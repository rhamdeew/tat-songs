# Оригинал

### Лилиана Ирназарова - Елама гузәлем

```
Елама, гузэлем, кирэкми,

Куз яше яраны тозэтми.

Сойгэнен безне читлэп йори,

Ул сине кондэшенэ сойли.

Тик сине яратам доньяда,

Тоткарлык юк безнен арада.

Булэк итэм сина йорэкне,

Гузэлем, ул сина кирэкми.

Тоннэрен куз яшенне тукмэ,

Аны кире кайтыр дип котмэ.

Киселгэн телемнэр ялганмас,

Бер сунгэн мэхэббэт янмас.

Омет белэн яшэ доньяда,

Чын сою тойгыларын алда.

Бэхетенне ышан, табарсын,

Мэхэббэт утында янарсын.

Елама, гузэлем, кирэкми,

Куз яше яраны тозэтми.

Сойгэнен безне читлэп йори,

Ул сине кондэшенэ сойли.

Тик сине яратам доньяда,

Тоткарлык юк безнен арада.

Булэк итэм сина йорэкне,

Гузэлем, ул сина кирэкми.
```

# Перевод

### Лилиана Ирназарова - Не плачь, красавица моя

```
Не плачь, красавица моя, не нужно,
Слёзы не залечат рану.
Твой любимый обходит нас стороной,
Он о тебе рассказывает своей сопернице.

Только тебя люблю на свете,
Между нами нет преград.
Дарю тебе своё сердце,
Красавица, но оно тебе не нужно.

Не лей слёзы по ночам,
Не жди, что он вернётся.
Отрезанные ломти не срастутся,
Погасшая однажды любовь не разгорится.

Живи с надеждой на свете,
Впереди тебя ждут настоящие чувства любви.
Верь — своё счастье найдёшь,
Загоришься в огне любви.

Не плачь, красавица моя, не нужно,
Слёзы не залечат рану.
Твой любимый обходит нас стороной,
Он о тебе рассказывает своей сопернице.

Только тебя люблю на свете,
Между нами нет преград.
Дарю тебе своё сердце,
Красавица, но оно тебе не нужно.
```
