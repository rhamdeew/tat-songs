# Оригинал

### Эдуард Ижбаев / Риф Арслан - Гомерләрең мизгелләрдән торсын

```
Уйларың ак, рухың ныклы булсын,
Гомер йомгакларын сүтәрлек.
Хыялларың булсын ак каяга,
Төшләреңдә алып менәрлек.

Каршыласын, атар таңнар булып,
Киләчәген җәеп кочагын.
Үзеңнән соң калсын кешеләргә,
Үт алырга кайнар учагың.

Балаларың-кошчыкларың белән,
Яәшәешең нурдай балкысын.
Җылынырлык учак итеп сакла,
Пычкып янган өмет чаткысын.

Җәең ямьле, язың назлы булсын,
Ак кышларың - карлы, буранлы.
Киләчәккә ышанычым булсын,
Озын булсын юлның узганы.

Гомерләрең мизгелләрдән торсын,
Үткәннәрең булсын җыраулы.
Учларында җылытучы булсын
Чәчләреңә яткан кырауны.

Йөрәгеңдә яшәр серең булсын -
Максатларга канат куючы.
Янәшәңдә сөйгән ярың булсын -
Гомер юлын бергә узучы.
```

# Перевод

### Эдуард Ижбаев / Риф Арслан - Пусть твоя жизнь состоится из прекрасных дней

```
Пусть будут мысли чисты, дух крепок,
Способным распутать клубки жизни.
Пусть будут мечты твои белой скалою,
Способным взойти на неё в твоих снах.

Пусть встречают тебя занимающиеся зори,
Раскрыв объятия будущего.
Пусть после тебя останется людям
Твой жаркий очаг, чтобы зажечь огонь.

С детьми-птичками твоими,
Пусть жизнь светится, как свет зари.
Храни, как очаг, чтобы у него грелись,
Тлеющую искру надежды.

Пусть лето твое будет приятным, весна - нежной,
Зимы твои - снежной и буйной.
Пусть будет в будущем вера моя,
Дорога пускай будет длинной.

Пусть твои годы состоят из прекрасных мгновений,
Пусть прошлое твоё будет певучим.
Пусть в ладонях согревающим будет
Иней, что лёг на твои волосы.

Пусть в сердце твоём таится секрет -
Дающий крылья целям.
Пусть рядом любимый будет -
С тобой проходящий путь жизни.
```
