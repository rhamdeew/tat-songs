# Оригинал

### Эльвира Хамматова - Парлы толымнар

```
Озын кара чэчлэренне
Салдын икегэ булеп.
Парлы бэхетлэр телэден
Парлы толымнар уреп.

Парлы, парлы толымнарын
Синен белэн мин идем.
Бэхетлэрен пар булсын дип
Парлы толымнар урден.

Толымнар кук озын булсын
Без утэсе гомер бергэ.
Гел янэшэ барса иде,
Аерылмыйча гомергэ.

Парлы, парлы толымнарын
Синен белэн мин идем.
Бэхетлэрен пар булсын дип
Парлы толымнар урден.

Иртэн бер тон назлы куллар
Толымнарын таратып.
Гомергэ бергэ булырга
Йорэк белэн яратып.

Парлы, парлы толымнарын
Синен белэн мин идем.
Бэхетлэрен пар булсын дип
Парлы толымнар урден.
```

# Перевод

### Эльвира Хамматова - Жемчужные волны

```
Длинные чёрные волосы твои
Разделила надвое.
Парного счастья желая,
Парные косы заплетая.

Парные, парные косы твои
Заплетала я с тобою.
Чтобы счастье твоё было парным,
Парные косы заплела.

Пусть будут длинны, как косы,
Наши совместные годы жизни.
Пусть всегда идём рядом,
Не расставаясь навеки.

Парные, парные косы твои
Заплетала я с тобою.
Чтобы счастье твоё было парным,
Парные косы заплела.

То утром, то ночью нежные руки
Расплетают твои косы.
Чтобы навек быть вместе,
Сердцем любя.

Парные, парные косы твои
Заплетала я с тобою.
Чтобы счастье твоё было парным,
Парные косы заплела.
```
