# Оригинал

### Эдуард Хәмидуллин - Карлыган

```
Бер күрүдә гашыйк булдым,
Карлыгандай күзләрең.
Кызыл чия иреннәрең,
Балдай татлы сүзләрең.

Җәйнең айлы төннәрендә
Пешә кара карлыган.
Ярата сине диярсең,
Яннарыңда мин булмам.

Гомер бит ул үтми тормый,
Көзләр дә килеп җитте.
Сиңа дигән карлыганым
Күптәннән пешеп кипте.

Җәйнең айлы төннәрендә
Пешә кара карлыган.
Ярата сине диярсең,
Яннарыңда мин булмам.

Сандугачлар кунып сайрый
Карлыганга тагын да.
Кавышырбыз микән тагын
Карлыганнар янында.

Җәйнең айлы төннәрендә
Пешә кара карлыган.
Ярата сине диярсең,
Яннарыңда мин булмам.
```

# Перевод

### Эдуард Хәмидуллин - Клюква

```
Один взгляд - и влюбился,
Твои глаза, как смородина.
Твои губы алые, как вишня,
Твои слова медовые, сладкие.

В летние лунные ночи
Зреет чёрная смородина.
Если ты кого-то любишь,
Рядом с тобой меня нет.

Ведь жизнь не стоит на месте,
Осени уже пришли.
Моя смородина для тебя
Давно уже созрела и высохла.

В летние лунные ночи
Зреет чёрная смородина.
Если ты кого-то любишь,
Рядом с тобой меня нет.

Соловьи садятся, поют
У смородины ещё раз.
Сможем ли мы снова встретиться
У самой смородины.

В летние лунные ночи
Зреет чёрная смородина.
Если ты кого-то любишь,
Рядом с тобой меня нет.
```
