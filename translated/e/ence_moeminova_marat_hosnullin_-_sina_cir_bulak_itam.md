# Оригинал

### Энҗе Мөэминова / Марат Хөснуллин - Сиңа җыр бүләк итәм

```
Исемеңне әйтми генә
Сиңа җыр бүләк итәм.
Минем ничек сөюемне
Соңлап аңларсың, иркәм.

Исемеңне әйтсәм әгәр,
Җыр таралыр дөньяга.
Исемеңне ишетерләр,
Ятлар керер арага.

Исемеңне әйтми генә
Сиңа җыр бүләк итәм.
Җырым яныңа килер дә
Серемне сөйләп китәр.

Исемеңне әйтсәм әгәр,
Җыр таралыр дөньяга.
Исемеңне ишетерләр,
Ятлар керер арага.
```

# Перевод

### Энҗе Мөэминова / Марат Хөснуллин - Я дарю тебе песню

```
Не называю имя
Я дарю тебе песню.
Как я люблю тебя,
Ты поймешь потом, моя радость.

Если скажу я имя,
Песня разлетится по миру.
Имя услышат,
Чужие войдут между нами.

Не называю имя
Я дарю тебе песню.
Песня подойдёт к тебе
И расскажет мой секрет.

Если скажу я имя,
Песня разлетится по миру.
Имя услышат,
Чужие войдут между нами.
```
