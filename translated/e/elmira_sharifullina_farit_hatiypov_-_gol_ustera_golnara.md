# Оригинал

### Эльмира Шәрифуллина / Фәрит Хатыйпов - Гөл үстерә Гөлнара

```
Гөлнара күзен ачканчы,
Якты уянган икән.
Якты иртә уянганга,
Гөлләр куанган икән,

Гөл чәчәге елтыр-елтыр
Елмая Гөлнарага.
Чиләгенә җыйган яңгыр
Суын сибә ул аңа.

Гел елмаеп торсын гөлләр,
Гөлнара торган төшкә.
Гөлләргә су сибә-сибә,
Өйрәнә кызлар эшкә...
```

# Перевод

### Эльмира Шәрифуллина / Фарит Хатыпов - Цветы выращивает Гульнара

```
Прежде чем Гульнара открыла глаза,
Уже проснулось утро, оказывается.
Оттого что светлое утро проснулось,
Цветы обрадовались, оказывается,

Цветок цветка светло-светло
Улыбается Гульнаре.
Дождевую воду, собранную в ведёрко,
Она льёт на них.

Пусть всегда улыбаются цветы,
Что снятся Гульнаре во сне.
Поливая цветы водой,
Учатся девушки труду...
```
