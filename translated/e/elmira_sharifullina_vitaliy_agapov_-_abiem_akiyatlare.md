# Оригинал

### Эльмира Шәрифуллина / Виталий Агапов - Әбием әкиятләре

```
Син сөйләгән әкиятләрдә
Чәчәкләр җирдә иде.
Балык сурәтләрдә түгел,
Елгада, күлдә иде.

Кирәксенмибез шифасын,
Яңгырын, чиста карын.
Кайсы әкият сыендырыр
Без яшәгән Җир шарын.

Син сөйләгән әкиятләрдә
Диңгезләр зәңгәр иде.
Юл буйлары - бәбкә үлән,
Егетләр мәргән иде.

Син сөйләгән әкиятләрдә
Изгелек - савап иде.
Әкиятеңне агуладык,
Кипте җирнең җилеге.
```

# Перевод

### Эльмира Шәрифуллина / Виталий Агапов - Сказки моей бабушки

```
В твоих сказках,
Цветы были на земле.
Рыба была не в картинах,
А в реке, в озере.

Нам не нужно его исцеление,
Дождь его, чистый снег.
Какая сказка приютит
Наш земной шар?

В твоих сказках
Моря были синими.
По обочинам - душистые травы,
Юноши были меткими.

В твоих сказках
Доброта была наградой.
Мы отравили твою сказку,
Иссякла живительная сила земли.
```
