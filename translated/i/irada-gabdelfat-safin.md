# Оригинал

### Габделфәт Сафин - Ирадә

```
Рәхимле-шәфкатьле исемең белән

Башлыйм әле изге эшне, Ходаем!

Ярдәм бирсәң, ният кыласым килә,

Ирадәмне төгәл үтәп чыгаем.

Бар кылучыга киңлегең Галәмнең

Пакь эшләре һәм сәҗдәсе адәмнең

Ирештерик сәламен:

«Әл-хәмдүлилләһи раббил-галәмин».

Фәкыйрь колың Сиңа иман китереп

Ярлыкавың сорый ялгыш эшләрне,

Җырларымны бәндәләргә җиткереп

Кичерсәңче кимчелекле төшләрне.

Бар кылучыга киңлегең Галәмнең

Пакь эшләре һәм сәҗдәсе адәмнең

Ирештерик сәламен:

«Әл-хәмдүлилләһи раббил-галәмин».
```

# Перевод

###  - Ирада

```
С Твоим милостивым, милосердным именем
Начинаю благое дело, Боже мой!
Если поможешь, хочу дать обет —
Исполнить свою волю до конца.

Творцу, чья ширь — Вселенная,
Чистым делам и поклону человека
Передадим приветствие:
«Аль-хамдулилляхи раббиль-галямин».

Раб Твой, немощный, уверовав в Тебя,
Просит прощения за ошибочные дела,
Донеся свои песни до людей,
Прости, прошу, несовершенные места.

Творцу, чья ширь — Вселенная,
Чистым делам и поклону человека
Передадим приветствие:
«Аль-хамдулилляхи раббиль-галямин».
```
