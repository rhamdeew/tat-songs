# Оригинал

### Эльнара Нурмөхәммәтова - Ике фәрештә

```
Хыяллар илендэ,

Мэхэббэт жирендэ,

Без биербез икэу

Бэхетнен турендэ.

Син генэ, мин генэ,

Мин генэ, син генэ.

Бу якты доньяда

Без ике фэрештэ.

Тотышып куллардан,

Утлардан, сулардан,

Бергэлэп утэргэ

Язсын бу юллардан.

Син генэ, мин генэ,

Мин генэ, син генэ.

Бу якты доньяда

Без ике фэрештэ.

Катырак очарга,

Куклэргэ очарга,

Телим синен белэн

Доньядан качарга.

Син генэ, мин генэ,

Мин генэ, син генэ.

Бу якты доньяда

Без ике фэрештэ.
```

# Перевод

###  - Два ангела

```
В стране мечтаний,
На земле любви,
Мы будем танцевать вдвоём
На самом почётном месте счастья.

Только ты, только я,
Только я, только ты.
В этом светлом мире
Мы — два ангела.

Держась за руки,
Сквозь огонь и воду,
Пусть суждено нам вместе
Пройти этими дорогами.

Только ты, только я,
Только я, только ты.
В этом светлом мире
Мы — два ангела.

Лететь бы крепче,
Лететь бы в небеса,
Хочу с тобой
Убежать от этого мира.

Только ты, только я,
Только я, только ты.
В этом светлом мире
Мы — два ангела.
```
