# Оригинал

### Илсөяр Шиһапова / Эльмир Низамов - Тормыш тузаны

```
Борма-сырма чаба юллар.
Чабам һаман үзем дә.
Кая барсам, илтә сыман
Юллар туган җиремә.

Яр буенда үргән чәчем
Таратмасын җил генә.
Тормыш тузаны кагылды
Кер белмәс күңелемә.

Еллар үтә, бер туктамый,
Ни син, гомер, ни яшәү?!
Яшәгәндә кирәктер ул
Ялкынланып бер күкрәү.

Яр буенда үргән чәчем
Таратмасын җил генә.
Тормыш тузаны кагылды
Кер белмәс күңелемә.

Чапсын юллар, үтсен гомер,
Булсын газап-әрнүләр.
Сагындырып килгән чакта
Татлы була бәхетләр.

Яр буенда үргән чәчем
Таратмасын җил генә.
Тормыш тузаны кагылды
Кер белмәс күңелемә.
Кер белмәс күңелемә...
```

# Перевод

### Илсөяр Шиһапова / Эльмир Низамов - Пыль жизни

```
Извилисто бегут дороги.
И я всё бегу сама.
Куда бы ни шла, будто ведут
Дороги к родной земле.

Косу, заплетённую на берегу,
Пусть только ветер не расплетёт.
Пыль жизни коснулась
Моей души, не знавшей пятна.

Годы проходят, не останавливаясь,
Что ты, жизнь, что ты, прожитое?
Наверно, нужно, пока живёшь,
Однажды вспыхнуть пламенным грохотом.

Косу, заплетённую на берегу,
Пусть только ветер не расплетёт.
Пыль жизни коснулась
Моей души, не знавшей пятна.

Пусть бегут дороги, пусть проходит жизнь,
Пусть будут муки и боль.
Когда приходит после долгой тоски,
Счастье бывает сладким.

Косу, заплетённую на берегу,
Пусть только ветер не расплетёт.
Пыль жизни коснулась
Моей души, не знавшей пятна.
Моей души, не знавшей пятна...
```
