# Оригинал

### Илдар Юзеев / Фирзәр Мортазин - Хуш инде

```
Хуш инде, мәңгегә
Хуш инде.
Китә яз, китә наз -
Кыш инде.
Тагын бер текәлеп
Карыймчы:
Рәсемеңне күңелемә
Алыймчы.

Ул китә, мәңгегә
Дип китә.
Соң килде мәхәббәт, -
Ник китә?
Чаналар кузгалып
Киттеләр,
Йөрәкне өздереп
Үттеләр.

Эзләрен кар-буран
Сылады.
Юлларга җил ятып
Елады.
Хуш инде, мәңгегә
Хуш инде.
Үтте яз, буранлы
Кыш инде.
```

# Перевод

### Илдар Юзеев / Фирзәр Мортазин - Прощай

```
Прощай же, навсегда
Прощай.
Уходит весна, уходит нежность -
Уже зима.
Дай ещё раз пристально
Посмотрю:
Твой образ в сердце
Унесу.

Она уходит, навсегда -
Так уходит.
Поздно пришла любовь,
Зачем же уходит?
Сани тронулись
И уехали,
Сердце разрывая,
Прошли мимо.

Их следы снег с метелью
Замели.
На дорогах ветер лёг
И плакал.
Прощай же, навсегда
Прощай.
Прошла весна, теперь
Метельная зима.
```
