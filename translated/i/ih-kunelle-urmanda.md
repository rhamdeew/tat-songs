# Оригинал

### Татар халык җыры - ИХ, КҮҢЕЛЛЕ УРМАНДА

```
Кара урманнарга керсәң,

Яңгырый кошлар тавышы

Их, күңелле урманда,

Нарат шаулап торганда.

Кычкырып җырлап җибәрсәң

Басыла йөрәк сагышы.

Их, күңелле урманда,

Кошлар сайрап торганда.

Кара урманнарга керсәм,

Исерәм чәчәк исенә.

Их, күңелле урманда,

Каен шаулап торганда.

Чәчәкләр өзгән чагымда

Син төшәсең исемә.

Их, күңелле урманда,

Кошлар сайрап торганда.
```

# Перевод

### Татарская народная песня - Эх, в весёлом лесу

```
Если войдёшь в тёмный лес,
Раздаётся пение птиц,
Эх, весело в лесу,
Когда сосны шумят.

Если запоёшь во весь голос,
Утихает тоска сердца.
Эх, весело в лесу,
Когда птицы поют.

Когда вхожу в тёмный лес,
Пьянею от запаха цветов.
Эх, весело в лесу,
Когда берёзы шумят.

Когда рву цветы,
Вспоминаю тебя.
Эх, весело в лесу,
Когда птицы поют.
```
