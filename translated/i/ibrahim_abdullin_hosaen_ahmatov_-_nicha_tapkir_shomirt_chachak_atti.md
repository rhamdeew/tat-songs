# Оригинал

### Ибраһим Абдуллин / Хөсәен Әхмәтов - Ничә тапкыр шомырт чәчәк атты

```
Ничә тапкыр шомырт чәчәк атты,
Ничә тапкыр ташты ташкыннар,
Шомыртлар да инде картайдылар,
Тик картаймый икән ярсулар.

Ярсуларым ярга кайтмас инде,
Яр булмагач алар сыерлык -
Яр булмагач ярсып сөерлек,
Гомер буе янып-көерлек.

Ничә тапкыр шомырт чәчәк атты,
Ничә тапкыр килде торналар.
Торналар да китә озак тормый,
Ә сагышлар һаман торалар,
Ә сагышлар һаман торалар.
```

# Перевод

### Ибраһим Абдуллин / Хусаин Ахметов - Сколько раз цвела черемуха

```
Сколько раз цвела черемуха,
Сколько раз бушевали потоки,
Черемухи тоже постарели,
Только страсти, кажется, не стареют.

Мои страсти уже не вернутся к берегу,
Раз нет берега - им нет предела,
Раз нет берега - стоит пылко любить,
Всю жизнь гореть и тлеть.

Сколько раз цвела черемуха,
Сколько раз прилетали журавли.
Журавли улетают, не задерживаясь надолго,
А печали остаются навсегда,
А печали остаются навсегда.
```
