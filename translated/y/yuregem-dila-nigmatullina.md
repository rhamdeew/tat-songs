# Оригинал

### Дилә Нигъмәтуллина - Йөрэгем

```
Монсулы чакларда

Сыкранып, йорэгем,

Чак кына туктамый каласын.

Язмышнын сынавын,

Жэзасын, газабын

Бик якын узенэ аласын.

Ни генэ курмэден,

Ни генэ сизмэден?

Койлэден тынгысыз,койлэден.

Дошманнар ут янсын,

Чын дуслар шатлансын,

Туктамый тип кенэ, йорэгем.

Сэгатьнен сугуы,

Гомернен узуы,

Уткэннэр кала бит хэтердэ.

Яшьлектэ дэртлэнеп

Ут янган йорэгем

Тик кенэ туктамый хичбердэ.

Ни генэ курмэден,

Ни генэ сизмэден?

Койлэден тынгысыз,койлэден.

Дошманнар ут янсын,

Чын дуслар шатлансын,

Туктамый тип кенэ, йорэгем.

Гаепле минутлар,

Шатлыклы секундлар

Ешайта йорэгем тибешен.

Яшисе бар эле,

Доньяда яшьнэде

Туктатма йорэгем тибешен.

Ни генэ курмэден,

Ни генэ сизмэден?

Койлэден тынгысыз,койлэден.

Дошманнар ут янсын,

Чын дуслар шатлансын,

Туктамый тип кенэ, йорэгем.
```

# Перевод

###  - Моё сердце

```
В грустные минуты,
Сжимаясь от боли, сердце моё,
Ты едва не останавливаешься.
Испытания судьбы,
Её кару, её муку
Принимаешь слишком близко к себе.

Чего только ты не видело,
Чего только не почувствовало?
Билось тревожно, билось.
Пусть враги горят в огне,
Пусть настоящие друзья радуются,
Только не останавливайся, сердце моё.

Тиканье часов,
Течение жизни,
Прошлое остаётся ведь в памяти.
В юности, разгоревшись,
Горящее огнём сердце моё
Никогда не останавливается.

Чего только ты не видело,
Чего только не почувствовало?
Билось тревожно, билось.
Пусть враги горят в огне,
Пусть настоящие друзья радуются,
Только не останавливайся, сердце моё.

Виноватые минуты,
Радостные секунды
Учащают биение моего сердца.
Ещё нужно жить,
Засверкало в этом мире,
Не останавливай биение моего сердца.

Чего только ты не видело,
Чего только не почувствовало?
Билось тревожно, билось.
Пусть враги горят в огне,
Пусть настоящие друзья радуются,
Только не останавливайся, сердце моё.
```
