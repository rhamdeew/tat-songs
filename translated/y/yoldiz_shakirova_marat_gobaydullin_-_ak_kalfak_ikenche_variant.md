# Оригинал

### Йолдыз Шакирова / Марат Гобәйдуллин - Ак калфак (икенче вариант)

```
Асыл ташлар, ефәк җепләр кушып,
Чиккән калфак-кызлар бизәге.
Ай алкалы татар сылуының
Күңеле саф, изге йөрәге.

Татар кызы аулак өйләрдә
Кич утырып чигә калфагын.
Якты уйлар, матур теләк теләп
Каршылый ул илемнең таңын.

Татар йолалары онытылмас
Ак калфаклы кызлар булганда.
Асыл затлар-милләт аналары,
Татарлыкны саклап торганда.

Ак калфакның югалган чагы дип,
Җырлар туган үткән елларда.
Югалмасын, каралмасын иде
Калфагыбыз озын юлларда.

Татар кызы, ак калфаклы сылу,
Кушыл әйдә,безнең сафларга.
Милләт өчен, янып-көеп яшәп,
Ана телебезне сакларга!
```

# Перевод

### Йолдыз Шакирова / Марат Гобәйдуллин - Белый калфак (второй вариант)

```
С драгоценными камнями и шёлковыми нитями
Вышитый калфак - украшение девушек.
У татарской красавицы с лунными серьгами
Душа чиста, сердце свято.

Татарская девушка на аулак өй,
Собравшись вечером, вышивает свой калфак.
Со светлыми мыслями, с добрыми пожеланиями
Она встречает рассвет моей страны.

Татарские обычаи не забудутся,
Пока есть девушки в белых калфаках.
Пока благородные души - матери нации -
Берегут татарскую сущность.

В прошлые годы рождались песни
О том, что настала пора утраты белого калфака.
Пусть же не потеряется и не померкнет
Наш калфак на долгих дорогах.

Татарская девушка, красавица в белом калфаке,
Присоединяйся к нашим рядам.
Жить, горя и болея за нацию,
Чтобы сохранить наш родной язык!
```
