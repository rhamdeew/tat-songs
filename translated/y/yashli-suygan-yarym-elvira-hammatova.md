# Оригинал

### Эльвира Хамматова - Яшьли сөйгән ярым

```
Яшьли сөйгән ярым,

Еракларда калдың.

Еракларда, яшьлек таңында.

Төшләремә кер син,

Өннәремдә кил син,

Якты кояшым бул янымда.

Яшьли сөйгән ярым,

Йөрәгемдә калдың.

Аерса да ачы язмышлар.

Үткәнгә уфтанмыйк,

Язмышка сылтанмыйк,

Язмышлардан табыйк узмышлар.

Газаплама көн дә,

Кереп төшләремә.

Синсез яшәү үзе зур газап.

Кайтып килик дустым

Яшьлек таңнарына.

Җитәкләшеп тагын бер кабат.
```

# Перевод

### Эльвира Хамматова - Моя возлюбленная, которую полюбил смолоду

```
Моя любовь с юных лет,

Осталась ты в дальних краях.

В дальних краях, на заре юности.

Приходи в мои сны,

Приходи наяву,

Будь моим ясным солнцем рядом.

Моя любовь с юных лет,

Осталась ты в моём сердце.

Пусть разлучили горькие судьбы.

Не будем горевать о прошлом,

Не будем винить судьбу,

Найдём выход из судеб.

Не мучай меня каждый день,

Приходя в мои сны.

Жизнь без тебя сама по себе большое мучение.

Давай вернёмся, друг мой,

К зорям нашей юности.

Взявшись за руки, ещё раз.
```
