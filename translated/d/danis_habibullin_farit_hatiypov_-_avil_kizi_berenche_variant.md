# Оригинал

### Данис Хәбибуллин / Фәрит Хатыйпов - Авыл кызы (беренче вариант)

```
Авыл кызы, назлы карлыгачым,
Чын куңелдән сине сөйдем мин.
Бүген тагын кичен,
Сине күрер өчен,
Бакчагызга сагынып килдем мин.

Ак пәрдәләр элгән тәрәзәңдә
Таңга кадәр янды утларың.
Йөрәк ярсып типте,
Күңел сине көтте,
Яннарыма нигә чакмадың?

Сиңа сөйләр кайнар хисләремне
Иң түрендә саклыйм хәтернең.
Мин аларны кабат,
Күзләреңә карап,
Бары сиңа гына әйтермен.
```

# Перевод

### Данис Хәбибуллин / Фарит Хатыпов - Деревенская девушка (первый вариант)

```
Деревенская девушка, нежная ласточка моя,
Искренне, всем сердцем я полюбил тебя.
Сегодня снова вечером,
Чтобы увидеть тебя,
Я с тоской пришёл в ваш сад.

В твоём окне с белыми занавесками
До рассвета горели твои огни.
Сердце билось, волнуясь,
Душа ждала тебя,
Почему ты не позвала меня к себе?

Горячие чувства к тебе
Я берегу в глубине памяти.
Я снова,
Глядя в твои глаза,
Скажу их только тебе одной.
```
