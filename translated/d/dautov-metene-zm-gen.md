# Оригинал

### Ә.Даутов / Ә.Даутов - ӨМЕТЕҢНЕ ӨЗМӘ ГЕНӘ

```
Бер генә елмаеп карадың,

Гомергә калдырдың газабын...
Кушымта:
Гел елмай, гел кара күзләремә.

Ялкын сал, ук када йөрәгемә.

Җил генә үтмәсен үзәгемә,

Тик өметеңне өзмә генә.
Елмаеп биек тау башында,

Торасың кебек син каршымда.
Кушымта.
```

# Перевод

### Э.Даутов / Э.Даутов - Не теряй же надежду

```
Ты лишь раз улыбнулась, взглянув,

И оставила мне муку на всю жизнь...
Припев:
Всё улыбайся, всё смотри на меня своими чёрными глазами.

Брось в меня пламя, вонзи стрелу в моё сердце.

Пусть хоть ветер не пронзит моё нутро,

Только не теряй надежды.
Улыбаясь на вершине высокой горы,

Ты словно стоишь передо мной.
Припев.
```
