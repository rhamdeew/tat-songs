# Оригинал

### Дилә Булгакова / Наил Шәймарданов - Ай гүзәлем, Айгизәм

```
Бөрлегәнгә бергә бардык
Тулмады чиләкләрем.
Сагындырыр, юксындырыр
Бөрлегән җыйган мәлем.

Өлгергән бөрлегәннәр,
Җыяр соң тагын кемнәр,
Ай гүзәлем, Айгизәм.

Ишелеп пешкән бөрлегән
Учларымнан коелды.
Эх, беләсе иде синең
Хыялыңны, уеңны.

Өлгергән бөрлегәннәр,
Җыяр соң тагын кемнәр,
Ай гүзәлем, Айгизәм.

Кемнәр өчен җыйдым икән
Бөрлегәннән гөлләмә?
Бергенәм, дип эзләгәнем,
Бөрлегәнем синме әллә?

Өлгергән бөрлегәннәр,
Җыяр соң тагын кемнәр,
Ай гүзәлем, Айгизәм.

Үпкәләмә Айгизәм,
Айым, кояшым дисәм,
Ай гүзәлем, Ай гүзәлем
Ай гүзәлем, Айгизәм.

Өлгергән бөрлегәннәр,
Җыяр соң тагын кемнәр,
Ай гүзәлем, Айгизәм.
```

# Перевод

### Дилә Булгакова / Наил Шәймарданов - Ах красавица, Айгизя

```
За ежевикой вместе ходили,
Не наполнились вёдра мои.
Тоской наполняет, грустью терзает
Тот миг, когда ежевику собирали.

Созревшая ежевика,
Кто же снова будет собирать,
Ах красавица, Айгизя.

Спелая налитая ежевика
Из горстей моих осыпалась.
Эх, знать бы мне твои
Мечты, твои думы.

Созревшая ежевика,
Кто же снова будет собирать,
Ах красавица, Айгизя.

Для кого же я собрал
Букет из ежевики?
Ту единственную, что искал,
Не ты ли моя ежевика?

Созревшая ежевика,
Кто же снова будет собирать,
Ах красавица, Айгизя.

Не обижайся, Айгизя,
Если назову луной, солнцем моим,
Ах красавица, ах красавица,
Ах красавица, Айгизя.

Созревшая ежевика,
Кто же снова будет собирать,
Ах красавица, Айгизя.
```
