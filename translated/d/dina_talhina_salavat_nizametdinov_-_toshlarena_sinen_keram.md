# Оригинал

### Динә Талхина / Салават Низаметдинов - Төшләреңә синең керәм

```
Төшләреңә синең керәм,
Тетрәндерәм күңелне.
Әнә, керфек очына
Тагы да чык эленди,
Төшләреңә синең керәм.

Төшләреңә синең керәм,
Үкендерәм түгелме?
Моңсуланды күзләрем (күзкәйләрең),
Сагышларга күмелде,
Төшләреңә синең керәм.

Төшләреңә синең керәм,
Саташтырып таңнарда.
Башкаларга җан (күз) атма
Бу дөньяда мин барда!
Төшләреңә синең керәм.
```

# Перевод

### Дина Талхина / Салават Низаметдинов - Вхожу в твои сны

```
Вхожу в твои сны,
Тревожу душу.
Вот, на кончик ресницы
Снова повисла роса,
Вхожу в твои сны.

Вхожу в твои сны,
Заставляю сожалеть?
Опечалились глаза мои (твои),
В тоску погрузились,
Вхожу в твои сны.

Вхожу в твои сны,
Заставляя бредить на рассветах.
Не смотри на других,
Пока я есть на этом свете!
Вхожу в твои сны.
```
