# Оригинал

### Ләйсан Гимаева - Җаныкаем жанашым

```
Ин кадерле кеше буген

Минем очен бер генэ.

Ярты суздэн дэ анлаучы

Мине бит, иркэм, син генэ.

Жаныкаем, жанашым,

Сина тобэп карашым.

Гомер буе янэшэндэ

Килэ минем барасым.

Син кунлемнен акчарлыгы,

Яшэу коче бируче.

Сыйпап-сыйпап чэчлэремннэн

Бердэн берем диюче.

Жаныкаем, жанашым,

Сина тобэп карашым.

Гомер буе янэшэндэ

Килэ минем барасым.

Ямьле донья, матур донья

Бары тик безнен очен.

Уртак бэхетне сакларга

Бирермен ботен кочем.

Жаныкаем, жанашым,

Сина тобэп карашым.

Гомер буе янэшэндэ

Килэ минем барасым.
```

# Перевод

###  - Душенька моя, любимый мой

```
Самый дорогой человек сегодня

Для меня только один.

Понимающая меня с полуслова,

Только ты, родная.

Моя душенька, родная,

Взгляд мой устремлён к тебе.

Всю жизнь идти

Рядом с тобой — вот чего я хочу.

Ты — чайка моей души,

Дающая силу жить.

Гладя мои волосы,

Называющая меня единственным.

Моя душенька, родная,

Взгляд мой устремлён к тебе.

Всю жизнь идти

Рядом с тобой — вот чего я хочу.

Прекрасный мир, красивый мир —

Только для нас.

Чтобы сберечь общее счастье,

Отдам все свои силы.

Моя душенька, родная,

Взгляд мой устремлён к тебе.

Всю жизнь идти

Рядом с тобой — вот чего я хочу.
```
