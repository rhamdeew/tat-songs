# Оригинал

### Чәчкә - Җавапсыз сөюем

```
Син ерак та тугел,

Янымда йорисен.

Тик сою газабын

Сизмисен, курмисен.

Кайлардан мин алыйм

Туземлек, сабырлык?

Дэшергэ тыймыймын

Батырлык, коч табып.

Син минем сагышлы,

Газаплы союем.

Яшерен союем,

Жавапсыз союем.

Эле бит сон тугел

Безгэ пар булырга,

Гомернен юлыннан

Бергэлэп барырга.

Син минем сагышлы,

Газаплы союем.

Яшерен союем,

Жавапсыз союем.

Барыбыр соенэм,

Янымда йорсэн дэ.

Шуннан тэм табамын,

Яшерен сойсэм дэ.

Син минем сагышлы,

Газаплы союем.

Яшерен союем,

Жавапсыз союем.
```

# Перевод

### Чэчкэ - Моя безответная любовь

```
Ты не так уж далека(ёк),

Ходишь рядом со мной.

Только муки любви

Не чувствуешь, не видишь.

Откуда мне взять

Терпение, выдержку?

Не могу удержаться, чтобы не заговорить,

Найдя в себе смелость и силы.

Ты моя тоскливая,

Мучительная любовь.

Моя тайная любовь,

Моя безответная любовь.

Ведь ещё не поздно

Стать нам парой,

Идти вместе

По дороге жизни.

Ты моя тоскливая,

Мучительная любовь.

Моя тайная любовь,

Моя безответная любовь.

Всё равно я радуюсь,

Даже если ты просто рядом ходишь.

В этом нахожу вкус,

Даже если люблю тайно.

Ты моя тоскливая,

Мучительная любовь.

Моя тайная любовь,

Моя безответная любовь.
```
