# Оригинал

### Unknown Artist - АК ЧӘЧКӘЛӘР

```
Таллыкта алан,

Аланны япкан

Ап-ак чәчкәләр...

Без бергә идек,

Калфаклар үрдек

Шул ак чәчкәдән.
Алсу йөзеңә

Бигрәк килешә

Чәчкә калфагың.

Синнән дә сылу

Чәчкәләр булу

Мөмкинме тагын?
Өстәлсен хисләр

Шушы хуш исләр

Мәңге сулмасын.

Безнең күңелләр

Өзелгән гөлләр

Кебек булмасын.
```

# Перевод

### Неизвестный артист - Белые цветы

```
В ивняке — поляна,
Поляну укрыли
Белые-белые цветы...

Мы были вместе,
Плели калфаки
Из этих белых цветов.

Твоему румяному лицу
Так идёт
Цветочный калфак.

А разве могут быть
Цветы прекрасней
Тебя самой?

Пусть прибавятся чувства,
Этот сладкий аромат
Пусть никогда не увянет.

Пусть наши сердца
Не станут похожи
На сорванные цветы.
```
