# Оригинал

### Unknown Artist - КАРУАНҺАРАЙ

```
Айкай за гына сайкай, керзәр йыуа,

Һай кем, керзәр йыуганда,

Талмай микән уның беләккәйзәре,

Һай кем, кер сайкаганда.
Күршелә генә тороп, күрешә йөрөп,

Һай кем, күрешә йөрөгәндә

Янмай микән уның йөрәккәйзәре,

Һай кем, кис ятканда.
```

# Перевод

### Неизвестный артист - Караван-сарай

```
Полощет, полощет бельё,

Ай, полоща бельё,

Не устают ли её ручки,

Ай, когда стирает бельё.
Живя по соседству, встречаясь,

Ай, когда встречаются,

Не горит ли её сердечко,

Ай, когда ложится вечером спать.
```
