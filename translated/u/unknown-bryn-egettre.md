# Оригинал

### Unknown Artist - БӨРЙӘН ЕГЕТТӘРЕ

```
Гашиктарзың биле лә бит ул –

Уның бер яме тизәр шул, ник кенә?

Кыззар безгә гишык тотһа,

Минең бер йәнем, тизәр, шул, ник кенә?
Кушымта:

Зәңгәр күкте байкап оса

Урал тау бөркөттәре лә;

Кара кашлы кара күзле

Бөрйәндең егеттәре.
Бөрйән буйы кара урман,

Агас һайын һандугас шул, ник кенә?

Бер йырламай күңел булмай,

Күңел тулы йыр булгас шул, ник кенә?
Кушымта.
```

# Перевод

### Неизвестный артист - Парни Бурзяна

```
Стан у влюблённых — вот в чём дело —
Одна лишь прелесть его быстро проходит, отчего же?
Если девушки нас полюбят,
Душа моя быстро оттает, отчего же?

Припев:
Синее небо озирая, летят
Орлы Уральских гор;
Чернобровые, черноглазые —
Парни Бурзяна.

Вдоль Бурзяна — чёрный лес,
На каждом дереве соловей, отчего же?
Не спевши песню, душе не легче,
Когда душа полна песней, отчего же?

Припев.
```
